# Remove Character | CAD | Sonoran Software Documentation

For the complete documentation index, see [llms.txt](https://docs.sonoransoftware.com/llms.txt)
. This page is also available as [Markdown](https://docs.sonoransoftware.com/cad/api-integration/api-endpoints/civilian/remove-character.md)
.

This API endpoint requires the **plus** version of Sonoran CAD or higher. For more information, see our [pricing](https://docs.sonoransoftware.com/cad/pricing/faq) page.

GitBook Assistant

Characters can NOT be removed from communities using [Database Sync](https://docs.sonoransoftware.com/cad/integration-plugins/database-sync-and-merge)
, as all characters are pulled from your server's in-game database.
