Getting started [#](https://doc.wabisabi.mom/matcha/#getting-started)

======================================================================

This is the documentation for the Matcha LuaVM.

Matcha **is not an executor** — it does not hook any functions in the Roblox engine. Instead it emulates them externally, which makes it completely undetected, but also means it has no direct access to internal Roblox API functions.

# Getting started · UI Library docs

[UI Library](https://doc.wabisabi.mom/ui-lib/)
 / Getting started

Getting started [#](https://doc.wabisabi.mom/ui-lib/#getting-started)

======================================================================

Wabi Sabi is a UI library for Matcha, rendered with the Drawing API. It draws entirely with the Drawing API and polls input itself, so it does not depend on Roblox ScreenGuis or events.

Installation [#](https://doc.wabisabi.mom/ui-lib/#installation)

----------------------------------------------------------------

luaCopy

    loadstring(game:HttpGet("https://scripts.wabisabi.mom/wabi-sabi-ui-lib.lua"))()
    local Library = WabiSabi
    

The library is accessed through the global `WabiSabi`, not the return value of the `loadstring` call.

Quick start [#](https://doc.wabisabi.mom/ui-lib/#quick-start)

--------------------------------------------------------------

luaCopy

    loadstring(game:HttpGet("https://scripts.wabisabi.mom/wabi-sabi-ui-lib.lua"))()
    local Library = WabiSabi
    
    local Window = Library:CreateWindow({
        Title = "My Menu",
        SubTitle = "v1.0",
        Size = Vector2.new(580, 460),
        Resize = true,
    })
    
    local Main = Window:AddTab({ Title = "Main", Icon = "house" })
    
    Main:AddToggle({ Id = "auto_save", Title = "Auto save", Default = true, Callback = function(value)
        print("auto save", value)
    end })
    
    Main:AddSlider({ Id = "volume", Title = "Volume", Min = 0, Max = 100, Default = 50, Callback = function(value)
        print("volume", value)
    end })
    
    Library:Notify({ Title = "Loaded", Content = "Menu ready.", Duration = 4 })

Installation [#](https://doc.wabisabi.mom/obsidian-lib/#installation)

----------------------------------------------------------------------

Load Obsidian directly with `loadstring` and `game:HttpGet`:

luaLoader.luaCopy

    local repo = "https://raw.githubusercontent.com/WhyMayko/Obsidian-MatchaV2/refs/heads/main/"
    loadstring(game:HttpGet(repo .. "Loader.lua"))()
    
    local Library, ThemeManager, SaveManager, EssentialsManager, WebhookManager, GroupGuard = _G.Obsidian()
    

### Modules [#](https://doc.wabisabi.mom/obsidian-lib/#modules)

| Module | Description |
| --- | --- |
| `Library` | Window engine, tabs, widgets, overlays, and watermark. |
| `ThemeManager` | 33+ built-in color themes and custom theme management. |
| `SaveManager` | Configuration saving and loading (`Options` and `Toggles`). |
| `EssentialsManager` | Menu settings (Keybind menu, Input block, DPI scaling, Unload). |
| `WebhookManager` | Discord webhook integration and logs. |
| `GroupGuard` | Roblox group rank verification. |

* * *

Quickstart [#](https://doc.wabisabi.mom/obsidian-lib/#quickstart)

------------------------------------------------------------------

luaExample.luaCopy

    local repo = "https://raw.githubusercontent.com/WhyMayko/Obsidian-MatchaV2/refs/heads/main/"
    loadstring(game:HttpGet(repo .. "Loader.lua"))()
    
    local Library, ThemeManager, SaveManager, EssentialsManager, WebhookManager, GroupGuard = _G.Obsidian()
    
    local Options = Library.Options
    local Toggles = Library.Toggles
    
    local Window = Library:CreateWindow({
        Title = "mspaint",
        Footer = "version: 2.0.0",
        Icon = 95816097006870,
        NotifySide = "Right",
        ShowSearch = true,
        Resizable = true,
        Size = Vector2.new(720, 600),
        MinSize = Vector2.new(480, 360),
        Transparency = 1,
    })
    
    local Tabs = {
        Main = Window:AddTab("Main", "user"),
        Combat = Window:AddTab("Combat", "swords"),
        Key = Window:AddKeyTab("Key System"),
        Webhook = Window:AddWebhookTab("Webhook"),
        ["UI Settings"] = Window:AddTab("UI Settings", "settings"),
    }
    
    local LeftGroup = Tabs.Main:AddLeftGroupbox("Player Controls", "user")
    
    LeftGroup:AddToggle("EspToggle", {
        Text = "Enable Player ESP",
        Default = false,
        Tooltip = "Highlights enemy players through walls.",
        Callback = function(value)
            print("ESP Enabled:", value)
        end,
    }):AddColorPicker("EspColor", {
        Default = Color3.fromRGB(255, 60, 60),
        Title = "ESP Accent Color",
        Callback = function(color)
            print("ESP Color:", color)
        end,
    })
    
    LeftGroup:AddSlider("WalkSpeed", {
        Text = "WalkSpeed Multiplier",
        Min = 16,
        Max = 250,
        Default = 16,
        Rounding = 0,
        Suffix = " studs/s",
        HideMax = false,
        Callback = function(value)
            print("WalkSpeed:", value)
        end,
    })
    
    EssentialsManager:SetLibrary(Library)
    EssentialsManager:BuildSection(Tabs["UI Settings"])
    
    SaveManager:SetLibrary(Library)
    SaveManager:SetFolder("Obsidian/Settings")
    SaveManager:BuildConfigSection(Tabs["UI Settings"])
    
    ThemeManager:SetLibrary(Library)
    ThemeManager:SetFolder("Obsidian/Settings")
    ThemeManager:ApplyToTab(Tabs["UI Settings"])
    
    Library:SetWatermark("Obsidian Matcha")
    Library:SetWatermarkVisibility(true)

Global Tables [#](https://doc.wabisabi.mom/obsidian-lib/#global-tables)

*   **`Library.Options[id]`**: Stores handles for all other widgets (`Options.MyOption.Value`).

# Globals · Matcha docs

[Matcha](https://doc.wabisabi.mom/matcha/)

Globals [#](https://doc.wabisabi.mom/matcha/functions-globals/#globals)

========================================================================

loadstring / load [#](https://doc.wabisabi.mom/matcha/functions-globals/#loadstring-load)

------------------------------------------------------------------------------------------

luaCopy

    function loadstring(chunk: string, chunkname: string?): function
    function load(chunk: string, chunkname: string?): function
    

Compiles `chunk` into a callable function (`load` is equivalent for string chunks).

Two Matcha-specific differences: a syntax error still returns a function (the error only prints when the function is called — never `nil` + message, so it isn't catchable), and a chunk's top-level `return` values are dropped (`loadstring("return 5")()` yields nothing — pass results out via globals).

decompile [#](https://doc.wabisabi.mom/matcha/functions-globals/#decompile)

----------------------------------------------------------------------------

luaCopy

    function decompile(script: Instance): string
    

Returns the decompiled source of `script` (a `LocalScript`, `ModuleScript`, or `Script`) as a string. If decompilation fails, an error message is printed to the console.

WorldToScreen [#](https://doc.wabisabi.mom/matcha/functions-globals/#worldtoscreen)

------------------------------------------------------------------------------------

luaCopy

    function WorldToScreen(position: Vector3): (Vector2, boolean)
    

Projects a 3D world `position` into 2D screen space. Returns the screen position in **pixels** (top-left origin) and a boolean that is `true` when the point is on screen; off screen or behind the camera returns `(0, 0)` and `false`.

luaCopy

    local pos, onScreen = WorldToScreen(part.Position)
    if onScreen then
        -- pos.X, pos.Y are valid pixel coordinates
    end

----------------------------------------------------------------------

luaCopy

    function notify(message: string, title: string, duration: number)
    

Shows a Matcha notification with the given message, title, and duration (seconds). Returns nothing.

luaCopy

----------------------------------------------------------------------------------

luaCopy

# Garbage collector · Matcha docs

[Matcha](https://doc.wabisabi.mom/matcha/)
 / Functions / Garbage collector

Garbage collector [#](https://doc.wabisabi.mom/matcha/garbage-collector/#garbage-collector)

============================================================================================

These functions find and modify values held in the game's Lua garbage collector by name, such as weapon stats and other values stored in Lua tables.

getgc [#](https://doc.wabisabi.mom/matcha/garbage-collector/#getgc)

--------------------------------------------------------------------

luaCopy

    function getgc(name: string): { table }
    function getgc(names: { string }): { table }
    

Returns every garbage-collected value stored under `name`. Pass a list of names to collect them all in a single scan. The result is an array of entries; each entry is a table:

*   `key` — the name the value was found under
*   `value` — the current value
*   `type` — the value's type (`number`, `string`, `boolean`, `table`, `function`, `userdata`, ...)
*   `addr` — the value's memory address

The same name can be stored in many places, so multiple entries are normal. Returns an empty table if nothing is found.

setgc [#](https://doc.wabisabi.mom/matcha/garbage-collector/#setgc)

--------------------------------------------------------------------

luaCopy

    function setgc(key: string, value: Any): int
    function setgc(values: { [string]: Any }): int
    

Sets every garbage-collected value stored under `key` to `value`, scanning the collector on each call. Pass a table to set multiple keys at once. Only values whose type matches `value` are changed. Returns the number of values set.

luaCopy

    -- singular
    setgc("FireRate", 0)
    
    -- group
    setgc({
        FireRate = 0,
        SpreadAngle = 0,
        CameraRecoilMult = 0,
        MagAmmo = 999999
    })
    

applygc [#](https://doc.wabisabi.mom/matcha/garbage-collector/#applygc)

------------------------------------------------------------------------

luaCopy

    function applygc(cache: table, key: string, value: Any): int
    function applygc(cache: table, values: { [string]: Any }): int
    

Same as `setgc`, but applies to a `cache` returned by `getgc` instead of scanning again. Call `getgc` once and reuse the cache with `applygc` when setting values repeatedly, such as inside a loop or for values the game keeps resetting. Run `getgc` again to refresh the cache if the values are rebuilt, for example after respawning or switching weapons. Returns the number of values set.

luaCopy

    local cache = getgc({ "FireRate", "SpreadAngle", "MagAmmo" })
    
    -- singular
    applygc(cache, "FireRate", 0)
    applygc(cache, "MagAmmo", 999999)
    
    -- group
    applygc(cache, { FireRate = 0, SpreadAngle = 0, MagAmmo = 999999 })

HTTP [#](https://doc.wabisabi.mom/matcha/http/#http)

=====================================================

`httpget` and `httppost` are **synchronous** — they block until the response arrives and return the response body as a string. They never raise an error: an HTTP error status (e.g. 404) returns the server's response body, and a connection failure (e.g. an unreachable host) returns an empty string. They are the global equivalents of `game:HttpGet` / `game:HttpPost`.

httpget [#](https://doc.wabisabi.mom/matcha/http/#httpget)

-----------------------------------------------------------

luaCopy

    function httpget(url: string, headers: table?): string
    

Sends a GET request to `url` and returns the response body. Optionally pass a table of request headers.

luaCopy

    local body = httpget("https://example.com/data.json")
    if body ~= "" then
        local data = game:GetService("HttpService"):JSONDecode(body)
    end

-------------------------------------------------------------

luaCopy

    function httppost(url: string, body: string, contentType: string?, headers: table?): string
    

Sends a POST request to `url` with `body` and returns the response body. `contentType` defaults to `"application/json"`. Optionally pass a table of request headers as the fourth argument.

luaCopy

# File system · Matcha docs

[Matcha](https://doc.wabisabi.mom/matcha/)

File system [#](https://doc.wabisabi.mom/matcha/filesystem/#file-system)

=========================================================================

Paths are relative to the Matcha workspace folder (e.g. `C:\matcha\workspace\`). `/` and `\` are interchangeable, and paths are case-insensitive.

`readfile`, `writefile`, and `appendfile` only accept these extensions: **`.txt` `.lua` `.luau` `.json` `.cfg` `.dat` `.ini`**. Any other extension — including images, audio, and executables — raises `file extension not allowed`. Contents are binary-safe, so store raw/binary data under `.dat`.

writefile [#](https://doc.wabisabi.mom/matcha/filesystem/#writefile)

---------------------------------------------------------------------

luaCopy

    function writefile(path: string, content: string): nil
    

Creates `path` (or overwrites it) with `content`. Missing parent folders are created automatically. Content is written exactly, including binary data. Errors if `path` has a disallowed extension or is an existing folder.

readfile [#](https://doc.wabisabi.mom/matcha/filesystem/#readfile)

-------------------------------------------------------------------

luaCopy

    function readfile(path: string): string
    

Returns the contents of `path` as a string (binary-safe). Errors if the file does not exist, so guard with `isfile` or `pcall`.

luaCopy

    if isfile("MyConfig.json") then
        local raw = readfile("MyConfig.json")
    end
    

appendfile [#](https://doc.wabisabi.mom/matcha/filesystem/#appendfile)

-----------------------------------------------------------------------

luaCopy

    function appendfile(path: string, content: string): nil
    

Appends `content` to the end of `path`, creating the file if it does not exist. Content is concatenated exactly — no separator is inserted.

makefolder [#](https://doc.wabisabi.mom/matcha/filesystem/#makefolder)

-----------------------------------------------------------------------

luaCopy

    function makefolder(path: string): nil

# Lua base library · Matcha docs

[Matcha](https://doc.wabisabi.mom/matcha/)
 / Functions / Lua base library

Lua base library [#](https://doc.wabisabi.mom/matcha/lua-base-library/#lua-base-library)

=========================================================================================

Matcha runs on a Luau-based VM, so the standard Lua(U) global functions are available and behave per the [Lua 5.1 reference](https://www.lua.org/manual/5.1/)
 **except** where noted below. This page lists what the VM actually exposes and flags the Matcha-specific differences — it does not re-document standard Lua semantics.

Type & conversion [#](https://doc.wabisabi.mom/matcha/lua-base-library/#type-conversion)

-----------------------------------------------------------------------------------------

### type [#](https://doc.wabisabi.mom/matcha/lua-base-library/#type)

luaCopy

    function type(value: any): string
    

Standard. Roblox datatypes (`Vector3`, `CFrame`, …) and Instances all report as `"userdata"` — use `typeof` for the specific name.

### tostring [#](https://doc.wabisabi.mom/matcha/lua-base-library/#tostring)

luaCopy

    function tostring(value: any): string
    

Standard, and honors `__tostring`. Matcha formats Roblox datatypes differently from Roblox itself — `tostring(Vector3.new(1, 2, 3))` returns `"Vector3(1.0000, 2.0000, 3.0000)"`, not `"1, 2, 3"`.

### tonumber [#](https://doc.wabisabi.mom/matcha/lua-base-library/#tonumber)

luaCopy

    function tonumber(value: any, base: number?): number?
    

Standard. Trims surrounding whitespace, parses `0x` hex, and accepts a `base` (2–36) — `tonumber("ff", 16)` returns `255`. Returns `nil` if the value can't be parsed.

Iteration & varargs [#](https://doc.wabisabi.mom/matcha/lua-base-library/#iteration-varargs)

---------------------------------------------------------------------------------------------

### pairs / ipairs / next [#](https://doc.wabisabi.mom/matcha/lua-base-library/#pairs-ipairs-next)

luaCopy

    function pairs(t: table): (function, table, any)
    function ipairs(t: table): (function, table, number)
    function next(t: table, key: any?): (any, any)
    

Standard iteration; `ipairs` stops at the first `nil` hole.

`pairs` does **not** honor the Luau `__iter` metamethod — it always iterates the raw table.

### select [#](https://doc.wabisabi.mom/matcha/lua-base-library/#select)

luaCopy

    function select(n: number | "#", ...): ...
    

Standard, including **negative indices**: `select(-1, ...)` returns the last argument.

### unpack [#](https://doc.wabisabi.mom/matcha/lua-base-library/#unpack)

luaCopy

    function unpack(t: table, i: number?, j: number?): ...
    

Returns `t[i]` through `t[j]` (defaults `i = 1`, `j = #t`). Exposed as a **global** — mainline Luau only provides `table.unpack`. `unpack` and `table.unpack` are separate function objects but behave identically.

Errors & protected calls [#](https://doc.wabisabi.mom/matcha/lua-base-library/#errors-protected-calls)

-------------------------------------------------------------------------------------------------------

### assert [#](https://doc.wabisabi.mom/matcha/lua-base-library/#assert)

luaCopy

    function assert(value: any, message: string?, ...): ...
    

Raises a catchable error (`Matcha:<line>: <message>`, or `assertion failed!` with no message) if `value` is falsy; otherwise returns its arguments unchanged — the way to raise a catchable error in Matcha.

### pcall [#](https://doc.wabisabi.mom/matcha/lua-base-library/#pcall)

luaCopy

    function pcall(f: function, ...): (boolean, ...)
    

Standard. Returns `true` plus `f`'s results on success, or `false, "Matcha:<line>: <message>"` on a runtime fault.

### xpcall [#](https://doc.wabisabi.mom/matcha/lua-base-library/#xpcall)

luaCopy

    function xpcall(f: function, handler: function, ...): (boolean, ...)
    

Standard, and **forwards extra arguments to `f`** (Luau-style): `xpcall(fn, handler, 3, 4)` calls `fn(3, 4)`. On a real error, `handler` runs with the error message.

Metatables [#](https://doc.wabisabi.mom/matcha/lua-base-library/#metatables)

-----------------------------------------------------------------------------

### setmetatable / getmetatable [#](https://doc.wabisabi.mom/matcha/lua-base-library/#setmetatable-getmetatable)

luaCopy

    function setmetatable(t: table, mt: table?): table
    function getmetatable(t: any): table | any
    

Standard. `getmetatable` returns the `__metatable` field when set; `setmetatable` on a table with a protected (`__metatable`) metatable raises `cannot change a protected metatable`.

### newproxy [#](https://doc.wabisabi.mom/matcha/lua-base-library/#newproxy)

luaCopy

    function newproxy(addMetatable: boolean?): userdata
    

Lua 5.1 holdover, fully supported. Returns a blank `userdata`; with `newproxy(true)` it gets a fresh, settable metatable (retrieved via `getmetatable`), so metamethods like `__index` and `__tostring` work.

Raw access [#](https://doc.wabisabi.mom/matcha/lua-base-library/#raw-access)

-----------------------------------------------------------------------------

### rawget / rawset / rawequal / rawlen [#](https://doc.wabisabi.mom/matcha/lua-base-library/#rawget-rawset-rawequal-rawlen)

luaCopy

    function rawget(t: table, key: any): any
    function rawset(t: table, key: any, value: any): table
    function rawequal(a: any, b: any): boolean
    function rawlen(t: table | string): number
    

Standard. These bypass metamethods; `rawset` returns the table.

Memory [#](https://doc.wabisabi.mom/matcha/lua-base-library/#memory)

---------------------------------------------------------------------

### gcinfo [#](https://doc.wabisabi.mom/matcha/lua-base-library/#gcinfo)

luaCopy

    function gcinfo(): number
    

Returns the VM's current memory usage in kilobytes.

getbase [#](https://doc.wabisabi.mom/matcha/memory/#getbase)

-------------------------------------------------------------

luaCopy

    function getbase(): int
    

Returns the base address of the `RobloxPlayerBeta.exe` module as a number (e.g. `140698037846016`) — the anchor for turning module offsets into absolute addresses.

memory\_write [#](https://doc.wabisabi.mom/matcha/memory/#memory_write)

------------------------------------------------------------------------

luaCopy

    memory_write(memoryType: string, address: int, value: Any): nil
    

Writes `value` to `address`, interpreting it as `memoryType` — the same type set as `memory_read` (`int`, `float`, `double`, `byte`, `string`, `uintptr_t`). Returns nothing.

Ensure the address and value type are correct before writing; a write to the wrong address can crash Roblox.

memory\_read [#](https://doc.wabisabi.mom/matcha/memory/#memory_read)

----------------------------------------------------------------------

luaCopy

    memory_read(memoryType: string, address: int): Any
    

Reads the value of type `memoryType` at `address` (see the **Memory Types** table). `byte` is 0–255, `int` a signed 32-bit integer, `uintptr_t` an unsigned 64-bit value, and `float`/`double` reinterpret the raw bytes. Reading an unmapped address safely returns `0`. The `string` type reads bytes until the first non-printable one (no length argument).

## loadstring / load

\`\`\`lua

Two Matcha-specific differences: a syntax error still returns a function (the error only prints when the function is called — never \`nil\` + message, so it isn't catchable), and a chunk's top-level \`return\` values are dropped (\`loadstring("return 5")()\` yields nothing — pass results out via globals).

Projects a 3D world \`position\` into 2D screen space. Returns the screen position in \*\*pixels\*\* (top-left origin) and a boolean that is \`true\` when the point is on screen; off screen or behind the camera returns \`(0, 0)\` and \`false\`.

## Get Fast Flag

\`\`\`lua

## require

\`\`\`lua
function require(path: string): table
\`\`\`

\`\`\`lua

# Garbage collector

Source: https://doc.wabisabi.mom/matcha/garbage-collector/

# Garbage collector

These functions find and modify values held in the game's Lua garbage collector by name, such as weapon stats and other values stored in Lua tables.

## getgc

\`\`\`lua
function getgc(name: string): { table }
function getgc(names: { string }): { table }
\`\`\`

Returns every garbage-collected value stored under \`name\`. Pass a list of names to collect them all in a single scan. The result is an array of entries; each entry is a table:

- \`key\` — the name the value was found under
- \`value\` — the current value
- \`type\` — the value's type (\`number\`, \`string\`, \`boolean\`, \`table\`, \`function\`, \`userdata\`, ...)
- \`addr\` — the value's memory address

The same name can be stored in many places, so multiple entries are normal. Returns an empty table if nothing is found.

## setgc

\`\`\`lua
function setgc(key: string, value: Any): int
function setgc(values: { \[string\]: Any }): int
\`\`\`

Sets every garbage-collected value stored under \`key\` to \`value\`, scanning the collector on each call. Pass a table to set multiple keys at once. Only values whose type matches \`value\` are changed. Returns the number of values set.

\`\`\`lua
-- singular
setgc("FireRate", 0)

-- group
setgc({
    FireRate = 0,
    SpreadAngle = 0,
    CameraRecoilMult = 0,
    MagAmmo = 999999
})
\`\`\`

## applygc

\`\`\`lua
function applygc(cache: table, key: string, value: Any): int
function applygc(cache: table, values: { \[string\]: Any }): int
\`\`\`

Same as \`setgc\`, but applies to a \`cache\` returned by \`getgc\` instead of scanning again. Call \`getgc\` once and reuse the cache with \`applygc\` when setting values repeatedly, such as inside a loop or for values the game keeps resetting. Run \`getgc\` again to refresh the cache if the values are rebuilt, for example after respawning or switching weapons. Returns the number of values set.

\`\`\`lua
local cache = getgc({ "FireRate", "SpreadAngle", "MagAmmo" })

-- singular
applygc(cache, "FireRate", 0)
applygc(cache, "MagAmmo", 999999)

-- group
applygc(cache, { FireRate = 0, SpreadAngle = 0, MagAmmo = 999999 })
\`\`\`

# File system

{% hint style="warning" %}
Paths are relative to the Matcha workspace folder (e.g. \`C:\\matcha\\workspace\\\`). \`/\` and \`\\\` are interchangeable, and paths are case-insensitive.

\`readfile\`, \`writefile\`, and \`appendfile\` only accept these extensions: \*\*\`.txt\` \`.lua\` \`.luau\` \`.json\` \`.cfg\` \`.dat\` \`.ini\`\*\*. Any other extension — including images, audio, and executables — raises \`file extension not allowed\`. Contents are binary-safe, so store raw/binary data under \`.dat\`.
{% endhint %}

## writefile

\`\`\`lua
function writefile(path: string, content: string): nil
\`\`\`

Creates \`path\` (or overwrites it) with \`content\`. Missing parent folders are created automatically. Content is written exactly, including binary data. Errors if \`path\` has a disallowed extension or is an existing folder.

## readfile

\`\`\`lua
function readfile(path: string): string
\`\`\`

Returns the contents of \`path\` as a string (binary-safe). Errors if the file does not exist, so guard with \`isfile\` or \`pcall\`.

\`\`\`lua
if isfile("MyConfig.json") then
    local raw = readfile("MyConfig.json")
end
\`\`\`

## appendfile

\`\`\`lua
function appendfile(path: string, content: string): nil
\`\`\`

Appends \`content\` to the end of \`path\`, creating the file if it does not exist. Content is concatenated exactly — no separator is inserted.

## makefolder

\`\`\`lua
function makefolder(path: string): nil
\`\`\`

Creates the folder at \`path\`, including any missing parent folders. Does nothing if the folder already exists. Errors if a file already occupies the path.

## isfile

\`\`\`lua
function isfile(path: string): boolean
\`\`\`

Returns \`true\` only if \`path\` is an existing file; \`false\` for folders or missing paths. Never errors.

## isfolder

\`\`\`lua
function isfolder(path: string): boolean
\`\`\`

Returns \`true\` only if \`path\` is an existing folder; \`false\` for files or missing paths. Never errors.

## listfiles

\`\`\`lua
function listfiles(path: string): { string }
\`\`\`

Returns the immediate children of \`path\` — files and folders, not recursive — as workspace-relative paths sorted alphabetically (e.g. \`listfiles("cfg")\` → \`{ "cfg\\\\a.json", "cfg\\\\sub" }\`). Each entry can be passed straight to \`isfile\`, \`isfolder\`, or \`readfile\`. \`listfiles("")\` lists the workspace root. Errors if \`path\` does not exist or is a file.

## delfile

\`\`\`lua
function delfile(path: string): boolean
\`\`\`

Deletes the file (or empty folder) at \`path\`. Returns \`true\` if something was removed, \`false\` if the path did not exist. Errors if \`path\` is a non-empty folder — use \`delfolder\` for those.

## delfolder

\`\`\`lua
function delfolder(path: string): boolean
\`\`\`

Recursively deletes the folder (or file) at \`path\` and everything inside it. Always returns \`true\`, even if \`path\` did not exist.

{% hint style="info" %}
\`httpget\` and \`httppost\` are \*\*synchronous\*\* — they block until the response arrives and return the response body as a string. # Lua base library

Matcha runs on a Luau-based VM, so the standard Lua(U) global functions are available and behave per the \[Lua 5.1 reference\](https://www.lua.org/manual/5.1/) \*\*except\*\* where noted below. This page lists what the VM actually exposes and flags the Matcha-specific differences — it does not re-document standard Lua semantics.

## Type & conversion

### type

\`\`\`lua
function type(value: any): string
\`\`\`

Standard. Roblox datatypes (\`Vector3\`, \`CFrame\`, …) and Instances all report as \`"userdata"\` — use \`typeof\` for the specific name.

### tostring

\`\`\`lua
function tostring(value: any): string
\`\`\`

Standard, and honors \`\_\_tostring\`. Matcha formats Roblox datatypes differently from Roblox itself — \`tostring(Vector3.new(1, 2, 3))\` returns \`"Vector3(1.0000, 2.0000, 3.0000)"\`, not \`"1, 2, 3"\`.

### tonumber

\`\`\`lua
function tonumber(value: any, base: number?): number?
\`\`\`

Standard. Trims surrounding whitespace, parses \`0x\` hex, and accepts a \`base\` (2–36) — \`tonumber("ff", 16)\` returns \`255\`. Returns \`nil\` if the value can't be parsed.

## Iteration & varargs

### pairs / ipairs / next

\`\`\`lua
function pairs(t: table): (function, table, any)
function ipairs(t: table): (function, table, number)
function next(t: table, key: any?): (any, any)
\`\`\`

Standard iteration; \`ipairs\` stops at the first \`nil\` hole.

{% hint style="warning" %}
\`pairs\` does \*\*not\*\* honor the Luau \`\_\_iter\` metamethod — it always iterates the raw table.
{% endhint %}

### select

\`\`\`lua
function select(n: number | "#", ...): ...
\`\`\`

Standard, including \*\*negative indices\*\*: \`select(-1, ...)\` returns the last argument.

### unpack

\`\`\`lua
function unpack(t: table, i: number?, j: number?): ...
\`\`\`

Returns \`t\[i\]\` through \`t\[j\]\` (defaults \`i = 1\`, \`j = #t\`). Exposed as a \*\*global\*\* — mainline Luau only provides \`table.unpack\`. \`unpack\` and \`table.unpack\` are separate function objects but behave identically.

## Errors & protected calls

### assert

\`\`\`lua
function assert(value: any, message: string?, ...): ...
\`\`\`

Raises a catchable error (\`Matcha:<line>: <message>\`, or \`assertion failed!\` with no message) if \`value\` is falsy; otherwise returns its arguments unchanged — the way to raise a catchable error in Matcha.

### pcall

\`\`\`lua
function pcall(f: function, ...): (boolean, ...)
\`\`\`

Standard. Returns \`true\` plus \`f\`'s results on success, or \`false, "Matcha:<line>: <message>"\` on a runtime fault.

### xpcall

\`\`\`lua
function xpcall(f: function, handler: function, ...): (boolean, ...)
\`\`\`

Standard, and \*\*forwards extra arguments to \`f\`\*\* (Luau-style): \`xpcall(fn, handler, 3, 4)\` calls \`fn(3, 4)\`. On a real error, \`handler\` runs with the error message.

## Metatables

### setmetatable / getmetatable

\`\`\`lua
function setmetatable(t: table, mt: table?): table
function getmetatable(t: any): table | any
\`\`\`

Standard. \`getmetatable\` returns the \`\_\_metatable\` field when set; \`setmetatable\` on a table with a protected (\`\_\_metatable\`) metatable raises \`cannot change a protected metatable\`.

### newproxy

\`\`\`lua
function newproxy(addMetatable: boolean?): userdata
\`\`\`

Lua 5.1 holdover, fully supported. Returns a blank \`userdata\`; with \`newproxy(true)\` it gets a fresh, settable metatable (retrieved via \`getmetatable\`), so metamethods like \`\_\_index\` and \`\_\_tostring\` work.

## Raw access

### rawget / rawset / rawequal / rawlen

\`\`\`lua
function rawget(t: table, key: any): any
function rawset(t: table, key: any, value: any): table
function rawequal(a: any, b: any): boolean
function rawlen(t: table | string): number
\`\`\`

Standard. These bypass metamethods; \`rawset\` returns the table.

## Memory

### gcinfo

\`\`\`lua
function gcinfo(): number
\`\`\`

Returns the VM's current memory usage in kilobytes.

# Getting started

Source: https://doc.wabisabi.mom/ui-lib/

# Getting started

Wabi Sabi is a UI library for Matcha, rendered with the Drawing API. It draws entirely with the Drawing API and polls input itself, so it does not depend on Roblox ScreenGuis or events.

## Installation

\`\`\`lua
loadstring(game:HttpGet("https://scripts.wabisabi.mom/wabi-sabi-ui-lib.lua"))()
local Library = WabiSabi
\`\`\`

{% hint style="info" %}
The library is accessed through the global \`WabiSabi\`, not the return value of the \`loadstring\` call.
{% endhint %}

## Quick start

\`\`\`lua
loadstring(game:HttpGet("https://scripts.wabisabi.mom/wabi-sabi-ui-lib.lua"))()
local Library = WabiSabi

local Window = Library:CreateWindow({
    Title = "My Menu",
    SubTitle = "v1.0",
    Size = Vector2.new(580, 460),
    Resize = true,
})

local Main = Window:AddTab({ Title = "Main", Icon = "house" })

Main:AddToggle({ Id = "auto\_save", Title = "Auto save", Default = true, Callback = function(value)
    print("auto save", value)
end })

Main:AddSlider({ Id = "volume", Title = "Volume", Min = 0, Max = 100, Default = 50, Callback = function(value)
    print("volume", value)
end })

Library:Notify({ Title = "Loaded", Content = "Menu ready.", Duration = 4 })
\`\`\`

# Tabs and sections

\`\`\`lua
local Tab = Window:AddTab({ Title = "Controls", Icon = "sliders-horizontal" })
\`\`\`

\`Icon\` is optional. It accepts a \[Lucide\](https://lucide.dev/icons) icon name (\`"house"\`), a Phosphor icon in the form \`"phosphor-<name>-<weight>"\` (\`"phosphor-users-bold"\`), or a direct image URL (\`"https://..."\`). Icons are loaded asynchronously.

Sections group elements under a header:

\`\`\`lua
local Audio = Tab:AddSection("Audio")
Audio:AddToggle({ ... })
Audio:AddSlider({ ... })

local Display = Tab:AddSection("Display")
Display:AddToggle({ ... })
\`\`\`

\`AddSection\` returns a section object that owns its elements; add to the section, not the tab. Elements added directly to a tab before any section appear above the first header.

# Elements

Source: https://doc.wabisabi.mom/ui-lib/controls/

# Elements

Wabi Sabi ships eight elements. Jump to any of them:

::: cards
\[\*\*Button\*\* Run an action on click\](#button)

\[\*\*Toggle\*\* On/off state, optional keybind\](#toggle)

\[\*\*Slider\*\* A number within a range\](#slider)

\[\*\*Dropdown\*\* Single or multi-select\](#dropdown)

\[\*\*Keybind\*\* Bind a key, three modes\](#keybind)

\[\*\*Colorpicker\*\* A colour, optional alpha\](#colorpicker)

\[\*\*Input\*\* Free text or numeric\](#input)

\[\*\*Paragraph\*\* A static text block\](#paragraph)
:::

## Element basics

Every element accepts these common keys:

| Key | Description |
|---|---|
| \`Id\` (or \`Flag\`) | Registers the element in \`Library.Options\` for save and load. |
| \`Title\` | Element label. |
| \`Description\` | Optional secondary line beneath the title. |
| \`Icon\` | Optional Lucide or Phosphor icon name. |

\*\*Values.\*\* Every element returns a handle. \`handle.Value\` reads the current value, and assigning \`handle.Value = x\` applies it. \`handle:Get()\` is equivalent to reading \`.Value\`, and \`handle:SetValue(x)\` sets it explicitly.

\*\*Change notifications.\*\* \`Callback\` runs on every change. \`handle:OnChanged(fn)\` registers a listener and additionally invokes it once with the current value.

\*\*Mutation.\*\* \`handle:SetTitle(text)\` and \`handle:SetDescription(text)\` update the label and secondary line live; assigning \`handle.Title\` or \`handle.Description\` does the same. \`handle:Destroy()\` removes the element from the interface.

\*\*Error handling.\*\* Callbacks are invoked through \`Library:SafeCallback\`. An error raised inside a callback is reported as a notification and does not interrupt the interface.

## Button

\`\`\`lua
Tab:AddButton({ Title = "Apply", Description = "Apply changes", Callback = function() end })

| Key | Type | Description |
|---|---|---|

## Toggle

|---|---|---|---|
| \`Default\` | boolean | \`false\` | Initial state. |
| \`Keybind\` | string \\| table | \`nil\` | Optional key that toggles the element, shown as an inline chip. Pass a table \`{ Default = "F1", Mode = "Hold" }\` to also set its mode. |
| \`Callback\` | \`function(value)\` | | Runs on change. |

Handle: \`t.Value\`, \`t:Get()\`, \`t:SetValue(boolean)\`, \`t:OnChanged(fn)\`, \`t.keybind\` (when a \`Keybind\` is set).

## Slider

\`\`\`lua

## Dropdown

\`\`\`lua
local d = Tab:AddDropdown({ Id = "quality", Title = "Quality", Values = { "Low", "Medium", "High" }, Default = "Medium", Callback = function(value) end })
\`\`\`

| \`Multi\` | boolean | \`false\` | Enables multi-selection. |

For single-selection, \`Value\` is the selected option. For multi-selection, \`Value\` is a set keyed by option:

## Keybind

\`\`\`lua
local k = Tab:AddKeybind({ Id = "ptt", Title = "Push to talk", Default = "V", Mode = "Hold", Callback = function(state) end })
\`\`\`

| Key | Type | Default | Description |
|---|---|---|---|
| \`Default\` | string \\| number | \`nil\` | Key name or virtual-key number. |
| \`Mode\` | string | \`"Toggle"\` | One of \`"Always"\`, \`"Toggle"\`, \`"Hold"\`. |
| \`Callback\` | \`function(state)\` | | Runs when the bind is pressed. |
| \`ChangedCallback\` | \`function(keyName)\` | | Runs when the bound key changes. |

Modes:

| Mode | Behavior |
|---|---|
| \`Always\` | \`GetState()\` always returns \`true\`. |
| \`Toggle\` | Each press flips a latched state; \`Callback\` receives the new state. |
| \`Hold\` | \`GetState()\` returns \`true\` while the key is held. |

Handle: \`k.Value\` (bound key name), \`k:GetState()\`, \`k.mode\`, \`k.toggled\`, \`k:SetValue(key, mode)\`, \`k:OnClick(fn)\`, \`k:DoClick()\`, \`k:OnChanged(fn)\`.

\`\`\`lua
task.spawn(function()
    while not Library.Unloaded do
        if k:GetState() then
            -- key is held this frame
        end
        task.wait()
    end
end)
\`\`\`

Accepted key names: \`"A"\`–\`"Z"\`, \`"0"\`–\`"9"\`, \`"F1"\`–\`"F12"\`, \`"LeftControl"\` / \`"Ctrl"\`, \`"Shift"\`, \`"Alt"\`, \`"Space"\`, \`"End"\`, the arrow keys, \`"MB1"\`, \`"MB2"\`, \`"Mouse4"\`, \`"Mouse5"\`. To rebind, click the field and press a key or mouse button; \`Esc\` cancels and \`Delete\` clears the bind. Keybinds remain active while the interface is minimized.

# Configuration

Elements with an \`Id\` are registered in \`Library.Options\` and included in saved configurations.

| Method | Description |
|---|---|
| \`Library:SaveConfig(name)\` | Writes the current values to \`WabiSabi/<name>.json\`. |
| \`Library:LoadConfig(name)\` | Loads values from a saved configuration. |
| \`Library:GetConfigs()\` | Returns an array of saved configuration names. |
| \`Library:SetAutoload(name)\` | Marks a configuration to load on startup. |
| \`Library:LoadAutoloadConfig()\` | Loads the configuration marked for autoload. |
| \`Library:SetFolder(name)\` | Sets the folder configurations are stored under (default \`WabiSabi\`). Accepts nested paths. |
| \`Library:SetIgnoreIndexes(list)\` | Excludes the listed element \`Id\`s from saved configurations. |

Saved value types: toggle, slider, input, dropdown, colorpicker, and keybind.

A complete manager UI is available without manual wiring:

\`\`\`lua
local Settings = Window:AddTab({ Title = "Settings", Icon = "settings" })
Window:BuildInterfaceSection(Settings)
Window:BuildConfigSection(Settings)
Library:LoadAutoloadConfig()
\`\`\`

To read individual values back out, see \[Reading values\](/ui-lib/reading-values).

# Notes

Source: https://doc.wabisabi.mom/ui-lib/notes/

# Notes from the dev

- I was trying to replicate the Acrylic blur that most Roblox UI libs have, but Matcha provides no framebuffer access. The \`Translucent\` option is the closest equivalent I've managed, looks-wise.
- The render loop is internal. Scripts should poll element state (for example, in a \`task.spawn\` loop) and exit when \`Library.Unloaded\` is \`true\`.

Notifications [#](https://doc.wabisabi.mom/ui-lib/notifications/#notifications)

luaCopy

    Library:Notify({ Title = "Saved", Content = "Configuration saved.", SubContent = "slot 1", Duration = 4 })
    

| Key | Type | Description |

| `Content` | string | Body text. `\n` is supported. |

Dialogs [#](https://doc.wabisabi.mom/ui-lib/notifications/#dialogs)

--------------------------------------------------------------------

luaCopy

    Window:Dialog({

        Content = "Are you sure?",
        Buttons = {
            { Title = "Yes", Callback = function() end },
            { Title = "No",  Callback = function() end },
        },
    })
    

| Key | Type | Description |
| --- | --- | --- |
| `Title` | string | Header text. |
| `Content` | string | Body text. `\n` is supported. |
| `Buttons` | array | Entries of `{ Title, Callback }`. The first button is accented. |
| `Yield` | boolean | Blocks the caller until the dialog closes. Call from the main thread, not from within a callback. |

A dialog is modal and blocks interaction with the menu until it is dismissed. `Window:Dialog` returns a handle with `:Close()` to dismiss it programmatically, and `:OnClosing(fn)` / `:OnClosed(fn)` to react to dismissal.

# Elements · UI Library docs

[UI Library](https://doc.wabisabi.mom/ui-lib/)
 / Guide / Elements

Elements [#](https://doc.wabisabi.mom/ui-lib/controls/#elements)

=================================================================

Wabi Sabi ships eight elements. Jump to any of them:

[**Button** Run an action on click](https://doc.wabisabi.mom/ui-lib/controls/#button)

[**Toggle** On/off state, optional keybind](https://doc.wabisabi.mom/ui-lib/controls/#toggle)

[**Slider** A number within a range](https://doc.wabisabi.mom/ui-lib/controls/#slider)

[**Dropdown** Single or multi-select](https://doc.wabisabi.mom/ui-lib/controls/#dropdown)

[**Keybind** Bind a key, three modes](https://doc.wabisabi.mom/ui-lib/controls/#keybind)

[**Colorpicker** A colour, optional alpha](https://doc.wabisabi.mom/ui-lib/controls/#colorpicker)

[**Input** Free text or numeric](https://doc.wabisabi.mom/ui-lib/controls/#input)

[**Paragraph** A static text block](https://doc.wabisabi.mom/ui-lib/controls/#paragraph)

Element basics [#](https://doc.wabisabi.mom/ui-lib/controls/#element-basics)

-----------------------------------------------------------------------------

Every element accepts these common keys:

| Key | Description |
| --- | --- |
| `Id` (or `Flag`) | Registers the element in `Library.Options` for save and load. |
| `Title` | Element label. |
| `Description` | Optional secondary line beneath the title. |
| `Icon` | Optional Lucide or Phosphor icon name. |

**Values.** Every element returns a handle. `handle.Value` reads the current value, and assigning `handle.Value = x` applies it. `handle:Get()` is equivalent to reading `.Value`, and `handle:SetValue(x)` sets it explicitly.

**Change notifications.** `Callback` runs on every change. `handle:OnChanged(fn)` registers a listener and additionally invokes it once with the current value.

**Mutation.** `handle:SetTitle(text)` and `handle:SetDescription(text)` update the label and secondary line live; assigning `handle.Title` or `handle.Description` does the same. `handle:Destroy()` removes the element from the interface.

**Error handling.** Callbacks are invoked through `Library:SafeCallback`. An error raised inside a callback is reported as a notification and does not interrupt the interface.

Button [#](https://doc.wabisabi.mom/ui-lib/controls/#button)

-------------------------------------------------------------

luaCopy

    Tab:AddButton({ Title = "Apply", Description = "Apply changes", Callback = function() end })
    

| Key | Type | Description |
| --- | --- | --- |
| `Callback` | `function()` | Runs when clicked. |

Toggle [#](https://doc.wabisabi.mom/ui-lib/controls/#toggle)

-------------------------------------------------------------

luaCopy

    local t = Tab:AddToggle({ Id = "auto_save", Title = "Auto save", Default = false, Keybind = "F1", Callback = function(value) end })
    

| Key | Type | Default | Description |
| --- | --- | --- | --- |
| `Default` | boolean | `false` | Initial state. |
| `Keybind` | string \| table | `nil` | Optional key that toggles the element, shown as an inline chip. Pass a table `{ Default = "F1", Mode = "Hold" }` to also set its mode. |
| `Callback` | `function(value)` |     | Runs on change. |

Handle: `t.Value`, `t:Get()`, `t:SetValue(boolean)`, `t:OnChanged(fn)`, `t.keybind` (when a `Keybind` is set).

Slider [#](https://doc.wabisabi.mom/ui-lib/controls/#slider)

-------------------------------------------------------------

luaCopy

    local s = Tab:AddSlider({ Id = "volume", Title = "Volume", Min = 0, Max = 100, Default = 50, Rounding = 0, Callback = function(value, oldValue) end })
    

| Key | Type | Default | Description |
| --- | --- | --- | --- |
| `Min` | number | `0` | Minimum value. |
| `Max` | number | `100` | Maximum value. |
| `Default` | number | `Min` | Initial value. |
| `Rounding` | integer | `0` | Decimal places. |
| `Callback` | `function(value, oldValue)` |     | Runs on change. |

Handle: `s.Value`, `s:Get()`, `s:SetValue(number)`, `s:OnChanged(fn)`.

The displayed value is editable: click it to type a value directly.

Dropdown [#](https://doc.wabisabi.mom/ui-lib/controls/#dropdown)

-----------------------------------------------------------------

luaCopy

    local d = Tab:AddDropdown({ Id = "quality", Title = "Quality", Values = { "Low", "Medium", "High" }, Default = "Medium", Callback = function(value) end })
    

| Key | Type | Default | Description |
| --- | --- | --- | --- |
| `Options` (or `Values`) | array | `{ "None" }` | Available choices. Any value type is accepted. |
| `Multi` | boolean | `false` | Enables multi-selection. |
| `Default` | value \| index \| array | first option | Initial selection. A number is treated as an index; an array sets multiple defaults. |
| `MaxItems` | integer | `6` | Visible rows before the list scrolls. |
| `Searchable` | boolean | `false` | Adds a search field to filter options. |
| `SearchPlaceholder` | string | `"Search..."` | Placeholder text for the search field. |
| `Displayer` | `function(value) -> string` | `tostring` | Customizes how each option is displayed. |
| `AllowNull` | boolean | `false` | Allows a single-selection dropdown to clear to `nil`. |
| `Callback` | `function(value)` |     | Runs on change. |

Handle: `d.Value`, `d:Get()`, `d:SetValue(value)`, `d:SetValues(list)`, `d:OnChanged(fn)`.

For single-selection, `Value` is the selected option. For multi-selection, `Value` is a set keyed by option:

luaCopy

    for option in pairs(d.Value) do
        print(option)
    end
    

Keybind [#](https://doc.wabisabi.mom/ui-lib/controls/#keybind)

---------------------------------------------------------------

luaCopy

    local k = Tab:AddKeybind({ Id = "ptt", Title = "Push to talk", Default = "V", Mode = "Hold", Callback = function(state) end })
    

| Key | Type | Default | Description |
| --- | --- | --- | --- |
| `Default` | string \| number | `nil` | Key name or virtual-key number. |
| `Mode` | string | `"Toggle"` | One of `"Always"`, `"Toggle"`, `"Hold"`. |
| `Callback` | `function(state)` |     | Runs when the bind is pressed. |
| `ChangedCallback` | `function(keyName)` |     | Runs when the bound key changes. |

Modes:

| Mode | Behavior |
| --- | --- |
| `Always` | `GetState()` always returns `true`. |
| `Toggle` | Each press flips a latched state; `Callback` receives the new state. |
| `Hold` | `GetState()` returns `true` while the key is held. |

Handle: `k.Value` (bound key name), `k:GetState()`, `k.mode`, `k.toggled`, `k:SetValue(key, mode)`, `k:OnClick(fn)`, `k:DoClick()`, `k:OnChanged(fn)`.

luaCopy

    task.spawn(function()
        while not Library.Unloaded do
            if k:GetState() then
                -- key is held this frame
            end
            task.wait()
        end
    end)
    

Accepted key names: `"A"`–`"Z"`, `"0"`–`"9"`, `"F1"`–`"F12"`, `"LeftControl"` / `"Ctrl"`, `"Shift"`, `"Alt"`, `"Space"`, `"End"`, the arrow keys, `"MB1"`, `"MB2"`, `"Mouse4"`, `"Mouse5"`. To rebind, click the field and press a key or mouse button; `Esc` cancels and `Delete` clears the bind. Keybinds remain active while the interface is minimized.

Colorpicker [#](https://doc.wabisabi.mom/ui-lib/controls/#colorpicker)

-----------------------------------------------------------------------

luaCopy

    local c = Tab:AddColorpicker({ Id = "accent", Title = "Accent", Default = Color3.fromRGB(96, 205, 255), Transparency = 0, Callback = function(color) end })
    

| Key | Type | Default | Description |
| --- | --- | --- | --- |
| `Default` | Color3 | white | Initial color. |
| `Transparency` | number | `nil` | Setting a value (0–1) enables an alpha channel. |
| `UpdateOnChange` | boolean | `false` | Fire `Callback` live while dragging. By default it fires only when the picker is closed with Done. |
| `Callback` | `function(color)` |     | Runs on change. |

Handle: `c.Value` (Color3), `c:Get()`, `c.alpha` (0–1), `c:SetValue(color)`, `c:SetValueRGB(color, transparency)`, `c:OnChanged(fn)`.

The picker provides a saturation/value field, a hue bar, an optional alpha bar, hex and RGB fields, and Cancel/Done actions.

Input [#](https://doc.wabisabi.mom/ui-lib/controls/#input)

-----------------------------------------------------------

luaCopy

    local i = Tab:AddInput({ Id = "username", Title = "Username", Default = "", Placeholder = "type...", Callback = function(text) end })
    

| Key | Type | Default | Description |
| --- | --- | --- | --- |
| `Default` | string | `""` | Initial text. |
| `Placeholder` | string | `""` | Placeholder shown when empty. |
| `Numeric` | boolean | `false` | Restricts input to numbers. |
| `Finished` | boolean | `false` | Runs `Callback` only when Enter is pressed. |
| `MaxLength` | integer | `nil` | Maximum character count. |
| `ClearOnFocusLost` | boolean | `false` | Clears the field after a `Finished` commit. |
| `Callback` | `function(text)` |     | Runs on change, or on Enter when `Finished`. |

Handle: `i.Value` (text), `i:Get()`, `i:SetValue(text)`, `i:OnChanged(fn)`.

Text fields support standard editing: click or drag to place the caret and select, double-click to select a word, arrow keys / Home / End to navigate, Ctrl+A to select all, and Ctrl+C / Ctrl+X to copy and cut.

Paragraph [#](https://doc.wabisabi.mom/ui-lib/controls/#paragraph)

| `TitleAlignment` | string | `"Left"`, `"Center"`, or `"Right"`. |
| `ContentAlignment` | string | `"Left"`, `"Center"`, or `"Right"`. |

Configuration [#](https://doc.wabisabi.mom/ui-lib/config/#configuration)

=========================================================================

Elements with an `Id` are registered in `Library.Options` and included in saved configurations.

| Method | Description |
| --- | --- |
| `Library:SaveConfig(name)` | Writes the current values to `WabiSabi/<name>.json`. |
| `Library:LoadConfig(name)` | Loads values from a saved configuration. |

| `Library:SetFolder(name)` | Sets the folder configurations are stored under (default `WabiSabi`). Accepts nested paths. |
| `Library:SetIgnoreIndexes(list)` | Excludes the listed element `Id`s from saved configurations. |

Saved value types: toggle, slider, input, dropdown, colorpicker, and keybind.

A complete manager UI is available without manual wiring:

luaCopy

                l:SetDescription("Retrying...")

            Title = "Cancel & Close",
            Variant = "Secondary",
            Order = 2,
            Callback = function(l)

    task.spawn(function()
        local steps = {
            "Downloading asset packages...",
            "Validating game memory offsets...",
            "Building user interface...",
            "Initialization complete!",
        }
    
        for stepIndex, description in ipairs(steps) do
            loading:SetDescription(description)
            loading:SetCurrentStep(stepIndex)
            task.wait(0.4)
        end
    
        loading:Continue()
    end)
