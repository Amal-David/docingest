 Levels Plugin ![MEE6-Premium](https://i.ibb.co/PtWdPbq/MEE6-Premium-4.png)
======================================================================================================================================

**The Leveling Plugin introduces an engaging leveling system for your Discord server. Users can earn XP simply by chatting and being active in the community.**

[¶](https://wiki.mee6.xyz/en/plugins/levels#setting-up-the-leveling-system)
 Setting Up The Leveling System
-----------------------------------------------------------------------------------------------------------

To begin your setup, go to the [MEE6 Dashboard,](https://mee6.xyz/dashboard)
 select your server, and navigate to the [Levels Plugin.](https://mee6.xyz/dashboard?redirect=/levels)

[¶](https://wiki.mee6.xyz/en/plugins/levels#the-level-up-channel)
 The Level Up Channel
---------------------------------------------------------------------------------------

In the plugin, find the "Level up announcement" section where you can choose how MEE6 alerts users about leveling up:

*   **Disabled:** MEE6 will not send a level-up message.
    
*   **Current Channel:** MEE6 will send the level-up message in the chat where the user has leveled up.
    
*   **Private Message:** MEE6 will DM the user the level-up message.
    
*   **Custom Channel:** Set a specific channel for all level-up notifications.
    

If you choose "Custom Channel," a new section named "Announcement Channel" will appear. Specify the channel where you want the level-up notifications to be posted.

[¶](https://wiki.mee6.xyz/en/plugins/levels#level-up-message)
 Level Up Message
-------------------------------------------------------------------------------

Customize the level-up message in the "Level Up Announcement Message" section.

[¶](https://wiki.mee6.xyz/en/plugins/levels#role-rewards)
 Role Rewards
-----------------------------------------------------------------------

Set reward roles for users when they reach certain levels:

*   **Stack previous rewards:** Users will keep all reward roles, and they won't be removed upon leveling up.
    
*   **Remove previous rewards:** Previous reward roles will be removed from users once they reach a new reward role.
    

Configure role rewards in the "Role Rewards" section. Select the role and set the level at which the user should receive it.

Additionally, the "Remove role reward after member loses XP" section allows for the removal of reward roles if a user's level is reset or their XP is manually taken away using the **/remove-xp** command.

[¶](https://wiki.mee6.xyz/en/plugins/levels#default-rank-card)
 Default Rank Card
---------------------------------------------------------------------------------

Customize the default rank card displayed in your server when using **/rank**:

**Non-Premium Servers:** Set multiple colors for the rank card background from preset colors or the custom color creator.

**Premium Servers:** Set background colors, choose premade backgrounds, or upload your own.

[¶](https://wiki.mee6.xyz/en/plugins/levels#xp-rate)
 XP Rate
-------------------------------------------------------------

Adjust the XP rate to change the difficulty of leveling. Drag the point to set the desired rate. This section also allows you to disable the ability to give [MEE6 Pro](https://wiki.mee6.xyz/en/pro)
 subscribers extra XP.

[¶](https://wiki.mee6.xyz/en/plugins/levels#no-xp-roles)
 No XP Roles
---------------------------------------------------------------------

Add roles to the "No XP Roles" section to prevent users from gaining XP and leveling up.

[¶](https://wiki.mee6.xyz/en/plugins/levels#no-xp-channels)
 No XP Channels
---------------------------------------------------------------------------

Specify channels in the "No XP Channels" section where users won't earn XP.

[¶](https://wiki.mee6.xyz/en/plugins/levels#additional-information)
 Additional Information
-------------------------------------------------------------------------------------------

*   Each time you send a message, you get a random number of XP between 15 and 25.
    
*   To avoid flooding, you can only gain XP once per minute.
    

[¶](https://wiki.mee6.xyz/en/plugins/levels#commands)
 Commands
---------------------------------------------------------------

Below is a table listing the level commands available in the MEE6 bot, along with their argument options:

| Command | Description | Arguments |
| --- | --- | --- |
| `/give-xp` | Give XP to a member | `@member` (Mention), `xp_amount` (Number) |
| `/remove-xp` | Remove XP from a member | `@member` (Mention), `xp_amount` (Number) |
| `/levels` | Get a link to the leaderboard |     |
| `/rank` | Get your rank or another members rank | `@member` (Mention, optional) |

 Getting Started With MEE6
==================================================================================================

**Welcome to MEE6, your all-in-one Discord bot that provides everything you need to manage and grow your server. This guide will walk you through the basics of setting up and using MEE6.**

[¶](https://wiki.mee6.xyz/en/getting-started#adding-mee6-to-your-server)
 Adding MEE6 To Your Server
----------------------------------------------------------------------------------------------------

To start using MEE6, follow these steps:

*   Visit the [MEE6 Website.](https://mee6.xyz/)
    
*   Click the ''Add to Discord'' button.
    
*   Log in to your Discord account if you’re not already logged in.
    
*   Select the server where you want to add MEE6.
    
*   Click ''Authorize'' and verify that you're not a robot if prompted.
    
*   MEE6 is now added to your server.
    

> ![MEE6-NEW](https://i.ibb.co/hV8LWtn/MEE6Info.png)**Important Information**  
> You must have **''Manage Server''** permissions in the server where you are adding the bot.

[¶](https://wiki.mee6.xyz/en/getting-started#configuring-mee6)
 Configuring MEE6
--------------------------------------------------------------------------------

Once MEE6 is added, you can configure it:

*   Visit the [MEE6 Dashboard.](https://mee6.xyz/dashboard)
    
*   Select your server from the list.
*   Browse the MEE6 features on the left side. Click on each feature to customize its settings.

[¶](https://wiki.mee6.xyz/en/getting-started#understanding-roles-and-permissions)
 Understanding Roles and Permissions
----------------------------------------------------------------------------------------------------------------------

Roles define member permissions. With MEE6, you can assign roles based on actions like leveling up or reacting to a message.

Example: To set up reaction roles:

*   Go to the Reaction Roles section in the dashboard.
    
*   Click ''Add Reaction Role'' and choose the message users will react to.
    
*   Select the reaction and the role to be assigned.
    
*   Click ''Save.''
    

[¶](https://wiki.mee6.xyz/en/getting-started#exploring-mee6-features)
 Exploring MEE6 Features
----------------------------------------------------------------------------------------------

MEE6 offers many features to enhance your server. Here are a few to explore:

*   **[Moderation:](https://wiki.mee6.xyz/plugins/moderator)
    ** Automate moderation tasks to maintain a healthy environment.
    
*   **[Leveling:](https://wiki.mee6.xyz/plugins/levels)
    ** Create a leaderboard and role rewards based on activity.
    
*   **[Custom Commands:](https://wiki.mee6.xyz/plugins/custom-commands)
    ** Set up custom commands and auto-responses.
    
*   **[Search Anything:](https://wiki.mee6.xyz/plugins/search-anything)
    ** Search the web for images, GIFs, and more directly from Discord.
    
*   **[MEE6 AI:](https://mee6.xyz/en/ai)
    ** Use MEE6 AI to engage users with intelligent responses and automate common replies.
    

MEE6 is designed to make managing your server easier. Experiment with different features to see what works best for your community.
