Flowstep generates production-ready UI screens from plain text prompts. Describe the screen you want — get a designed interface back in seconds. Iterate through follow-up prompts or direct edits, export to Figma or image files, and share with your team via a single link. For developers and technical designers, Flowstep also runs as an [MCP server](https://docs.flowstep.ai/mcp/overview)
 — generate and edit screens directly from Cursor, Claude Code, Windsurf, or Claude Desktop without leaving your IDE.

# فوترة Flowstep: الدورات والإلغاء والوصول - Flowstep

[الانتقال إلى المحتوى الرئيسي](https://docs.flowstep.ai/ar/billing#content-area)

يمنحك Flowstep السيطرة على كيفية ودوقت دفعك. يمكنك اختيار الفوترة الشهرية أو السنوية عند الاشتراك، ويمكنك الإلغاء في أي وقت دون فقدان الوصول لبقية فترة الفوترة.

[​](https://docs.flowstep.ai/ar/billing#%D9%85%D9%86-%D9%8A%D9%85%D9%83%D9%86%D9%87-%D8%A5%D8%AF%D8%A7%D8%B1%D8%A9-%D8%A7%D9%84%D9%81%D9%88%D8%AA%D8%B1%D8%A9)

من يمكنه إدارة الفوترة
----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

في مؤسسة ما، فقط **Owner** (صاحب المؤسسة) — الشخص الذي أنشأ المؤسسة — يمكنه إدارة الفوترة. **Owner** هو الشخص الوحيد الذي يرى صفحة **Plan & Billing** في الإعدادات وأزرار **Upgrade** في التطبيق. يمكن للمسؤولين **Admins** إضافة وإزالة الأشخاص، لكنهم لا يستطيعون ترقية الخطة أو تخفيضها أو تغيير المقاعد أو إلغاء الاشتراك — تتم مزامنة تغييرات المقاعد مع الاشتراك فقط من خلال **Owner**. راجع [Organizations](https://docs.flowstep.ai/ar/organizations)
 للاطلاع على التفصيل الكامل للأدوار.

[​](https://docs.flowstep.ai/ar/billing#%D8%AF%D9%88%D8%B1%D8%A7%D8%AA-%D8%A7%D9%84%D9%81%D9%88%D8%AA%D8%B1%D8%A9)

دورات الفوترة
-----------------------------------------------------------------------------------------------------------------------------------

عند الاشتراك في خطة Flowstep المدفوعة، تختار بين خيارين للفوترة:

*   **Monthly** — يتم فرض الرسوم عليك مرة واحدة شهريًا في تاريخ الفوترة.
*   **Annual** — يتم فرض الرسوم عليك مرة واحدة سنويًا. يتم فوترتك للسنة الكاملة مقدمًا في بداية فترة الفوترة.

يتم فوترة الخطط المدفوعة لكل مقعد: إجمالي الخاص بك هو سعر الخطة لكل مقعد مضروبًا في عدد المقاعد — واحد لكل **Owner** و**Admin** و**Member** في مؤسستك. الضيوف **Guests** مجانيون ولا يتم احتسابهم. إضافة أشخاص في منتصف الدورة يتم حسابها بشكل تناسبي، لذا تدفع فقط عن بقية الفترة. راجع [Seats](https://docs.flowstep.ai/ar/seats)
 للتفاصيل. تسري ترقيات الخطة فورًا، بينما يسري التخفيضات في نهاية فترة الفوترة الحالية.

اختيار الفوترة السنوية يوفر لك ما يصل إلى 20% مقارنة بالدفع شهريًا. إذا كنت تخطط لاستخدام Flowstep بانتظام، فإن الخطة السنوية هي الخيار الأكثر فعالية من حيث التكلفة.

[​](https://docs.flowstep.ai/ar/billing#%D8%A5%D8%AF%D8%A7%D8%B1%D8%A9-%D8%A7%D8%B4%D8%AA%D8%B1%D8%A7%D9%83%D9%83)

إدارة اشتراكك
-----------------------------------------------------------------------------------------------------------------------------------

يدير **Owner** الاشتراك من **Settings → Plan & Billing**. على المستوى المجاني أو فترة تجريبية، تعرض الصفحة زر **Upgrade** يفتح منتقي الخطة. على خطة مدفوعة، تعرض زر **Manage** بدلاً من ذلك، والذي يفتح بوابة الفوترة حيث تدير تفاصيل الدفع والاشتراك.

[​](https://docs.flowstep.ai/ar/billing#%D8%A7%D9%84%D8%A5%D9%84%D8%BA%D8%A7%D8%A1)

الإلغاء
----------------------------------------------------------------------------------------------

يمكنك إلغاء اشتراك Flowstep في أي وقت — لا توجد رسوم إلغاء أو فترات قفل. للإلغاء، يفتح **Owner** بوابة الفوترة عبر **Manage** في صفحة **Plan & Billing**. يتلقى **Owner** بريدًا إلكترونيًا يؤكد الإلغاء والتاريخ الذي ينفذ فيه.

عند الإلغاء، لا ينتهي اشتراكك فورًا. تحتفظ بإمكانية الوصول الكاملة إلى ميزات خطتك والرسائل المتبقية حتى نهاية فترة الفوترة الحالية. بعد ذلك، تنتقل مؤسستك إلى خطة Free مع مقعد واحد — يحتفظ **Owner** بإمكانية الوصول للتحرير، وأي أعضاء آخرين يصبحون بإمكانية القراءة فقط حتى تقوم بالترقية مرة أخرى.

[​](https://docs.flowstep.ai/ar/billing#%D8%A7%D9%84%D9%81%D9%88%D8%A7%D8%AA%D9%8A%D8%B1)

الفواتير
-----------------------------------------------------------------------------------------------------

بعد كل دورة فوترة، يقوم Flowstep تلقائيًا بإنشاء فاتورة لدفعتك. يمكنك تنزيل الفواتير السابقة في أي وقت من خلال بوابة الفوترة. راجع [Invoices](https://docs.flowstep.ai/ar/invoices)
 للحصول على التعليمات.

[الانتقال إلى المحتوى الرئيسي](https://docs.flowstep.ai/ar/data-privacy#content-area)

بيانات تنتمي إليك. لا يستخدم Flowstep بياناتك الشخصية لتدريب نماذج الذكاء الاصطناعي، وموفرو نماذج اللغة الكبيرة (LLM) الذين يشغلون ميزات الذكاء الاصطناعي في Flowstep ممنوعون تعاقديًا من استخدام بياناتك لأغراض التدريب أيضًا. ينطبق هذا على كل شيء تنشئه أو تحمّله أو تتفاعل معه داخل Flowstep.

[​](https://docs.flowstep.ai/ar/data-privacy#%D9%85%D8%A7-%D9%84%D8%A7-%D9%8A%D9%81%D8%B9%D9%84%D9%87-flowstep)

ما لا يفعله Flowstep
---------------------------------------------------------------------------------------------------------------------------------------

*   لا يُدخِل Flowstep تصاميمك أو الموجّهات أو محتوى المشروع في تدريب نماذج الذكاء الاصطناعي.
*   موفرو نماذج اللغة الكبيرة (LLM) في Flowstep غير مسموح لهم باستخدام بياناتك لتدريب نماذجهم أو ضبطها بدقة.

[​](https://docs.flowstep.ai/ar/data-privacy#%D8%A7%D9%84%D8%AA%D8%B9%D9%84%D9%8A%D9%82%D8%A7%D8%AA-%D8%A7%D9%84%D9%85%D8%AC%D9%85%D9%91%D8%B9%D8%A9-%D9%88%D8%A7%D9%84%D9%85%D8%AC%D9%87%D9%91%D9%84%D8%A9-%D8%A7%D9%84%D9%87%D9%88%D9%8A%D8%A9)

التعليقات المجمّعة والمجهّلة الهوية
----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

قد يستخدم Flowstep التعليقات المجمّعة والمجهّلة الهوية لتحسين جودة مخرجات الذكاء الاصطناعي. لا يمكن تتبع هذه البيانات إليك أو إلى مشاريعك — فهي لا تحتوي على معلومات التعريف الشخصية ولا محتوى خام من عملك.

يساعد هذا الاستخدام المحدود للتعليقات المجهّلة Flowstep على جعل ميزات الذكاء الاصطناعي الخاصة بها أكثر دقة وفائدة للجميع، دون المساس بخصوصيتك.

[​](https://docs.flowstep.ai/ar/data-privacy#%D8%A5%D8%B0%D8%A7-%D8%AA%D8%BA%D9%8A%D9%91%D8%B1-%D8%A7%D9%84%D9%86%D9%87%D8%AC)

إذا تغيّر النهج
-------------------------------------------------------------------------------------------------------------------------------------------------

إذا تغيّرت ممارسات Flowstep المتعلقة بالبيانات في أي وقت، ستعرف ذلك. سيقوم Flowstep بتحديث سياسة الخصوصية الخاصة به وإخطار المستخدمين قبل أن تصبح أي استخدامات بيانات جديدة سارية المفعول. لن تفاجأ بالتغييرات في كيفية التعامل مع بياناتك.

[​](https://docs.flowstep.ai/ar/data-privacy#%D8%A3%D8%B3%D8%A6%D9%84%D8%A9-%D8%AD%D9%88%D9%84-%D8%A7%D9%84%D8%AE%D8%B5%D9%88%D8%B5%D9%8A%D8%A9)

أسئلة حول الخصوصية
----------------------------------------------------------------------------------------------------------------------------------------------------------------------

إذا كان لديك أسئلة حول كيفية تعامل Flowstep مع بياناتك، تواصل مع الفريق على [hello@flowstep.ai](mailto:hello@flowstep.ai)
. يمكنك أيضًا مراجعة سياسة خصوصية Flowstep الكاملة على [flowstep.ai](https://flowstep.ai/)
 للحصول على تفاصيل كاملة.

حمّل مستند متطلبات المنتج لإعطاء Flowstep فهماً شاملاً لأهداف منتجك والميزات واحتياجات المستخدمين قبل إنشاء الشاشات.

استخدم مرجع مستند متطلبات المنتج عندما تقوم بتصميم ميزة لها متطلبات مكتوبة بالفعل. يقرأ Flowstep المستند ويستخدمه لاتخاذ قرارات تصميم تتوافق مع نية منتجك—مما يوفر عليك إعادة تكرار كل شيء في الموجّه.

### 

[​](https://docs.flowstep.ai/ar/design-references#%D8%AA%D8%AD%D9%85%D9%8A%D9%84-%D8%B5%D9%88%D8%B1%D8%A9)

تحميل صورة

أرفق لقطة شاشة أو رسمة أو لوحة ألوان أو أي صورة لإعطاء Flowstep مرجعاً بصرياً للأسلوب أو التخطيط الذي تفكر فيه.

استخدم مرجع الصورة عندما يكون لديك اتجاه بصري قوي في الاعتبار—مثل واجهة مستخدم منافس تريد الاستلهام منها، أو رسمة خطوط أولية رسمتها يدويّاً. يستخدم Flowstep الصورة كمصدر إلهام، وليس كنموذج دقيق للنسخ.

### 

[​](https://docs.flowstep.ai/ar/design-references#%D8%A7%D9%84%D8%B5%D9%82-%D8%B9%D9%86%D9%88%D8%A7%D9%86-url)

الصق عنوان URL

وفّر رابطاً لموقع ويب أو منتج مباشر أو أي صفحة ويب وسيستخدمها Flowstep كمرجع للأسلوب البصري أو الهيكل أو أنماط المحتوى.

استخدم مرجع URL عندما تريد المطابقة أو الاستلهام من منتج رقمي موجود. هذا مفيد بشكل خاص لأعمال إعادة التسمية البيضاء، أو تحليل المنافسين، أو عندما يقول صاحب المصلحة “اجعله يبدو مثل هذا.”

[​](https://docs.flowstep.ai/ar/design-references#%D8%A7%D9%84%D8%A5%D8%B1%D9%81%D8%A7%D9%82-%D8%B9%D9%86-%D8%B7%D8%B1%D9%8A%D9%82-%D8%A7%D9%84%D9%84%D8%B5%D9%82)

الإرفاق عن طريق اللصق
-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

الطريقة الأسرع لإرفاق مرجع غالباً ما تكون اللصق: لصق ملف أو صورة في إدخال الموجّه يرفقها تلقائياً. المرفقات المدعومة هي الصور (JPG, PNG, WEBP) والمستندات (PDF, MD, TXT)، حتى 3 ميجابايت لكل واحد. يعمل لصق نصوص طويلة أيضاً — يحتوي إدخال الموجّه على ما يصل إلى 6,000 حرف، ولصق النص عند هذا الحد أو تجاوزه يرفقه تلقائياً كملف يسمى `pasted.txt` (إذا كان الموجّه فارغاً، يتم ملؤه بـ “اتبع التعليمات في الملف”). مفيد جداً لتسليم Flowstep مواصفات طويلة دون تقليصها.

[​](https://docs.flowstep.ai/ar/design-references#%D9%84%D9%85%D8%A7%D8%B0%D8%A7-%D8%AA%D8%B3%D8%AA%D8%AE%D8%AF%D9%85-%D8%A7%D9%84%D9%85%D8%B1%D8%A7%D8%AC%D8%B9)

لماذا تستخدم المراجع
-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

تقلل المراجع من حجم التفاصيل التي تحتاج إلى تضمينها في موجهك. بدلاً من كتابة فقرة لشرح سياق منتجك أو اتجاهك البصري، يمكن لملف أو رابط واحد أن يوصله بشكل أكثر اكتمالاً. هذا يجعل عملية الإنشاء أسرع وغالباً ما ينتج عن نتائج أكثر صلة في المحاولة الأولى. يمكنك دمج المراجع—على سبيل المثال، إرفاق مستند متطلبات المنتج لسياق المنتج وصورة للإلهام البصري في نفس الوقت.

# عيّن إرشادات التصميم للحفاظ على كل جيل Flowstep متوافق مع الهوية البصرية - Flowstep

> Documentation Index
> -------------------
> 
> Fetch the complete documentation index at: [/llms.txt](https://docs.flowstep.ai/llms.txt)
> 
> Use this file to discover all available pages before exploring further.

[الانتقال إلى المحتوى الرئيسي](https://docs.flowstep.ai/ar/design-guidelines#content-area)

تتيح لك إرشادات التصميم تعيين قواعد ثابتة — الألوان والطباعة والمسافات واصطلاحات المكونات — التي يطبقها Flowstep على كل جيل وتعديل للذكاء الاصطناعي في الملف. بدلاً من تكرار «استخدم مظهرنا الأزرق» في كل موجّه، اكتبها مرة واحدة والذكاء الاصطناعي يتبعها من ثم فصاعداً.

[​](https://docs.flowstep.ai/ar/design-guidelines#%D8%B9%D8%AF%D9%91%D9%84-%D8%A5%D8%B1%D8%B4%D8%A7%D8%AF%D8%A7%D8%AA-%D8%A7%D9%84%D8%AA%D8%B5%D9%85%D9%8A%D9%85)

عدّل إرشادات التصميم
-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

1

افتح نافذة إرشادات التصميم

في رأس لوحة الدردشة، انقر فوق زر **Edit design guidelines** (تحرير إرشادات التصميم). تُفتح نافذة **Design guidelines** (إرشادات التصميم) مع محرر نصوص `DESIGN.md`.

2

اكتب أو استورد إرشاداتك

اكتب إرشاداتك مباشرة، أو اسحب وأفلت ملف `.md` في المحرر لاستيراده. يتبع التنسيق معيار `design.md` المفتوح من Google — مقدمة YAML اختيارية (المفاتيح المعترف بها: `version`, `name`, `description`, `colors`, `typography`, `rounded`, `spacing`, `components`) متبوعة بأقسام Markdown.

3

احفظ

انقر فوق **Save changes** (حفظ التغييرات). من الآن فصاعداً، كل جيل وتعديل في هذا الملف يستخدم إرشاداتك كسياق إجباري.

تنطبق الإرشادات على **future output only** (المخرجات المستقبلية فقط) — البيانات التصميم الموجودة تبقى كما هي. يتم تحديد نطاقها بالملف الحالي ولا تُنقل إلى ملفات أخرى.

[​](https://docs.flowstep.ai/ar/design-guidelines#%D9%85%D8%A7-%D8%A7%D9%84%D8%B0%D9%8A-%D8%AA%D8%AD%D8%AA%D8%A7%D8%AC-%D9%85%D8%B9%D8%B1%D9%81%D8%AA%D9%87)

ما الذي تحتاج معرفته
------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

*   **حد الطول** — يمكن للإرشادات أن تصل إلى 50,000 حرف. الملفات المستوردة التي تتجاوز ذلك يتم اقتطاعها.
*   **التحقق** — الأخطاء الهيكلية (مقدمة YAML غير مغلقة، عناوين أقسام `##` مكررة) تمنع الحفظ. المشاكل الأخف، مثل مفاتيح YAML غير معترف بها أو الألوان التي ليست رموز hex صحيحة، تُظهر تحذيرات لكن لا تزال تُحفظ.
*   **تصدير** — استخدم زري **Copy raw file** و **Download** في النافذة لنسخ أو تنزيل `DESIGN.md` الخاص بك.
*   **إزالة الإرشادات** — امسح حقل النص واحفظ لإزالة الإرشادات لهذا الملف.

[​](https://docs.flowstep.ai/ar/design-guidelines#%D9%8A%D9%82%D9%88%D9%85-flowstep-%D8%A8%D8%AA%D8%AD%D8%AF%D9%8A%D8%AB-%D8%A7%D9%84%D8%A5%D8%B1%D8%B4%D8%A7%D8%AF%D8%A7%D8%AA-%D9%84%D9%83)

يقوم Flowstep بتحديث الإرشادات لك
----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

عندما تعطي تعليمات نمط ثابتة في موجّه — على سبيل المثال، «من الآن فصاعداً، استخدم مظهراً أزرق» — يكتشفها Flowstep ويحدّث إرشادات التصميم الخاصة بك تلقائياً، مع تأكيد في الدردشة: «تم تحديث إرشادات التصميم الخاصة بك لاستخدام \[style\] للأجيال المستقبلية». الطلبات لمرة واحدة مثل «اجعلها زرقاء» لا تغيّر الإرشادات؛ فهي تؤثر فقط على هذا الجيل.

[​](https://docs.flowstep.ai/ar/design-guidelines#%D8%A5%D8%B1%D8%B4%D8%A7%D8%AF%D8%A7%D8%AA-%D8%A7%D9%84%D8%AA%D8%B5%D9%85%D9%8A%D9%85-%D8%B9%D8%A8%D8%B1-mcp)

إرشادات التصميم عبر MCP
------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

إذا كنت تعمل من خلال [MCP server](https://docs.flowstep.ai/ar/mcp/overview)
، تقرأ أدوات `get-design-guidelines`, `update-design-guidelines`, و `delete-design-guidelines` وتكتب نفس الإرشادات — وبالتالي يبقى سير العمل الخاص بك IDE والتطبيق الويب متزامناً. انظر [مرجع الأدوات](https://docs.flowstep.ai/ar/mcp/tools)
.

# تنزيل تصاميم Flowstep كملفات صور JPG أو PNG - Flowstep

> Documentation Index
> -------------------
> 
> Fetch the complete documentation index at: [/llms.txt](https://docs.flowstep.ai/llms.txt)
> 
> Use this file to discover all available pages before exploring further.

[الانتقال إلى المحتوى الرئيسي](https://docs.flowstep.ai/ar/export-formats#content-area)

![Screenshot 2026 05 06 At 14 19 49](https://mintcdn.com/flowstep/UmnbuTkaA7N6vp1N/images/Screenshot-2026-05-06-at-14.19.49.png?w=2500&fit=max&auto=format&n=UmnbuTkaA7N6vp1N&q=85&s=0e9e329a393b6e6475c028222de2cf8b)

عندما تكون مستعدًا لمشاركة تصميم أو تسليمه، يتيح لك Flowstep تصديره كصورة ثابتة — JPG أو PNG. كلا الصيغتين مدعومة على نطاق واسع في أدوات التصميم وبرامج العروض التقديمية والمتصفحات، لذا يمكنك نقل تصاميمك المُنتجة بالذكاء الاصطناعي أينما تحتاج.

[​](https://docs.flowstep.ai/ar/export-formats#%D9%83%D9%8A%D9%81%D9%8A%D8%A9-%D8%AA%D8%B5%D8%AF%D9%8A%D8%B1-%D8%AA%D8%B5%D9%85%D9%8A%D9%85%D9%83)

كيفية تصدير تصميمك
------------------------------------------------------------------------------------------------------------------------------------------------------------------------

1

افتح تصميمك

انتقل إلى التصميم الذي تريد تصديره داخل Flowstep.

2

افتح قائمة التصدير

ابحث عن خيار التصدير في شريط الأدوات أو لوحة التصميم. حدده لفتح إعدادات التصدير.

3

اختر صيغتك

حدد **JPG** أو **PNG** حسب حالتك الاستخدامية (انظر المقارنة أدناه).

4

تنزيل الملف

أكد اختيارك وتنزيل الصورة المُصدَّرة إلى جهازك.

![Screenshot 2026 05 06 At 14 19 39](https://mintcdn.com/flowstep/UmnbuTkaA7N6vp1N/images/Screenshot-2026-05-06-at-14.19.39.png?w=2500&fit=max&auto=format&n=UmnbuTkaA7N6vp1N&q=85&s=86c79f2c1ca043d214bbc2424351cd3c)

[​](https://docs.flowstep.ai/ar/export-formats#jpg-%D9%85%D9%82%D8%A7%D8%A8%D9%84-png-%D8%A3%D9%8A-%D8%B5%D9%8A%D8%BA%D8%A9-%D9%8A%D8%AC%D8%A8-%D8%A3%D9%86-%D8%AA%D8%B3%D8%AA%D8%AE%D8%AF%D9%85%D8%9F)

JPG مقابل PNG: أي صيغة يجب أن تستخدم؟
------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

|     | JPG | PNG |
| --- | --- | --- |
| **الأفضل لـ** | مشاركة المعاينات والعروض التقديمية ومراجعات الأصحاب المعنيين | التصاميم ذات الخلفيات الشفافة والتسليمات عالية الجودة |
| **حجم الملف** | أصغر — أسرع في المشاركة عبر البريد الإلكتروني أو المراسلة | أكبر — يحتفظ بكامل تفاصيل الصورة |
| **الشفافية** | غير مدعومة | مدعومة |
| **الجودة** | مضغوطة قليلاً | بدون فقدان — بدون تقليل الجودة |

إذا كنت تلصق تصميمك في شريحة أو ترسل معاينة سريعة لعميل، فإن JPG هو عادةً الخيار الصحيح. إذا كنت بحاجة إلى حواف حادة أو خلفية شفافة — على سبيل المثال، لتراكب التصميم على صورة أخرى — استخدم PNG.

[​](https://docs.flowstep.ai/ar/export-formats#%D8%AA%D8%B5%D8%AF%D9%8A%D8%B1-%D8%A7%D9%84%D9%83%D9%88%D8%AF)

تصدير الكود
----------------------------------------------------------------------------------------------------------------------------

بالإضافة إلى الصور، يصدر زر **Code** شاشة كود React + Tailwind — انسخ مقطع أو نزّل الحزمة الكاملة كـ ZIP. الحزم مكتفية ذاتيًا: الصور المستخدمة في التصميم (بما في ذلك التي أرفقتها في لوحة الدردشة) مضمنة في مجلد `public/assets/` مع إشارة الكود إليها برابط محلي، لذا يعمل التصدير كما هو. الملفات المنزلة — الصور وحزم الكود على حد سواء — سُميت على اسم الشاشة التي تنتمي إليها (العودة إلى اسم الملف إذا كانت الشاشة بدون اسم)، مما يحافظ على سهولة تحديد التصديرات عند العمل مع عدة شاشات.

إذا كنت بحاجة إلى نقل تصميمك إلى سير عمل تحرير متجه، انسخه مباشرة إلى Figma بدلاً من ذلك. راجع [نسخ تصاميم Flowstep إلى Figma فوراً](https://docs.flowstep.ai/ar/figma-integration)
.

# شرح رسائل Flowstep: حدود الاستخدام وإعادة التعيين - Flowstep

> Documentation Index
> -------------------
> 
> Fetch the complete documentation index at: [/llms.txt](https://docs.flowstep.ai/llms.txt)
> 
> Use this file to discover all available pages before exploring further.

[الانتقال إلى المحتوى الرئيسي](https://docs.flowstep.ai/ar/messages-and-limits#content-area)

تقيس Flowstep استخدامك بالرسائل. تتضمن كل خطة مخصصًا شهريًا من الرسائل، وبعض الخطط — مثل خطة Free — لها أيضًا حد يومي. يساعدك فهم كيفية احتساب الرسائل — وموعد إعادة تعيين حدودك — على الحصول على أقصى استفادة من خطتك.

[​](https://docs.flowstep.ai/ar/messages-and-limits#%D9%85%D8%A7-%D9%87%D9%8A-%D8%A7%D9%84%D8%B1%D8%B3%D8%A7%D9%84%D8%A9%D8%9F)

ما هي الرسالة؟
-------------------------------------------------------------------------------------------------------------------------------------------------

في كل مرة ترسل موجّهًا إلى Flowstep، يُحسب ذلك كرسالة واحدة. يتضمن ذلك طلبات التصميم الأولية والموجّهات المتابعة لتحسين أو تكرار التصميم الموجود.

إذا أسفر طلبك عن خطأ، فإن هذه المحاولة **لا** تُحتسب ضمن حد الرسائل. لن تفقد رسالة بسبب فشل التوليد.

[​](https://docs.flowstep.ai/ar/messages-and-limits#%D8%AD%D8%AF%D9%88%D8%AF-%D8%A7%D9%84%D8%A7%D8%B3%D8%AA%D8%AE%D8%AF%D8%A7%D9%85)

حدود الاستخدام
------------------------------------------------------------------------------------------------------------------------------------------------------

اعتمادًا على خطتك، قد يكون لديك **حد رسائل يومي** و**حد رسائل شهري**. بمجرد الوصول إلى أي من الحدود، ستحتاج إلى انتظار إعادة تعيينها قبل إرسال موجّهات أخرى. يمكنك رؤية عدد الرسائل المتبقية لديك في لوحة الموجّه في المحرر، وحدود خطتك على صفحة **Settings → Plan & Billing**.

[​](https://docs.flowstep.ai/ar/messages-and-limits#%D8%A7%D9%84%D8%AD%D8%AF%D9%88%D8%AF-%D9%81%D9%8A-%D8%A7%D9%84%D9%85%D8%A4%D8%B3%D8%B3%D8%A7%D8%AA)

الحدود في المؤسسات
-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------

في الخطط المدفوعة، تنطبق حدود الرسائل على كل مقعد: يحصل كل عضو يملك مقعدًا على المخصص الكامل من الرسائل الخاص بالخطة على حدة. لا يتم دمج الاستخدام — استخدام زميل ثقيل لا يؤثر على رسائل أي شخص آخر. راجع [Seats](https://docs.flowstep.ai/ar/seats)
 لمعرفة كيفية عمل المقاعد.

[​](https://docs.flowstep.ai/ar/messages-and-limits#%D9%85%D8%A7%D8%B0%D8%A7-%D9%8A%D8%AD%D8%AF%D8%AB-%D8%B9%D9%86%D8%AF-%D8%A7%D9%84%D9%88%D8%B5%D9%88%D9%84-%D8%A5%D9%84%D9%89-%D8%AD%D8%AF%D9%91%D9%83)

ماذا يحدث عند الوصول إلى حدّك
-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

إذا أرسلت موجّهًا بعد الوصول إلى حدّك، فلا يتم معالجة الموجّه ولا يستخدم رسالة. بدلاً من ذلك، ترد Flowstep في الدردشة لإعلامك بأنك استخدمت جميع رسائلك، مع الخيار لترقية الخطة أو الانتظار حتى إعادة تعيين حدّك. يمكنك الاستمرار في عرض تصاميمك وتعديلها يدويًا أثناء الانتظار. في مؤسسة، تظهر خيارات ترقية الخطة فقط لـ Owner — إذا كنت Member أو Admin وضربت حدّك، اطلب من Owner ترقية الخطة.

# 管理您的組織：人員、角色和設定 - Flowstep

> Documentation Index
> -------------------
> 
> Fetch the complete documentation index at: [/llms.txt](https://docs.flowstep.ai/llms.txt)
> 
> Use this file to discover all available pages before exploring further.

[跳轉到主要內容](https://docs.flowstep.ai/zh-Hant/organization-settings#content-area)

Owner（擁有者）和 Admin（管理員）從「設定」中的兩個頁面管理組織：**Organization**（組織名稱）和 **People**（您的成員和來賓）。Member（成員）和 Guest（來賓）看不到這些頁面。

[​](https://docs.flowstep.ai/zh-Hant/organization-settings#%E7%AE%A1%E7%90%86%E4%BA%BA%E5%93%A1)

管理人員
--------------------------------------------------------------------------------------------------------

前往 **Settings → People** 查看組織中的所有人。該頁面分為兩個索引標籤：

*   **Members** — Owner、Admin 和 Member。每一列顯示該人的名稱和電子郵件、其角色，以及他們最後一次看到的時間（如果他們目前處於活躍狀態，則為「Online now」）。
*   **Guests** — 擁有個別檔案檢視存取權的人員。**Access** 欄位顯示每位來賓可以開啟多少個檔案；點擊它查看清單。

尚未接受邀請的人會出現在清單底部，標記為 **Pending**。

[​](https://docs.flowstep.ai/zh-Hant/organization-settings#%E6%96%B0%E5%A2%9E%E6%88%90%E5%93%A1)

新增成員
--------------------------------------------------------------------------------------------------------

1

開啟「People」頁面

前往 **Settings → People**，然後點擊 **Add members**。

2

輸入電子郵件地址

輸入或貼上電子郵件地址，以逗號分隔。每個地址變成一個 pill，所以您可以同時邀請多個人。無效地址會反白顯示，以便您在傳送前進行更正。

3

選擇角色

為您邀請的人員選擇 **Admin** 或 **Member**。此角色適用於此批次中的所有人，您稍後可以變更個別角色。

4

傳送邀請

點擊 **Invite**。每個人都會收到一封電子郵件邀請 — 他們不需要現有的 Flowstep 帳戶，因為會自動為他們建立一個。

您邀請的每位成員都會在您組織的方案中新增一個付費席位，從他們受邀的時刻開始。在付費方案上，當 Owner 新增人員時，席位會自動更新；由 Admin 新增的成員可能會顯示為 **Inactive**，直到 Owner 點擊 **Fix**。在免費方案上，受邀的成員以 **Inactive**（唯讀）身分加入，直到您升級為止。請參閱[席位](https://docs.flowstep.ai/zh-Hant/seats)
。

Guest 無法從此對話方塊邀請 — 來賓存取權是透過[使用檢視存取權共用檔案](https://docs.flowstep.ai/zh-Hant/sharing-designs)
授予的。

[​](https://docs.flowstep.ai/zh-Hant/organization-settings#%E8%AE%8A%E6%9B%B4%E6%9F%90%E4%BA%BA%E7%9A%84%E8%A7%92%E8%89%B2)

變更某人的角色
--------------------------------------------------------------------------------------------------------------------------------------

在 **Members** 索引標籤上，使用 **Role** 欄中的下拉式選單在 **Admin** 和 **Member** 之間切換該人員。Owner 的角色是固定的，無法變更。

[​](https://docs.flowstep.ai/zh-Hant/organization-settings#%E7%A7%BB%E9%99%A4%E6%9F%90%E4%BA%BA)

移除某人
--------------------------------------------------------------------------------------------------------

開啟該人員列上的 **⋯** 選單，然後選擇 **Remove from organization**。系統會要求您確認：該人員立即失去對組織中所有檔案的存取權，您可以隨時重新邀請他們。 移除成員可釋放其席位，但您的組織在目前計費週期結束前會保留（並支付）該席位 — 在那之前將其指派給其他人，否則會在您下次續約時移除。 對於尚未接受邀請的人，操作改為 **Cancel invite**，會立即撤回邀請。由於待處理成員邀請已經佔用一個席位，取消它會釋放該席位。

您無法移除自己或組織的 Owner。

[​](https://docs.flowstep.ai/zh-Hant/organization-settings#%E7%AE%A1%E7%90%86%E4%BE%86%E8%B3%93)

管理來賓
--------------------------------------------------------------------------------------------------------

在 **Guests** 索引標籤上，您可以檢視每位來賓可以存取的內容。在付費方案上，Owner 可以使用 **Upgrade to member** 將來賓升級為完整成員 — 成員可以檢視和編輯組織內的檔案，因此將來賓升級會在您的方案中新增一個付費席位。在免費方案上，在您升級之前此操作無法使用。

[​](https://docs.flowstep.ai/zh-Hant/organization-settings#%E4%BF%AE%E6%AD%A3%E9%9D%9E%E4%BD%BF%E7%94%A8%E4%B8%AD%E7%9A%84%E6%88%90%E5%93%A1)

修正非使用中的成員
----------------------------------------------------------------------------------------------------------------------------------------------------------

如果某些成員顯示為 **Inactive**，他們具有唯讀存取權，因為您的組織有比付費席位更多的成員：

*   在**付費方案**上，Owner 會看到「Some members aren’t active」橫幅 — 點擊 **Fix** 以同步您的席位並恢復其編輯存取權。
*   在**免費方案**上，升級到付費方案以啟用您的成員。

[​](https://docs.flowstep.ai/zh-Hant/organization-settings#%E9%87%8D%E6%96%B0%E5%91%BD%E5%90%8D%E6%82%A8%E7%9A%84%E7%B5%84%E7%B9%94)

重新命名您的組織
------------------------------------------------------------------------------------------------------------------------------------------------

前往 **Settings → Organization**，然後在組織名稱旁邊點擊 **Change**。組織中的其他成員可以看到該名稱。

# Fatturazione Flowstep: cicli, cancellazione e accesso - Flowstep

> Documentation Index
> -------------------
> 
> Fetch the complete documentation index at: [/llms.txt](https://docs.flowstep.ai/llms.txt)
> 
> Use this file to discover all available pages before exploring further.

[Vai al contenuto principale](https://docs.flowstep.ai/it/billing#content-area)

Flowstep ti dà il controllo su come e quando paghi. Puoi scegliere la fatturazione mensile o annuale al momento dell’iscrizione, e puoi annullare in qualsiasi momento senza perdere l’accesso per il resto del tuo periodo pagato.

[​](https://docs.flowstep.ai/it/billing#chi-pu%C3%B2-gestire-la-fatturazione)

Chi può gestire la fatturazione
----------------------------------------------------------------------------------------------------------------

In un’organizzazione, solo **Owner** (proprietario) — la persona che ha creato l’organizzazione — può gestire la fatturazione. L’Owner è l’unica persona che vede la pagina **Plan & Billing** in Settings e i pulsanti **Upgrade** nell’app. Gli Admin (amministratori) possono aggiungere e rimuovere persone, ma non possono passare a un piano superiore, passare a un piano inferiore, cambiare postazioni o annullare l’abbonamento — i cambiamenti delle postazioni si sincronizzano con l’abbonamento solo tramite l’Owner. Vedi [Organizzazioni](https://docs.flowstep.ai/it/organizations)
 per la ripartizione completa dei ruoli.

[​](https://docs.flowstep.ai/it/billing#cicli-di-fatturazione)

Cicli di fatturazione
---------------------------------------------------------------------------------------

Quando ti iscrivi a un piano Flowstep a pagamento, puoi scegliere tra due opzioni di fatturazione:

*   **Monthly** — ti viene addebitato una volta al mese nella tua data di fatturazione.
*   **Annual** — ti viene addebitato una volta all’anno. L’intero anno viene fatturato in anticipo all’inizio del periodo di fatturazione.

I piani a pagamento sono fatturati per postazione: il tuo totale è il prezzo per postazione del piano moltiplicato per il numero di postazioni — una per ogni Owner, Admin e Member (membro) nella tua organizzazione. I Guest (ospiti) sono gratuiti e non contano. L’aggiunta di persone a metà ciclo è calcolata proporzionalmente, quindi paghi solo per il resto del periodo. Vedi [Postazioni](https://docs.flowstep.ai/it/seats)
 per i dettagli. I passaggi a un piano superiore hanno effetto immediato, mentre i passaggi a un piano inferiore hanno effetto alla fine del tuo attuale periodo di fatturazione.

La fatturazione annuale ti consente di risparmiare fino al 20% rispetto al pagamento mensile. Se prevedi di utilizzare Flowstep regolarmente, il piano annuale è l’opzione più conveniente.

[​](https://docs.flowstep.ai/it/billing#gestione-dell%E2%80%99abbonamento)

Gestione dell’abbonamento
-------------------------------------------------------------------------------------------------------

L’Owner gestisce l’abbonamento da **Settings → Plan & Billing**. Nel piano gratuito o in una prova, la pagina mostra un pulsante **Upgrade** che apre il selettore del piano. Su un piano a pagamento, mostra invece un pulsante **Manage**, che apre il portale di fatturazione dove gestisci i tuoi dettagli di pagamento e l’abbonamento.

[​](https://docs.flowstep.ai/it/billing#annullamento)

Annullamento
---------------------------------------------------------------------

Puoi annullare il tuo abbonamento Flowstep in qualsiasi momento — non ci sono costi di annullamento o periodi di blocco. Per annullare, l’Owner apre il portale di fatturazione tramite **Manage** nella pagina **Plan & Billing**. L’Owner riceve un’email di conferma dell’annullamento e la data in cui ha effetto.

Quando annulli, il tuo abbonamento non termina immediatamente. Mantieni l’accesso completo alle funzionalità del tuo piano e ai messaggi rimanenti fino alla fine del tuo attuale periodo di fatturazione. Dopo di che, la tua organizzazione passa al piano Free con una singola postazione — l’Owner mantiene l’accesso di modifica e qualsiasi altro membro diventa di sola lettura fino a quando non passi di nuovo a un piano superiore.

[​](https://docs.flowstep.ai/it/billing#fatture)

Fatture
-----------------------------------------------------------

Dopo ogni ciclo di fatturazione, Flowstep genera automaticamente una fattura per il tuo pagamento. Puoi scaricare le fatture passate in qualsiasi momento tramite il portale di fatturazione. Vedi [Fatture](https://docs.flowstep.ai/it/invoices)
 per le istruzioni.

Flowstep va Figma o’zaro qo’shma vositalar, raqobatchilar emas. Flowstep dizaynini Figma-ga qanday nusxalash kerak
-----------------------------------------------------------------------------------------------------------------------------------------------------------

1

Flowstep-da bir yoki bir nechta ekranni tanlang

Ekranni tanlash uchun bosing — yoki bir nechta ekranni tanlang va ularni barcha birgalikda nusxalang. Canvas-da tanlov ta’kidlanganiga ishonch hosil qiling.

2

Tanlovni nusxalang

Mac-da \*\*Cmd+\*\*⇧+**C** yoki Windows-da \*\*Ctrl+\*\*⇧+**C** tugmasini bosing. Flowstep “Preparing your design — stay on this tab and keep the screen selected” xabarini ko’rsatadi; nusxalash bir lahzada tugaydi.

3

Figma faylingizga joylashtiring

Figma-ga o’ting va dizaynni joylashtirish uchun kerak bo’lgan faylni oching. Mac-da **Cmd+V** yoki Windows-da **Ctrl+V** tugmasini bosib joylashtiring. Flowstep ekranlari sizning Figma kanvasida paydo bo’ladi, tahrir qilishga tayyor.

Figma-ga nusxalash brauzer clipboard-dan foydalanadi, shuning uchun brauzer Flowstep clipboard-ga kirish huquqiga ruxsat berishi kerak — agar xatolik ko’rsatsa, brauzer sozlamalarida clipboard-ga kirish huquqini berish va qayta urinish. Tab oralig’ida nusxalashni to’xtatib qo’yish o’tkazishni urib qo’yadi; nusxalash tugaguniga qadar Flowstep varaqini o’ziga e’tibor qiling.

Ramkani Figma-da ajratilgan “AI importlari” sahifasiga joylashtiring — bu sizning ishchi fayllarini tartibda saqlaydi. U yerdan siz elementlarni o’z vaqtingizda asosiy dizayn tizimiga yoki komponent kutubhonasingizga o’tkazishingiz mumkin.

[​](https://docs.flowstep.ai/uz/figma-integration#figma-dan-dizaynni-import-qilish)

Figma-dan dizaynni import qilish
-----------------------------------------------------------------------------------------------------------------------

Shuningdek, siz aksincha qilishingiz va Figma ramkasini Flowstep-ga tahrirlanadigun ekran sifatida olishingiz mumkin. Import hammaga ochiq — Figma akkauntini bir marta ulang, keyin ramka havolasidan import qiling.

1

Figma-ni ulang

Flowstep akkauntingizni Figma bilan sozlamalardan ulang. Flowstep sizga ruxsat bergan fayllarni o’qish uchun Figma avtorizatsiyasidan foydalanadi.

2

Figma-da ramka havolasini nusxalang

Figma-da, siz kerak bo’lgan ramkani o’ng bosing va **Copy link to selection** tanlang. Shuningdek, butun sahifani nusxalash uchun butun sahifaga havolani nusxalashingiz mumkin — bu birgalikda uning barcha yuqori darajadagi ramkalarini import qiladi.

3

Flowstep-ga import qilish

Flowstep asboblar panelida Figma import variantini ishlating va havolani joylashtiring. Flowstep ramkani tahrirlanadigun elementlarga o’zgartirilmishdir. Bir xil ramkani qayta import qilish uni joyida yangilaydi.

### 

[​](https://docs.flowstep.ai/uz/figma-integration#nima-import-qilinadi)

Nima import qilinadi

Flowstep Figma ramkasini mahalliy, tahrirlanadigun elementlar sifatida qayta yaratadi — tekis rasm emas. Import bu narsalarni olib keladi:

*   Ramkalar va ularning o’rnatilgan qatlamlari
*   Matn, masalan og’irlik, rang va qalin kabi belgiga mahsus stilga ega
*   Figma o’zgaruvchileridan ranglar
*   Rasm to’ldirishlari va SVG ikonkalar va shakllar

# Pladser og opladning pr. plads for Flowstep-teams - Flowstep

> Documentation Index
> -------------------
> 
> Fetch the complete documentation index at: [/llms.txt](https://docs.flowstep.ai/llms.txt)
> 
> Use this file to discover all available pages before exploring further.

[Spring til hovedindhold](https://docs.flowstep.ai/da/seats#content-area)

Betalte Flowstep-abonnementer faktureres pr. plads. Hver Owner, Admin og Member i din organisation bruger en plads; Guests er gratis og tæller aldrig med i dit samlede antal pladser. Prisen på dit abonnement er abonnementets pris pr. plads ganget med antallet af pladser.

Hver plads får det fulde beskedtilladelse individuelt — brugen er ikke samlet på tværs af teamet. Se [Beskeder og grænser](https://docs.flowstep.ai/da/messages-and-limits)
.

[​](https://docs.flowstep.ai/da/seats#hvem-bruger-en-plads)

Hvem bruger en plads
-----------------------------------------------------------------------------------

| Rolle | Bruger en plads |
| --- | --- |
| Owner, Admin, Member | Ja  |
| Guest | Nej |

Se [Organisationer](https://docs.flowstep.ai/da/organizations)
 for hvad hver rolle kan gøre.

[​](https://docs.flowstep.ai/da/seats#tilf%C3%B8jelse-af-medlemmer)

Tilføjelse af medlemmer
----------------------------------------------------------------------------------------------

Når Owner inviterer medlemmer på et betalt abonnement, tilføjes pladser til abonnementet automatisk, og prisen beregnes forholdsmæssigt — du betaler kun for resten af den aktuelle faktureringsperiode. Der er ingen separat trin til køb af pladser. Hvis en Admin inviterer medlemmer i stedet, kan nye medlemmer vises som **Inactive** indtil Owner klikker **Fix** på People page. Et medlems plads bruges fra det øjeblik, de inviteres, selv mens invitationen stadig ikke er accepteret — annullering af en ikke-accepteret invitation frigør pladsen. Når du først opgraderer til et betalt abonnement, bliver du opkrævet for de personer, der allerede er i din organisation — en plads for hver Owner, Admin og Member. På Free-abonnementet har din organisation en enkelt plads, så inviterede medlemmer tilslutter sig som **Inactive** indtil du opgraderer. Invitelse af medlemmer er ikke det eneste, der bruger en plads: opgradering af en Guest til Member og [tildeling af redigeringsadgang til en fil](https://docs.flowstep.ai/da/sharing-designs)
 begge tilføjer en betalt plads.

[​](https://docs.flowstep.ai/da/seats#fjernelse-af-medlemmer)

Fjernelse af medlemmer
---------------------------------------------------------------------------------------

Fjernelse af et medlem frigør deres plads, men organisationen beholder pladsen — og fortsætter med at betale for den — til slutningen af den aktuelle faktureringsperiode. Du kan tildele den til nogen anden inden da, eller den fjernes ved din næste fornyelse. Hvis du har flere pladser end aktive medlemmer, viser People page hvor mange pladser der er tilgængelige, og Owner kan klikke på **Reduce seats** for at trimme abonnementet, så det matcher teamet. En pladsreduktion er planlagt til slutningen af den aktuelle faktureringsperiode i stedet for at blive anvendt med det samme — du beholder pladserne og deres adgang til da, og din regning falder ved næste fornyelse. Hvis du tilføjer mennesker igen, før en planlagt reduktion træder i kraft, annulleres reduktionen, og de nye pladser tilføjes med det samme, fordelt for resten af perioden.

[​](https://docs.flowstep.ai/da/seats#inaktive-medlemmer)

Inaktive medlemmer
-------------------------------------------------------------------------------

Medlemmer uden en plads får skrivebeskyttet adgang og vises som **Inactive** på People page. Dette sker, når din organisation har flere medlemmer end betalte pladser — for eksempel efter at invitere medlemmer på Free-abonnementet eller efter at reducere dit antal pladser. Når der er færre pladser end medlemmer, går pladser til Owner først, derefter til medlemmer efter tilmeldingsdato — de senest tilmeldte medlemmer bliver først inaktive. Owner kan gendanne deres adgang ved at klikke på **Fix** på People page (betalte abonnementer) eller ved at opgradere til et betalt abonnement. Inaktive medlemmer kan stadig åbne organisationens filer, men kan ikke redigere dem — undtagen filer, som de selv oprettede, som de altid kan redigere.

[​](https://docs.flowstep.ai/da/seats#hvem-administrerer-pladser)

Hvem administrerer pladser
-----------------------------------------------------------------------------------------------

Kun organisationens Owner kan ændre abonnementet, justere pladser eller håndtere anden faktureringskontrol. Admins kan tilføje og fjerne medlemmer, men de kan ikke få adgang til faktureringssider, og ændringer af pladser synkroniseres kun til abonnementet gennem Owner. Se [Fakturering](https://docs.flowstep.ai/da/billing)
.

[​](https://docs.flowstep.ai/da/seats#annullering)

Annullering
-----------------------------------------------------------------

Hvis Owner annullerer et betalt abonnement, beholder organisationen sit abonnement og pladser til slutningen af den betalte periode. Derefter skifter det til Free-abonnementet med en enkelt plads — Owner beholder redigeringsadgang, og andre medlemmer bliver skrivebeskyttet til organisationen opgraderes igen.

Var denne side nyttig?

# Flowstep szervezetek: csapatok, szerepkörök és engedélyek - Flowstep

> Documentation Index
> -------------------
> 
> Fetch the complete documentation index at: [/llms.txt](https://docs.flowstep.ai/llms.txt)
> 
> Use this file to discover all available pages before exploring further.

[Ugrás a fő tartalomhoz](https://docs.flowstep.ai/hu/organizations#content-area)

Minden Flowstep-fiók egy szervezethez tartozik. Feliratkozáskor a Flowstep automatikusan létrehoz egy szervezetet számodra — és amikor csapattársakat adsz hozzá, azok csatlakoznak a szervezetedhez, és a szerepkörük alapján dolgozhatnak a fájljain.

[​](https://docs.flowstep.ai/hu/organizations#a-szervezetek-m%C5%B1k%C3%B6d%C3%A9se)

A szervezetek működése
--------------------------------------------------------------------------------------------------------------

A fájlok egy szervezetben élnek, nem személyes fiókban. Új fájl létrehozásakor az a szervezet hozza létre, amely jelenleg kiválasztott, és a szervezet minden tagja megtekintheti azt a szerepköre és a fájl [megosztási beállításai](https://docs.flowstep.ai/hu/sharing-designs)
 alapján. Ha több szervezethez tartozol, a fejlécben megjelenik egy szervezetváltó. A szervezet váltása megváltoztatja az egész munkaterület kontextusát:

*   A Kezdőlapon az **All files** (Összes fájl) és a **Created by me** (Nekem készült) a kiválasztott szervezet fájljait mutatják.
*   A **Shared with me** (Velem megosztva) a fájlokat mutatja, amelyeket olyan szervezetektől osztottak meg veled, amelyeknek nem vagy tagja.

[​](https://docs.flowstep.ai/hu/organizations#szerepk%C3%B6r%C3%B6k)

Szerepkörök
-----------------------------------------------------------------------------------

A Flowstep-szervezeteknek négy szerepköre van:

| Szerepkör | Helyhasználat | Mit tehetnek |
| --- | --- | --- |
| **Owner** | Igen | Mindent, amit az Adminok, plusz a csomag, a helyek és a számlázás kezelése. Az Owner az a személy, aki létrehozta a szervezetet. |
| **Admin** | Igen | Megtekintheti és szerkesztheti a szervezetben lévő összes fájlt. Megváltoztathatja a szervezet beállításait és új tagokat hívhat meg. |
| **Member** | Igen | Megtekintheti és szerkesztheti a szervezetben lévő összes fájlt. Nem módosíthatja a szervezet beállításait és nem hívhat meg új tagokat. |
| **Guest** | Nem | Csak olvasható hozzáférés a velük megosztott tervekhez. A vendégek nem szerkeszthetnek semmit a szervezetedben. |

A fájlhoz való hozzáférést az egyes fájlok megosztási beállításai is szabályozzák — a **Restricted** (Korlátozott) beállítású fájlok csak azokkal nyithatók meg, akikkel meg vannak osztva. A részletekért tekintsd meg a [Tervek megosztása](https://docs.flowstep.ai/hu/sharing-designs)
 oldalt.

Minden szervezetnek pontosan egy Ownere van — az a személy, aki létrehozta. Az Owner szerepkör nem lehet átadni vagy eltávolítani az alkalmazásban, és csak az Owner kezelheti a számlázást. A részletekért tekintsd meg a [Számlázás](https://docs.flowstep.ai/hu/billing)
 oldalt.

[​](https://docs.flowstep.ai/hu/organizations#vend%C3%A9gek)

Vendégek
------------------------------------------------------------------------

A vendégek azok a személyek, akiknek megtekintési hozzáférést adtak az Ön terveihez — például egy projektgazda, akit meghívtál egy fájl felülvizsgálatára. A vendéghozzáférés csak olvasható: a vendégek nem szerkeszthetnek semmit a szervezetedben.

*   A vendégek ingyenesek: soha nem használnak fizetett [helyeket](https://docs.flowstep.ai/hu/seats)
    .
*   Valaki vendéggé válik, ha elfogad egy megtekintési meghívót az egyik fájlodhoz. Nincs lehetőség arra, hogy közvetlenül a szervezet beállításaiból hívjon meg egy vendéget — a vendéghozzáférés mindig a fájlok megosztásával kezdődik. A részletekért tekintsd meg a [Tervek megosztása](https://docs.flowstep.ai/hu/sharing-designs)
     oldalt.
*   Fizetős csomagban az Owner a vendéget teljes Memberé emelheti fel a **Settings → People** (Beállítások → Személyek) menüből. Ez egy fizetett helyET adja hozzá a csomagodhoz. A részletekért tekintsd meg a [Szervezet beállításai](https://docs.flowstep.ai/hu/organization-settings)
     oldalt.

[​](https://docs.flowstep.ai/hu/organizations#inakt%C3%ADv-tagok)

Inaktív tagok
----------------------------------------------------------------------------------

A tagnak fizetett helyre van szüksége az szerkesztési hozzáférés megtartásához. Ha a szervezetedben több tag van, mint hely — például, miután ingyenes csomagban meghívtál embereket — az hely nélküli tagok **Inactive** (Inaktív) jelöléssel vannak megjelölve, és csak olvasható hozzáférést kapnak, amíg hely nem lesz elérhető. Fizetős csomagban a helyek általában automatikusan szinkronizálódnak, amikor az Owner embereket ad hozzá. Ha a tagok **Inactive** (Inaktív) jelöléssel jelennek meg, az Owner a **Settings → People** (Beállítások → Személyek) oldalon a **Fix** (Javítás) gombra kattinthat a hozzáférésük helyreállításához — vagy magasabb csomagra válthat, ha a szervezeted az ingyenes csomagban van. A [Helyek](https://docs.flowstep.ai/hu/seats)
 oldalt megtekintheted, hogy megtudhasd, hogyan működnek a helyek.

[​](https://docs.flowstep.ai/hu/organizations#csatlakoz%C3%A1s-egy-szervezethez)

Kattints a meghívó e-mailben lévő linkre, és hozzáadódnak a szervezethez azzal a szerepkörrel, ahogy meghívtak — ha még nincs Flowstep-fiókod, az automatikusan létrejön, és a meghívó linkre kattintás bejelentkeztet. Csatlakozás után a szervezet megjelenik a szervezetváltódban.

# Як використовувати Flowstep без попереднього досвіду дизайну - Flowstep

> Documentation Index
> -------------------
> 
> Fetch the complete documentation index at: [/llms.txt](https://docs.flowstep.ai/llms.txt)
> 
> Use this file to discover all available pages before exploring further.

[Перейти до основного вмісту](https://docs.flowstep.ai/uk/no-design-skills#content-area)

Вам не потрібно знати різницю між гарнітурою та шрифтом, розумітися на системах сіток чи коли-небудь відкривати інструменти дизайну. Flowstep автоматично обробляє макет, типографіку, колір, відступи та візуальну ієрархію — ваше завдання просто описати, що вам потрібно.

[​](https://docs.flowstep.ai/uk/no-design-skills#%D1%8F%D0%BA-%D1%86%D0%B5-%D0%BF%D1%80%D0%B0%D1%86%D1%8E%D1%94-%D0%B1%D0%B5%D0%B7-%D0%BD%D0%B0%D0%B2%D0%B8%D1%87%D0%BE%D0%BA-%D0%B4%D0%B8%D0%B7%D0%B0%D0%B9%D0%BD%D1%83)

Як це працює без навичок дизайну
-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

Коли ви вводите промпт, Flowstep інтерпретує ваш опис і приймає всі візуальні рішення, які зазвичай приймав би дизайнер: як розташувати елементи на екрані, які шрифти використовувати, скільки пустого простору додати та як створити візуальну ієрархію, яка спрямовує погляд. Ви описуєте мету та вміст; Flowstep видає екран, який виглядає так, ніби його спроектував професіонал.

Уявіть собі введення промпту в Flowstep так само, як ви брифували б дизайнера. Ви б не розповідали дизайнеру, який розмір шрифту використовувати — ви б розповіли йому, для чого потрібен екран і що він повинен повідомити. Flowstep працює так само.

[​](https://docs.flowstep.ai/uk/no-design-skills#%D0%BF%D0%BE%D1%80%D0%B0%D0%B4%D0%B8-%D1%89%D0%BE%D0%B4%D0%BE-%D0%BD%D0%B0%D0%BF%D0%B8%D1%81%D0%B0%D0%BD%D0%BD%D1%8F-%D1%85%D0%BE%D1%80%D0%BE%D1%88%D0%B8%D1%85-%D0%BF%D1%80%D0%BE%D0%BC%D0%BF%D1%82%D1%96%D0%B2)

Поради щодо написання хороших промптів
------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

Зосередьтеся на трьох речах: на призначенні екрану, на ключовій інформації, яку він повинен показувати, та на типі продукту або аудиторії. **Почніть з призначення екрану** Почніть з того, що повинен робити екран. «Екран реєстрації для додатку планування їжі» розповідає Flowstep набагато більше, ніж список елементів інтерфейсу користувача. **Згадайте ключовий вміст або дії** Включіть найважливіші речі, які користувач повинен бачити або робити. Вам не потрібно перераховувати все — просто елементи, які найбільше важать для користувацького досвіду. **Посилайтеся на тип продукту або аудиторію, якщо це допоможе** Згадування типу продукту (наприклад, мобільний додаток для споживачів, панель керування B2B, оформлення замовлення електронної комерції) допомагає Flowstep відповідати правильному візуальному тону та конвенціям.

Якщо ваш перший результат не зовсім правильний, не починайте спочатку — просто введіть подальший промпт. Сказати «зробіть макет більш мінімальним» або «використовуйте темнішу колірну схему» достатньо, щоб спрямувати дизайн у новому напрямку.

[​](https://docs.flowstep.ai/uk/no-design-skills#%D0%BF%D1%80%D0%B8%D0%BA%D0%BB%D0%B0%D0%B4%D0%B8-%D0%BF%D1%80%D0%BE%D0%BC%D0%BF%D1%82%D1%96%D0%B2-%D0%B4%D0%BB%D1%8F-%D1%81%D0%BF%D1%80%D0%BE%D0%B1%D1%83%D0%B2%D0%B0%D0%BD%D0%BD%D1%8F)

Приклади промптів для спробування
------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

Ось кілька промптів, які добре працюють, написаних простою англійською мовою без дизайнерської термінології: **Потік входу для додатку фітнесу**

> «Перший екран потоку входу для додатку відстеження фітнесу. Він повинен привітати користувача, коротко пояснити, що робить додаток, і мати кнопку для початку роботи.»

**Сторінка параметрів для продукту SaaS**

> «Сторінка параметрів для інструменту управління проектами B2B. Включіть розділи для профілю, сповіщень, виставлення рахунків та підключених облікових записів. Використовуйте чистий, професійний вигляд.»

**Мобільний екран оформлення замовлення**

> «Екран оформлення замовлення для мобільного додатку покупок. Показати резюме замовлення, поле для промо-коду та видну кнопку для завершення покупки.»

Ці промпти працюють не тому, що вони використовують мову дизайну, а тому, що вони чітко описують призначення, вміст та контекст екрану. Це все, що вам потрібно.

### 

[​](https://docs.flowstep.ai/lv/design-references#pievienojiet-prd)

Pievienojiet PRD

Augšupielādējiet produkta prasību dokumentu, lai sniegtu Flowstep detalizētu izpratni par jūsu produkta mērķiem, funkcijām un lietotāju vajadzībām pirms ekrāņu ģenerēšanas.

### 

[​](https://docs.flowstep.ai/lv/design-references#aug%C5%A1upiel%C4%81d%C4%93jiet-att%C4%93lu)

Augšupielādējiet attēlu

Pievienojiet ekrānuzņēmumu, skici, garastāvokļa kolāžu vai jebkuru attēlu, lai sniegtu Flowstep vizuālu atsauci par stilu vai izkārtojumu, ko jums ir prātā.

Izmantojiet attēla atsauci, kad jums ir spēcīgs vizuālais virziens prātā—piemēram, konkurenta lietotāja interfeiss, no kura vēlaties iegūt iedvesmu, vai vienpavīdu maketus, ko jūs uzzīmējāt ar roku. Flowstep izmanto attēlu kā iedvesmu, nevis kā precīzu šablonu kopēšanai.

### 

[​](https://docs.flowstep.ai/lv/design-references#iel%C4%ABm%C4%93jiet-url)

Ielīmējiet URL

Norādiet saiti uz tīmekļa vietni, aktīvu produktu vai jebkuru tīmekļa lapu, un Flowstep izmantos to kā atsauci vizuālajam stilam, struktūrai vai satura modeļiem.

Izmantojiet URL atsauci, kad vēlaties atbilst vai iegūt iedvesmu no esošā digitālā produkta. Tas ir īpaši noderīgi ar balto etiķeti saistītos darbiem, konkurentu analīzei vai kad vadības pārstāvis saka “padariet to tā izskatīties.”

[​](https://docs.flowstep.ai/lv/design-references#pievienojiet-iel%C4%ABm%C4%93jot)

Pievienojiet ielīmējot
-------------------------------------------------------------------------------------------------------------

Ātrākais veids, kā pievienot atsauci, bieži vien ir ielīmēšana: fails vai attēls, kas ielīmēts uzvednes ievadē, automātiski tiek pievienots. Atbalstītie pielikumi ir attēli (JPG, PNG, WEBP) un dokumenti (PDF, MD, TXT), katrs līdz 3 MB. Arī garā teksta ielīmēšana darbojas — uzvednes ievads var saturēt līdz 6000 rakstzīmēm, un teksta ielīmēšana šajā vai lielākos apjomos automātiski to pievieno kā failu ar nosaukumu `pasted.txt` (ja uzvedne ir tukša, tas tiek aizpildīts ar “Izpildiet norādījumus failā”). Ērti, lai nodotu Flowstep plašu specifikāciju bez tās apgriešanas.

[​](https://docs.flowstep.ai/lv/design-references#k%C4%81p%C4%93c-izmantot-atsauces)

Kāpēc izmantot atsauces
---------------------------------------------------------------------------------------------------------------

Atsauces samazina detaļu skaitu, ko jums jāiekļauj savo uzvednē. Tā vietā, lai rakstītu rindkopu, lai paskaidrotu sava produkta kontekstu vai vizuālo virzienu, viena pievienotā datne vai saite to var izteikt daudz pilnīgāk. Tas paātrīna ģenerēšanas procesu un bieži vien pirmajā mēģinājumā iegūst atbilstošākus rezultātus. Jūs varat apvienot atsauces—piemēram, pievienojot PRD produkta kontekstam un attēlu vizuālai iedvesmei vienlaicīgi.

# Zacznij z Flowstep: zarejestruj się i generuj projekty - Flowstep

[Przejdź do głównej treści](https://docs.flowstep.ai/pl/getting-started#content-area)

Uruchomienie Flowstep zajmuje zaledwie kilka minut. Rejestru­jesz się za darmo, opisujesz, co chcesz zbudować, a Flowstep natychmiast generuje Twój projekt. Następnie możesz go udoskonalić poprzez kolejne prompty, zaprosić swój zespół do współpracy i udostępnić wynik interesariuszom — nie potrzebujesz narzędzi do projektowania ani wcześniejszego doświadczenia.

1

Utwórz bezpłatne konto

Przejdź do [flowstep.ai](https://flowstep.ai/)
 i zarejestruj się za pomocą Google lub swojego adresu e-mail i hasła. Aby zacząć, nie potrzebujesz karty kredytowej.

Jeśli zarejestrujesz się za pomocą adresu e-mail i hasła, sprawdź swoją skrzynkę odbiorczą pod kątem wiadomości e-mail potwierdzającej („Confirm your Flowstep email”) i kliknij link, aby aktywować swoje konto — możesz ponownie wysłać go ze strony „Check your inbox”, jeśli nie dotrze. Adresy e-mail jednorazowe nie są akceptowane; użyj firmowego lub osobistego adresu e-mail.

Po zarejestrowaniu lądujemy na krótkim ekranie powitalnym: odpowiedz na trzy szybkie pytania, a następnie opisz swój pierwszy projekt bezpośrednio tam — cztery przykładowe prompty (Dashboard, Landing page, Mobile app, Checkout) są dostępne, jeśli chcesz punktu wyjścia.

2

Opisz ekran, który chcesz

Wpisz prompt w zwykłym angielskim, opisując interfejs, który masz na myśli. Bądź konkretny co do celu ekranu i wszelkich kluczowych elementów, które powinien zawierać.Prompt taki jak „Dashboard dla aplikacji do zarządzania projektami z listą zadań, paskami postępu i nawigacją na pasku bocznym” daje Flowstep wystarczającą ilość kontekstu, aby wytworzyć skoncentrowany, przydatny projekt.

Nie potrzebujesz słownika projektowania. Skup się na tym, do czego służy ekran i jakie informacje powinien pokazywać — Flowstep obsługuje układ, typografię, odstępy i wybór kolorów.

3

Wygeneruj swoje ekrany

Prześlij swój prompt, a Flowstep generuje Twój projekt w kilka sekund. Możesz wygenerować wiele ekranów w jednej sesji, aby zbadać różne kierunki lub zbudować pełny przepływ.

4

Udoskonal poprzez rozmowę

Nie jest to idealne? Wpisz prompt uzupełniający, aby dostosować projekt — zmień schemat kolorów, zmień układ elementów, zamień zawartość lub poproś o całkowicie inny układ. Możesz również edytować elementy ręcznie lub używać akcji jednym klikiem w menu opcji.

5

Wyeksportuj lub udostępnij swoją pracę

Gdy jesteś zadowolony z rezultatu, wybierz sposób jego udostępnienia:

*   **Export** kod lub za pomocą MCP
*   **Download** ekran jako plik JPG lub PNG
*   **Copy to Figma** korzystając ze skrótu klawiszowego, aby wkleić bezpośrednio do istniejącego pliku Figma
*   **Share a link** z kolegami z zespołu lub interesariuszami — mogą przeglądać projekt bez tworzenia konta

Możesz zaprosić swój zespół do współpracy na pliku Flowstep. Mogą dołączyć i zacząć wnosić wkład w ciągu minut.

# 如何在没有设计经验的情况下使用 Flowstep - Flowstep

> Documentation Index

[跳转到主要内容](https://docs.flowstep.ai/zh/no-design-skills#content-area)

您无需了解字体和字型之间的区别、理解网格系统或曾经打开过设计工具。Flowstep 会自动处理布局、排版、颜色、间距和视觉层次 — 您的工作就是简单地描述您想要的内容。

[​](https://docs.flowstep.ai/zh/no-design-skills#%E6%97%A0%E9%9C%80%E8%AE%BE%E8%AE%A1%E6%8A%80%E8%83%BD%E5%A6%82%E4%BD%95%E5%B7%A5%E4%BD%9C)

无需设计技能如何工作
----------------------------------------------------------------------------------------------------------------------------------------------------------

当您输入提示词时，Flowstep 会解释您的描述并做出设计师通常会做的所有视觉决策：如何在屏幕上排列元素、使用哪些字体、添加多少空白以及如何建立引导眼睛的视觉层次。您描述目的和内容；Flowstep 生成看起来像专业设计的屏幕。

将向 Flowstep 输入提示词的方式想象成与设计师沟通的方式。您不会告诉设计师使用哪种字体大小 — 而是告诉他们屏幕的用途以及它需要传达什么。Flowstep 的工作方式相同。

[​](https://docs.flowstep.ai/zh/no-design-skills#%E7%BC%96%E5%86%99%E5%A5%BD%E7%9A%84%E6%8F%90%E7%A4%BA%E8%AF%8D%E7%9A%84%E6%8F%90%E7%A4%BA)

编写好的提示词的提示
----------------------------------------------------------------------------------------------------------------------------------------------------------

关注三件事：屏幕的目的、它应该显示的关键信息以及产品或受众的类型。 **以屏幕的目的开头** 从屏幕应该做什么开始。“餐饮计划应用的注册屏幕”比 UI 元素列表能告诉 Flowstep 更多信息。 **提及关键内容或操作** 包含用户应该看到或做的最重要的事情。您不需要列出所有内容 — 只需列出对体验最重要的元素。 **如果有帮助，请参考产品类型或受众** 提及产品的类型（例如，消费类移动应用、B2B 仪表板、电子商务结账）有助于 Flowstep 匹配正确的视觉语调和约定。

如果您的第一个结果不完全正确，不要重新开始 — 只需输入后续提示词。说”让布局更简约”或”使用更深的配色方案”足以将设计引导到新的方向。

[​](https://docs.flowstep.ai/zh/no-design-skills#%E5%8F%AF%E4%BB%A5%E5%B0%9D%E8%AF%95%E7%9A%84%E7%A4%BA%E4%BE%8B%E6%8F%90%E7%A4%BA%E8%AF%8D)

可以尝试的示例提示词
----------------------------------------------------------------------------------------------------------------------------------------------------------

以下是一些效果很好的提示词，用简单的英文编写，没有设计术语： **健身应用的入职流程**

> “First screen of an onboarding flow for a fitness tracking app. It should welcome the user, briefly explain what the app does, and have a button to get started.”

**SaaS 产品的设置页面**

> “Settings page for a B2B project management tool. Include sections for profile, notifications, billing, and connected accounts. Use a clean, professional look.”

**移动结账屏幕**

> “Checkout screen for a mobile shopping app. Show an order summary, a field for a promo code, and a prominent button to complete the purchase.”

这些提示词之所以有效，不是因为它们使用设计语言，而是因为它们清楚地描述了屏幕的目的、内容和背景。这就是您需要的全部内容。

L’endpoint `/mcp` richiede un `access_token` Supabase passato come token Bearer. La maggior parte dei client MCP lo ottiene automaticamente tramite il flusso OAuth 2.1 PKCE. Puoi anche fornire un token manualmente per i test.

[​](https://docs.flowstep.ai/it/mcp/authentication#flusso-oauth-2-1-pkce)

Flusso OAuth 2.1 PKCE
--------------------------------------------------------------------------------------------------

Flowstep implementa un server di autorizzazione OAuth 2.1 completo presso `https://api.flowstep.ai`. I client MCP lo scoprono e completano il flusso automaticamente: aprono una finestra del browser per accedere, quindi gestiscono lo scambio di token dietro le quinte.

### 

[​](https://docs.flowstep.ai/it/mcp/authentication#metodi-di-accesso-supportati)

Metodi di accesso supportati

La pagina di autorizzazione presso `/oauth/authorize` supporta:

*   **Email/password** — qualsiasi account Flowstep con una password impostata
*   **Google SSO** — reindirizza tramite l’autenticazione sociale Supabase, ritorna al client automaticamente

### 

[​](https://docs.flowstep.ai/it/mcp/authentication#creazione-dell%E2%80%99account-per-gli-utenti-del-connettore-claude-ai)

Creazione dell’account per gli utenti del connettore claude.ai

La pagina di accesso OAuth non include un modulo di iscrizione. Se ti stai connettendo tramite il connettore personalizzato di claude.ai e non hai ancora un account Flowstep, creane uno prima su [app.flowstep.ai](https://app.flowstep.ai/)
, quindi ritorna alla configurazione del connettore per autenticarti.

[​](https://docs.flowstep.ai/it/mcp/authentication#fallback-dei-cookie)

Fallback dei cookie
----------------------------------------------------------------------------------------------

Se non è presente alcuna intestazione `Authorization`, il middleware ricorre a una sessione Supabase basata su cookie. Questo funziona quando accedi a `/mcp` direttamente da un browser con una sessione Flowstep attiva. I client MCP utilizzano sempre il percorso Bearer.

[​](https://docs.flowstep.ai/it/mcp/authentication#token-manuale-test)

Token manuale (test)
----------------------------------------------------------------------------------------------

Per chiamare l’endpoint direttamente senza un flusso OAuth del client:

1.  Accedi a [app.flowstep.ai](https://app.flowstep.ai/)
     nel tuo browser
2.  Apri DevTools → Console ed esegui:

    const pairs = document.cookie.split("; ").map((c) => {
      const i = c.indexOf("=");
      return [c.slice(0, i), c.slice(i + 1)];
    });
    const authPairs = pairs
      .filter(([k]) => /^sb-.+-auth-token(\.\d+)?$/.test(k))
      .sort(([a], [b]) => a.localeCompare(b));
    const raw = authPairs.map(([, v]) => decodeURIComponent(v)).join("");
    const session = JSON.parse(
      raw.startsWith("base64-") ? atob(raw.slice(7)) : raw,
    );
    console.log(session.access_token);
    

3.  Passa il token come intestazione:

    curl -X POST https://api.flowstep.ai/mcp \
      -H "Authorization: Bearer <access_token>" \
      -H "Content-Type: application/json" \
      -H "Accept: application/json, text/event-stream" \
      -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
    

Le sessioni MCP durano 30 giorni — il server aggiorna trasparentemente il token sottostante, quindi i client che utilizzano il flusso OAuth non devono ri-autenticarsi durante l’uso normale. Un token estratto manualmente come quello sopra scade comunque dopo circa un’ora; è solo per i test rapidi.

Sie benötigen ein Flowstep-Konto, bevor Sie eine Verbindung herstellen. Erstellen Sie eines unter [app.flowstep.ai](https://app.flowstep.ai/)
.

[​](https://docs.flowstep.ai/de/mcp/clients/cursor#verbindung-%C3%BCberpr%C3%BCfen)

Verbindung überprüfen
------------------------------------------------------------------------------------------------------------

Geben Sie in einem Cursor-Chat Folgendes ein:

    List my Flowstep files
    

Wenn der Tool-Aufruf erfolgreich ist, funktioniert die Verbindung.

[​](https://docs.flowstep.ai/de/mcp/clients/cursor#verwendungsbeispiel)

Verwendungsbeispiel
----------------------------------------------------------------------------------------------

    Create a Flowstep file called "Onboarding", generate a mobile sign-up screen
    with name, email, and password fields, then show me the image.
    

Cursor ruft `create-file` → `ai-prompt` → `get-screen-image` der Reihe nach auf.
