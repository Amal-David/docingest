# Hardware Setup (Main PC) | DMA

For the complete documentation index, see [llms.txt](https://ducks-services.gitbook.io/dma/llms.txt)
. This page is also available as [Markdown](https://ducks-services.gitbook.io/dma/dma-card/hardware-setup-main-pc.md)
.

### 🔌 1. Power Down Your Game PC[](https://ducks-services.gitbook.io/dma#id-1.-power-down-your-game-pc)

*   Completely shut down your **main PC (Game PC)** before inserting the DMA card.
    

* * *

### 🧩 2. Insert the DMA Card[](https://ducks-services.gitbook.io/dma#id-2.-insert-the-dma-card)

*   Plug your DMA card into **any available PCI-e slot** on your Game PC.
    

![](https://ducks-services.gitbook.io/dma/~gitbook/image?url=https%3A%2F%2F3431908052-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FIYId8chK5X4hf9NjSeQv%252Fuploads%252FIc9SnNetEMSvn60gdBBI%252FInstall.gif%3Falt%3Dmedia%26token%3Def1f3b1a-51a1-475f-b469-48d2f87c48ec&width=768&dpr=3&quality=100&sign=93e40ef2&sv=2)

* * *

### 🔗 3. Connect to 2nd PC[](https://ducks-services.gitbook.io/dma#id-3.-connect-to-2nd-pc)

*   Use the included **USB data cable** to connect the **Data Port** on the DMA card to your **2nd PC** (second PC).
    

![](https://ducks-services.gitbook.io/dma/~gitbook/image?url=https%3A%2F%2F3431908052-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FIYId8chK5X4hf9NjSeQv%252Fuploads%252FTgc9N3uGzuurQ03LqaRf%252FDMA.png%3Falt%3Dmedia%26token%3Dfa312c0a-d0e5-4389-97b1-8412c48784e6&width=768&dpr=3&quality=100&sign=5bde4960&sv=2)

* * *

### ⚙️ 4. Enter BIOS on Game PC[](https://ducks-services.gitbook.io/dma#id-4.-enter-bios-on-game-pc)

*   Power on your Game PC and **enter BIOS/UEFI setup**:
    
    *   Usually done by pressing `DEL`, `F2`, or `ESC` during boot (varies by motherboard).
        
    

* * *

### 🚫 5. Disable Virtualization (Required)[](https://ducks-services.gitbook.io/dma#id-5.-disable-virtualization-required)

Virtualization interferes with DMA memory access and **must be disabled**.

#### Intel CPUs:[](https://ducks-services.gitbook.io/dma#intel-cpus)

*   Disable:
    
    *   `VT-d`
        
    *   `Intel Virtualization Technology`
        
    *   `IOMMU` (if available)
        
    

#### AMD CPUs:[](https://ducks-services.gitbook.io/dma#amd-cpus)

*   Disable:
    
    *   `SVM`
        
    *   `IOMMU`
        
    

* * *

### ⚠️ 6. Optional (If Available)[](https://ducks-services.gitbook.io/dma#id-6.-optional-if-available)

*   **Disable NX-Bit / Execute Disable Bit** _(Only if listed in your BIOS. If not, skip this step.)_
    
*   **Set PCIe Slot to Gen1** _(Recommended for maximum compatibility. Found under_ `_Advanced > PCI Settings_` _or similar.)_
    

* * *

### 🧱 7. Disable Memory Integrity in Windows[](https://ducks-services.gitbook.io/dma#id-7.-disable-memory-integrity-in-windows)

On your **Game PC**, do the following:

1.  Open **Windows Security**
    
2.  Navigate to: `Device Security > Core Isolation > Core Isolation Details`
    
3.  **Turn off "Memory Integrity"**
    

> If this section won’t load, the setting may already be disabled or unsupported — no action needed.

📖 [Reference – Microsoft Guide](https://support.microsoft.com/en-us/windows/options-to-optimize-gaming-performance-in-windows-11-a255f612-2949-4373-a566-ff6f3f474613)

* * *

### ✅ You're Done[](https://ducks-services.gitbook.io/dma#youre-done)

Your DMA card is now installed and your Game PC is properly configured.

> 🖥️ **Next Step:** It is now **recommended to proceed with the second PC (2ndPC) setup** to complete the process. Refer to the [35t Driver Setup (2nd PC)](https://ducks-services.gitbook.io/dma/dma-card/data-driver-setup-2nd-pc)
>  or [75t Driver Setup (2nd PC)](https://ducks-services.gitbook.io/dma/dma-card/jtag-driver-setup-2nd-pc)
>  for instructions.

If you run into issues, double-check that virtualization is fully disabled and all hardware connections are secure.

2.  Look for one of these scenarios:

*   Device appears as: **FTDI FT601 USB 3.0 Bridge Device**
    
*   Located under: **Universal Serial Bus devices**
    
*   **Status**: Working properly → Skip this guide
    

#### ⚠️ **Missing Driver (Install now)**[](https://ducks-services.gitbook.io/dma/dma-card/data-driver-setup-2nd-pc#missing-driver-install-now)

*   Located under: **Universal Serial Bus devices**
    
*   **Action**: Right-click → **Uninstall device** → Check 'Delete driver'
    
*   Then proceed with installation below

# Troubleshooting | DMA

For the complete documentation index, see [llms.txt](https://ducks-services.gitbook.io/dma/llms.txt)
. This page is also available as [Markdown](https://ducks-services.gitbook.io/dma/dma-card/troubleshooting.md)
.

### ❌ `[FAIL] VMM INIT FAILED.`[](https://ducks-services.gitbook.io/dma/dma-card/troubleshooting#fail-vmm-init-failed)

**Cause:** Your DMA card or connection is "hung," often due to a fast reboot or system waking from sleep.

**Fix:**

*   Fully shut down your **Game PC** (do **not** reboot).
    
*   Wait **5–10 seconds**, then power it back on (a **cold boot**).
    
*   This resolves the issue **99% of the time**.
    

* * *

### ❌ `FPGA: ERROR: Unable to connect to USB/FT601 device [0,v0.0,0000]`[](https://ducks-services.gitbook.io/dma/dma-card/troubleshooting#fpga-error-unable-to-connect-to-usb-ft601-device-0-v0.0-0000)

**Cause:** FTDI driver not installed or incorrect port used.

**Fix:**

*   Make sure the [**FTDI driver**](https://ducks-services.gitbook.io/dma/dma-card/data-driver-setup-2nd-pc)
     is installed on your **Radar PC**.
    
*   Confirm you are using the **Data Port** on the DMA card (not the power-only port).
    

* * *

### ❌ `Failed to retrieve Physical Memory Map!`[](https://ducks-services.gitbook.io/dma/dma-card/troubleshooting#failed-to-retrieve-physical-memory-map)

**Cause:** Unstable or faulty USB connection.

**Fix:**

*   Reseat your USB cable on both ends.
    
*   Try a different **USB 3.0 cable** and **USB port**.
    
*   As a last resort, re-install Windows on your **Game PC**.
    

* * *

### ❌ `[SYMBOL] Offline symbols unavailable - file 'info.db' not found.`[](https://ducks-services.gitbook.io/dma/dma-card/troubleshooting#symbol-offline-symbols-unavailable-file-info.db-not-found)

**Cause:** PCILeech cannot retrieve symbol data for memory interpretation.

**Fix:**

*   Ensure the tool was **unzipped completely**.
    
*   Check that both `symsrv.dll` and `dbghelp.dll` are in the same folder.
    
*   Verify you have **active internet** and no firewalls are blocking access.
    
*   Still stuck? ➤ [Download latest `info.db` manually](https://github.com/ufrisk/MemProcFS/releases)
     and place it in your tool folder.
    

* * *

### ⚠️ `FPGA: TINY PCIe TLP Algorithm auto-selected!`[](https://ducks-services.gitbook.io/dma/dma-card/troubleshooting#fpga-tiny-pcie-tlp-algorithm-auto-selected)

**Cause:** DMA card running at lower speeds due to poor USB connection or firmware.

**Fix:**

*   Check USB cable is **firmly connected** on both ends.
    
*   Try a **different USB port**.
    
*   In some cases, outdated or restricted firmware may reduce speed.
    

* * *

### ❌ `[CORE] Initialization Failed. Unable to locate valid DTB / auto-identify OS`[](https://ducks-services.gitbook.io/dma/dma-card/troubleshooting#core-initialization-failed.-unable-to-locate-valid-dtb-auto-identify-os)

**Cause:** Incorrect BIOS settings or unstable USB link.

**Fix:**

*   Review and apply **all required BIOS changes** on your **Game PC**.
    
*   Double-check USB cable stability and port selection.
    
*   As a last resort, re-install Windows on the **Game PC**.
    

* * *

### ❌ `DMA Test Tool – Test Result: FAIL / General Failures`[](https://ducks-services.gitbook.io/dma/dma-card/troubleshooting#dma-test-tool-test-result-fail-general-failures)

**Cause:** Speed or throughput below operational threshold.

#### 📉 Common Triggers:[](https://ducks-services.gitbook.io/dma/dma-card/troubleshooting#common-triggers)

*   **Speed under 4000 Mem/sec**
    
*   **Throughput under 125 MB/s**
    

#### 🛠 Fixes:[](https://ducks-services.gitbook.io/dma/dma-card/troubleshooting#fixes)

1.  Use a **USB 3.0 data-rated** cable (not charging-only).
    
2.  Make sure cable is seated **securely**.
    
3.  Switch to **High Performance** power plan on Radar PC.
    
4.  Try different USB ports and cables.
    
5.  **Reseat** the DMA card in its PCIe slot.
    
6.  Ensure **bracket isn't interfering** with USB connection.
    
7.  Check that your **Radar PC meets system requirements**.
    
8.  Some firmware (e.g., Vanguard/Faceit bypass) may cause reduced speed.
    

> 🧪 **Recommendation:** Run the DMA speed test for **~360 seconds** to check for connection stability (dropouts). If stable, slightly low speeds may still work fine.

* * *

### ❗ DMA Software: Not Loading / Entities Missing / Glitchy Behavior[](https://ducks-services.gitbook.io/dma/dma-card/troubleshooting#dma-software-not-loading-entities-missing-glitchy-behavior)

**Cause:** **Paged Out Memory** — the target process's memory is moved to the page file due to high memory pressure.

#### ⚠️ Why This Matters:[](https://ducks-services.gitbook.io/dma/dma-card/troubleshooting#why-this-matters)

*   DMA cannot read from the Windows page file, leading to undefined behavior in cheat/radar software.
    

#### 🔧 Fix:[](https://ducks-services.gitbook.io/dma/dma-card/troubleshooting#fix)

*   **Install more RAM** in your **Game PC**.
    
*   (Optional) Disable the **System Page File** in Windows _(Not Recommended: May cause system instability or BSOD if memory is exhausted)._
    

* * *

### 📩 Still Stuck?[](https://ducks-services.gitbook.io/dma/dma-card/troubleshooting#still-stuck)

If none of the above solutions work, please [**open a support ticket**](https://ducks-services.com/discord)
 with:

*   A description of your issue
    
*   A screenshot or full error log
    
*   Your DMA card model and current setup details
    

We’re here to help.

*   The 2nd monitor should be connected to its **respective PC**, not the Fuser.

*   This indicates **not all HDMI cables are HDMI 2.0**.
    
*   Use **three HDMI 2.0 cables** for the Fuser setup.

# Troubleshooting & Indicators | DMA

For the complete documentation index, see [llms.txt](https://ducks-services.gitbook.io/dma/llms.txt)

#### Indicator Lights (Front Panel)[](https://ducks-services.gitbook.io/dma/4k-dc500-fuser/troubleshooting-and-indicators#indicator-lights-front-panel)

*   **DC** → Monitor detected
    
*   **RX0** → Host PC detected
    
*   **RX1** → Secondary PC detected
    
*   **RH** → Overlay enabled
    

If a light is **off**, that signal is not detected DC500 User Manual

* * *

#### On-Screen Info (Press K1)[](https://ducks-services.gitbook.io/dma/4k-dc500-fuser/troubleshooting-and-indicators#on-screen-info-press-k1)

Shows:

*   MAIN: Host resolution & Hz
    
*   SECOND: Secondary resolution & Hz
    
*   ALPHA: Overlay strength
    
*   BD: Firmware date
    
*   UID: Device ID
    
*   EDID: Mode A or B
    
*   SEC: Activation status
    

* * *

#### EDID Modes (Critical)[](https://ducks-services.gitbook.io/dma/4k-dc500-fuser/troubleshooting-and-indicators#edid-modes-critical)

*   **Mode A (Default)** – Universal compatibility
    
*   **Mode B** – Native display compatibility
    

If you get **no image**, switch to **Mode B** (Long-press K1 for 5 seconds → auto reboot)

* * *

#### Common Fixes (90% of Issues)[](https://ducks-services.gitbook.io/dma/4k-dc500-fuser/troubleshooting-and-indicators#common-fixes-90-of-issues)

**No Image but All Lights On**

1.  Long-press **K3** (factory reset)
    
2.  Power off everything → reconnect cables
    
3.  Reset monitor to factory defaults
    
4.  Switch EDID Mode (K1 long press)
    

**Black Screen When Launching Games**

*   Disable **G-SYNC**
    
*   Match in-game resolution to desktop
    
*   Reset GPU control panel settings
    

**Repeating / Tiled Screen**

*   Set **same resolution on both PCs**
    
*   Switch EDID Mode
    
*   Factory reset (K3)
    

**Artifacts / Image Shift**

*   Factory reset (K3)
    
*   Reboot fuser
    

* * *

### Final Notes[](https://ducks-services.gitbook.io/dma/4k-dc500-fuser/troubleshooting-and-indicators#final-notes)

*   Always use **certified HDMI 2.1 FRL 48 Gbps or DP 1.4+ cables**
    
*   Plug cables into the **GPU**, not motherboard ports
    
*   When in doubt: **K3 long-press reset**

# Intro & Requirements | DMA

For the complete documentation index, see [llms.txt](https://ducks-services.gitbook.io/dma/llms.txt)
. This page is also available as [Markdown](https://ducks-services.gitbook.io/dma/4k-dc500-fuser/intro-and-requirements.md)
.

#### What the DC500 Does[](https://ducks-services.gitbook.io/dma/4k-dc500-fuser/intro-and-requirements#what-the-dc500-does)

The DC500 is a **hardware video fuser** that combines:

*   A **Host (gaming) PC**
    
*   A **Secondary PC** into **one single display output** without software capture or latency.
    

It supports **extremely high refresh rates** at 1080p, 1440p, and 4K depending on interface and GPU.

* * *

#### Supported Interfaces[](https://ducks-services.gitbook.io/dma/4k-dc500-fuser/intro-and-requirements#supported-interfaces)

⚠️ **You must use only ONE interface type at a time**

*   **HDMI 2.1 (FRL 48 Gbps)**
    
*   **DisplayPort 1.4 / 2.1**
    

❌ HDMI + DP mixing is **not supported**

* * *

#### Resolution & Refresh Rate Support[](https://ducks-services.gitbook.io/dma/4k-dc500-fuser/intro-and-requirements#resolution-and-refresh-rate-support)

**HDMI 2.1**

*   1080p: up to **480–540Hz**
    
*   1440p: up to **320–355Hz**
    
*   4K: up to **144–158Hz**
    

**DisplayPort 1.4**

*   1080p: up to **480Hz**
    
*   1440p: up to **320Hz**
    
*   4K: up to **144Hz**
    

> Actual limits depend on GPU generation and DSC behavior DC500 User Manual

* * *

#### Minimum Hardware Requirements[](https://ducks-services.gitbook.io/dma/4k-dc500-fuser/intro-and-requirements#minimum-hardware-requirements)

**Host & Secondary PC GPUs**

*   HDMI: NVIDIA RTX 3060 / AMD RX 6500 XT or better
    
*   DP: NVIDIA GTX 10-series / AMD RX 500-series or newer
    

**Secondary PC CPU**

*   Minimum **6 threads**
    

**Monitor**

*   HDMI 2.1 FRL 48 Gbps **or**
    
*   DP 1.4 / DP 2.1 input

# Troubleshooting

### ❌ \`\[FAIL\] VMM INIT FAILED.\`

\*\*Cause:\*\*\\
Your DMA card or connection is "hung," often due to a fast reboot or system waking from sleep.

\*\*Fix:\*\*

\* Fully shut down your \*\*Game PC\*\* (do \*\*not\*\* reboot).
\* Wait \*\*5–10 seconds\*\*, then power it back on (a \*\*cold boot\*\*).
\* This resolves the issue \*\*99% of the time\*\*.

\*\*\*

### ❌ \`FPGA: ERROR: Unable to connect to USB/FT601 device \[0,v0.0,0000\]\`

\*\*Cause:\*\*\\
FTDI driver not installed or incorrect port used.

\*\*Fix:\*\*

\* Make sure the \[\*\*FTDI driver\*\*\](/dma/dma-card/data-driver-setup-2nd-pc.md) is installed on your \*\*Radar PC\*\*.
\* Confirm you are using the \*\*Data Port\*\* on the DMA card (not the power-only port).

\*\*\*

### ❌ \`Failed to retrieve Physical Memory Map!\`

\*\*Cause:\*\*\\
Unstable or faulty USB connection.

\*\*Fix:\*\*

\* Reseat your USB cable on both ends.
\* Try a different \*\*USB 3.0 cable\*\* and \*\*USB port\*\*.
\* As a last resort, re-install Windows on your \*\*Game PC\*\*.

\*\*\*

### ❌ \`\[SYMBOL\] Offline symbols unavailable - file 'info.db' not found.\`

\*\*Cause:\*\*\\
PCILeech cannot retrieve symbol data for memory interpretation.

\*\*Fix:\*\*

\* Ensure the tool was \*\*unzipped completely\*\*.
\* Check that both \`symsrv.dll\` and \`dbghelp.dll\` are in the same folder.
\* Verify you have \*\*active internet\*\* and no firewalls are blocking access.
\* Still stuck?\\
  ➤ \[Download latest \`info.db\` manually\](https://github.com/ufrisk/MemProcFS/releases) and place it in your tool folder.

\*\*\*

### ⚠️ \`FPGA: TINY PCIe TLP Algorithm auto-selected!\`

\*\*Cause:\*\*\\
DMA card running at lower speeds due to poor USB connection or firmware.

\*\*Fix:\*\*

\* Check USB cable is \*\*firmly connected\*\* on both ends.
\* Try a \*\*different USB port\*\*.
\* In some cases, outdated or restricted firmware may reduce speed.

\*\*\*

### ❌ \`\[CORE\] Initialization Failed. Unable to locate valid DTB / auto-identify OS\`

\*\*Cause:\*\*\\
Incorrect BIOS settings or unstable USB link.

\*\*Fix:\*\*

\* Review and apply \*\*all required BIOS changes\*\* on your \*\*Game PC\*\*.
\* Double-check USB cable stability and port selection.
\* As a last resort, re-install Windows on the \*\*Game PC\*\*.

\*\*\*

### ❌ \`DMA Test Tool – Test Result: FAIL / General Failures\`

\*\*Cause:\*\*\\
Speed or throughput below operational threshold.

#### 📉 Common Triggers:

\* \*\*Speed under 4000 Mem/sec\*\*
\* \*\*Throughput under 125 MB/s\*\*

#### 🛠 Fixes:

1. Use a \*\*USB 3.0 data-rated\*\* cable (not charging-only).
2. Make sure cable is seated \*\*securely\*\*.
3. Switch to \*\*High Performance\*\* power plan on Radar PC.
4. Try different USB ports and cables.
5. \*\*Reseat\*\* the DMA card in its PCIe slot.
6. Ensure \*\*bracket isn't interfering\*\* with USB connection.
7. Check that your \*\*Radar PC meets system requirements\*\*.
8. Some firmware (e.g., Vanguard/Faceit bypass) may cause reduced speed.

> 🧪 \*\*Recommendation:\*\* Run the DMA speed test for \*\*\\~360 seconds\*\* to check for connection stability (dropouts).\\
> If stable, slightly low speeds may still work fine.

\*\*\*

### ❗ DMA Software: Not Loading / Entities Missing / Glitchy Behavior

\*\*Cause:\*\*\\
\*\*Paged Out Memory\*\* — the target process's memory is moved to the page file due to high memory pressure.

#### ⚠️ Why This Matters:

\* DMA cannot read from the Windows page file, leading to undefined behavior in cheat/radar software.

#### 🔧 Fix:

\* \*\*Install more RAM\*\* in your \*\*Game PC\*\*.
\* (Optional) Disable the \*\*System Page File\*\* in Windows\\
  \*(Not Recommended: May cause system instability or BSOD if memory is exhausted).\*

\*\*\*

### 📩 Still Stuck?

If none of the above solutions work, please \[\*\*open a support ticket\*\*\](https://ducks-services.com/discord) with:

\* A description of your issue
\* A screenshot or full error log
\* Your DMA card model and current setup details

We’re here to help.

# Intro & Requirements

#### What the DC500 Does

The DC500 is a \*\*hardware video fuser\*\* that combines:

\* A \*\*Host (gaming) PC\*\*
\* A \*\*Secondary PC\*\*\\
  into \*\*one single display output\*\* without software capture or latency.

It supports \*\*extremely high refresh rates\*\* at 1080p, 1440p, and 4K depending on interface and GPU.

\*\*\*

#### Supported Interfaces

⚠️ \*\*You must use only ONE interface type at a time\*\*

\* \*\*HDMI 2.1 (FRL 48 Gbps)\*\*
\* \*\*DisplayPort 1.4 / 2.1\*\*

❌ HDMI + DP mixing is \*\*not supported\*\*

\*\*\*

#### Resolution & Refresh Rate Support

\*\*HDMI 2.1\*\*

\* 1080p: up to \*\*480–540Hz\*\*
\* 1440p: up to \*\*320–355Hz\*\*
\* 4K: up to \*\*144–158Hz\*\*

\*\*DisplayPort 1.4\*\*

\* 1080p: up to \*\*480Hz\*\*
\* 1440p: up to \*\*320Hz\*\*
\* 4K: up to \*\*144Hz\*\*

> Actual limits depend on GPU generation and DSC behavior DC500 User Manual

\*\*\*

#### Minimum Hardware Requirements

\*\*Host & Secondary PC GPUs\*\*

\* HDMI: NVIDIA RTX 3060 / AMD RX 6500 XT or better
\* DP: NVIDIA GTX 10-series / AMD RX 500-series or newer

\*\*Secondary PC CPU\*\*

\* Minimum \*\*6 threads\*\*

\*\*Monitor\*\*

\* HDMI 2.1 FRL 48 Gbps \*\*or\*\*
\* DP 1.4 / DP 2.1 input

# Troubleshooting & Indicators

#### Indicator Lights (Front Panel)

\* \*\*DC\*\* → Monitor detected
\* \*\*RX0\*\* → Host PC detected
\* \*\*RX1\*\* → Secondary PC detected
\* \*\*RH\*\* → Overlay enabled

If a light is \*\*off\*\*, that signal is not detected DC500 User Manual

\*\*\*

#### On-Screen Info (Press K1)

Shows:

\* MAIN: Host resolution & Hz
\* SECOND: Secondary resolution & Hz
\* ALPHA: Overlay strength
\* BD: Firmware date
\* UID: Device ID
\* EDID: Mode A or B
\* SEC: Activation status

\*\*\*

#### EDID Modes (Critical)

\* \*\*Mode A (Default)\*\* – Universal compatibility
\* \*\*Mode B\*\* – Native display compatibility

If you get \*\*no image\*\*, switch to \*\*Mode B\*\*\\
(Long-press K1 for 5 seconds → auto reboot)

\*\*\*

#### Common Fixes (90% of Issues)

\*\*No Image but All Lights On\*\*

1. Long-press \*\*K3\*\* (factory reset)
2. Power off everything → reconnect cables
3. Reset monitor to factory defaults
4. Switch EDID Mode (K1 long press)

\*\*Black Screen When Launching Games\*\*

\* Disable \*\*G-SYNC\*\*
\* Match in-game resolution to desktop
\* Reset GPU control panel settings

\*\*Repeating / Tiled Screen\*\*

\* Set \*\*same resolution on both PCs\*\*
\* Switch EDID Mode
\* Factory reset (K3)

\*\*Artifacts / Image Shift\*\*

\* Factory reset (K3)
\* Reboot fuser

\*\*\*

### Final Notes

\* Always use \*\*certified HDMI 2.1 FRL 48 Gbps or DP 1.4+ cables\*\*
\* Plug cables into the \*\*GPU\*\*, not motherboard ports
\* When in doubt: \*\*K3 long-press reset\*\*
