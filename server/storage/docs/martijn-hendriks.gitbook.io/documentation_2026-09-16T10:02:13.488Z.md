Gedachte achter de dongles[](https://martijn-hendriks.gitbook.io/archive#gedachte-achter-de-dongles)

-----------------------------------------------------------------------------------------------------

Enkel jaren gelden gestart met het ontwerpen, fabriceren van de dongles. Belangrijkste reden was toen dat de commerciële oplossingen kostbaar zijn, vaak met abonnement en je data zonder dat je het weet op de servers van de leverancier zet.

Het concept laat zich in enkele steekwoorden samenvatten:

*   Open source beschikbaar
    
*   Privacy: data blijft altijd van de gebruiker en wordt niet gedeeld
    
*   Veilig ontwerp
    
*   Geen abonnement
    
*   laagdrempelig: in kosten en gebruikerservaring
    

Primaire functies[](https://martijn-hendriks.gitbook.io/archive#primaire-functies)

-----------------------------------------------------------------------------------

*   Uitlezen van de slimme meter (via de p1 aansluiting)
    
*   Wifi koppeling met uw netwerk
    
*   Inzien van de actuele gegevens (Elektra/Gas)
    
*   Inzien van de energie geschiedenis (tabel/grafisch)
    
*   Eigen web server (standalone) voor het kunnen inzien van alle gegevens en configureren
    
*   Lokaal opslaan van de gegevens met een bewaartermijn van maximaal 2 jaar
    
*   Delen van de gegevens met andere systemen

### Quick start[](https://martijn-hendriks.gitbook.io/archive/geavanceerd/telnet-toegang#quick-start)

De dongle is via telnet te naderen. Dit kan op een Mac, Windows of Linus systeem. Hieronder een voorbeeld op een Mac nadat Terminal app gestart is.

Copy

    telnet p1-dongle.local

### Menu[](https://martijn-hendriks.gitbook.io/archive/geavanceerd/telnet-toegang#menu)

Na Telnet toegang wordt onderstaande menu getoond.

![](https://martijn-hendriks.gitbook.io/archive/~gitbook/image?url=https%3A%2F%2F942759145-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FJNPScwSpoihQIGBzQp0p%252Fuploads%252Fjs3aPjtzMccJVM7HMidW%252FSchermafbeelding%25202022-06-19%2520om%252015.01.05.png%3Falt%3Dmedia%26token%3D459ab010-0e4c-458a-b0eb-14bb128d792f&width=768&dpr=3&quality=100&sign=55c1c131bcabf43370e622fe8dd1fd60&sv=3)

In het menu is het volgende te zien:

*   dongle versie
    
*   mac adres van de dongle
    
*   menu commando's
    

Een \* voor een commando geeft aan dat dit alleen een hoofdletter dient te zijn. W <return> = force wifi reset.

Een + achter een letter geeft aan dat er een invoerveld of keuze volgt.

De logging van de dongle komt continue langs en kan op een hoger loglevel gezet worden door Verbose (V) in te drukken.

### Remote update[](https://martijn-hendriks.gitbook.io/archive/geavanceerd/telnet-toegang#remote-update)

Download eerst de data bestanden (RNG files) voordat u een update uitvoert.

Zowel de firmware als het data segment kunnen geupdate worden.

Firmware update:

Voer U in. Een keuze veld volgt. Geeft hier versie nummer op: bv 3.5.0

Filesystem update:

Door S in te voeren wordt file system update gestart. Voer het versie nummer in van de filesystem bundle om de update te starten.

Filesystem update wist al je data!!!

### Update locatie[](https://martijn-hendriks.gitbook.io/archive/geavanceerd/telnet-toegang#update-locatie)

Standaard zal er geupdate worden van de ota.smart-stuff.nl/ locatie. Deze verwijzing kan worden aangepast in de settingsfile op de dongel.

Locaties kunnen alleen http endpoints zijn.

Browser toegang[](https://martijn-hendriks.gitbook.io/archive/snelle-start/startscherm#browser-toegang)

--------------------------------------------------------------------------------------------------------

De dongle is via de browser te benaderen met url of het ip-adres. De benadering via de url is het meest prettige. Soms blokkert de router het gebruik van de url. Benader dan de dongle via het ip-adres.

Het ip-adres van de dongle wordt pas na aanmelden op het wifi-netwerk uitgegeven is vooraf niet bekend. Het ip-adres kan op twee manieren worden verkregen, namelijk:

1.  Door in uw router op zoek te gaan naar de dongle en daar het ip-adres uit te lezen.
    
2.  Via de site [api.smart-stuff.nl/ip](http://api.smart-stuff.nl/checkip)
     door het mac-adres in te vullen (staat rechts onder op de adres-sticker kunt u tot 1 uur na installatie het ip-adres vinden. Na 1 uur is het ip-adres niet meer opvraagbaar. Na opnieuw opstarten van de dongle gaat het uur weer in.

For the complete documentation index, see [llms.txt](https://martijn-hendriks.gitbook.io/archive/llms.txt)

Slimme meter versies[](https://martijn-hendriks.gitbook.io/archive/snelle-start/wifi-koppeling#slimme-meter-versies)

---------------------------------------------------------------------------------------------------------------------

Er zijn diverse versies en merken slimme meters in omloop. Meest voorkomende zijn versies 2,3,4 en 5. De laatste jaren worden alleen versie 5 meters geïnstalleerd. De versie staat vaak ergens op de meter met de aanduiding DSMR of SMR er voor. Via het type nummer van de meter kan dit opgezocht worden op het internet.

Op versie 5 meters kan de dongle zo aangesloten worden zonder extra voeding. Voor de versie 2,3 en 4 meters dient een aparte usb adapter + kabel gebruikt te worden. Dit kan elke oude usb adapter zijn die u nog heeft liggen.

In België zijn het altijd versie 5 meters.

Soms is een usb adapter nodig om de dongle te voeden

Enkele versie 5 meters zijn kritisch waardoor helaas een usb adapter aangesloten dient te worden op de dongle.

Koppelen[](https://martijn-hendriks.gitbook.io/archive/snelle-start/wifi-koppeling#koppelen)

---------------------------------------------------------------------------------------------

Volg de onderstaande stappen om de dongle te koppelen met uw wifi-netwerk.

*   Optioneel: sluit een usb adapter aan
    
*   Steek de (rj12) plug van de dongle in de P1 aansluiting van de slimme meter. Deze is vaak afgeschermd en te herkennen aan opschrift P1
    
*   De blauwe led van de dongle licht een keer kort op. Vanaf nu wordt er een wifi hotspot opgebouwd met de naam P1-Dongel

hotspot te vinden via netwerken

*   Klik op het P1-Dongle netwerk en na een tijdje zal er een scherm zoals hieronder verschijnen
    

Verschijnt de popup niet binnen 1 minuut, type dan in de browser [http://192.168.4.1](http://192.168.4.1/)

### Dashboard[](https://martijn-hendriks.gitbook.io/archive/snelle-start/schermuitleg#dashboard)

Het dashboard is een combinatie van actuele en historische gegevens van maximaal 3 dagen. Het aantal onderdelen is afhankelijk van uw situatie, heeft u bv. geen gasaansluiting dan zult u deze niet zien natuurlijk. Hieronder alle mogelijkheden op een rijtje.

Sommige dashboard zaken zijn in te stellen. Zie Frontend instellingen in geavanceerd

Actueel (altijd zichtbaar)[](https://martijn-hendriks.gitbook.io/archive/snelle-start/schermuitleg#actueel-altijd-zichtbaar)

*   Levert u systeem terug dan is de kop groen, neemt u af dan wordt deze rood.
    
*   Heeft u geen energie opwekking zal de kop altijd blauw blijven
    
*   Heeft u 1 fase systeem dan is maar een boog zichtbaar anders alle fases.
    
*   Per boog is het actuele stroomverbruik zichtbaar en onder in het totale
    
*   De belasting (load balance) is via deze boven mooi te zien
    
*   Onder Actueel \[kW\] is de actuele totale belasting/teruglevering te zien
    
*   min/max zijn de minimale en maximale waardes gemeten zolang de webpagina actief
    

Afname (altijd zichtbaar)[](https://martijn-hendriks.gitbook.io/archive/snelle-start/schermuitleg#afname-altijd-zichtbaar)

*   Boog zijn de gegevens van vandaag, gisteren en eergisteren
    
*   Daaronder de afname van vandaag
    
*   Afname = wat afgenomen wordt van het net
    

Teruglevering (alleen bij systemen die terugleveren)[](https://martijn-hendriks.gitbook.io/archive/snelle-start/schermuitleg#teruglevering-alleen-bij-systemen-die-terugleveren)

*   Boog zijn de gegevens van vandaag, gisteren en eergisteren
    
*   Daaronder de teruglevering van vandaag
    
*   Teruglevering = wat het netwerk heeft ontvangen van uw zelf opgewekte energie
    

Afname - Terug (alleen bij systemen die terugleveren)[](https://martijn-hendriks.gitbook.io/archive/snelle-start/schermuitleg#afname-terug-alleen-bij-systemen-die-terugleveren)

# Extern toegang | Archive

For the complete documentation index, see [llms.txt](https://martijn-hendriks.gitbook.io/archive/llms.txt)
. This page is also available as [Markdown](https://martijn-hendriks.gitbook.io/archive/geavanceerd/extern-toegang.md)

Met externe toegang kunt u vanaf buiten u netwerk naar de dongle. Juiste configuratie is essentieel zodat **onbevoegde GEEN toegang** kunnen krijgen tot dongle/data en eventueel uw netwerk.

Als u niet weet wat u aan het doen bent is het verstandig om eerst in te lezen via het internet wat port forwaring betekent.

Zodra de dongle gekoppeld is aan uw Wifi-netwerk kunt u via uw Wifi-netwerk de dongle altijd bereiken. Mocht u het ook prettig vinden om buiten uw wifi-netwerk (onderweg, op werk) bij de dongle te kunnen dan is dat mogelijk. Hiervoor dient u uw router aan te passen zodat er vanaf buiten uw netwerk door de router naar de dongle gegaan kan worden. Dit doet u door port-forwarding te configureren in uw router.

### Alleen toegang voor bevoegde[](https://martijn-hendriks.gitbook.io/archive/geavanceerd/extern-toegang#alleen-toegang-voor-bevoegde)

Om er voor te zorgen dan onbevoegden geen toegang kunnen krijgen tot uw netwerk dient de dongle te worden afgeschermd.

Vanaf firmware versie 4.3.0 of 3.5.0 is gebruik te maken van deze functie i.v.m instellen van de autorisatie

Hieronder een klein stappenplannentje.

#### Instellen autorisatie[](https://martijn-hendriks.gitbook.io/archive/geavanceerd/extern-toegang#instellen-autorisatie)

Download het bestand DSMRsettings.json en pas onderstaande sectie aan door gebruikersnaam en wachtwoord toe te voegen.

Let op! gebruik lange wachtwoorden! minimaal 8 karakters met enkele speciale tekens zoals # @ !.

Copy

    "basic-auth":{"user":"","pass":""

Indien er geen sectie basic-auth aanwezig is dan staan hieronder alle settings en kunt u de sectie zelf toevoegen of onderstaande in zijn geheel kopiëren. Kopieert u onderstaande dan de overige settings weer even goed zetten.

Copy

    {"Hostname":"P1-DONGLE/","EnergyDeliveredT1":0.100000001,"EnergyDeliveredT2":0.200000003,"EnergyReturnedT1":0.300000012,"EnergyReturnedT2":0.400000006,"GASDeliveredT":0.5,"EnergyVasteKosten":15.14999962,"GasVasteKosten":11.10999966,"SmHasFaseInfo":1,"TelegramInterval":2,"IndexPage":"/DSMRindexEDGE.html","MQTTbroker":"","MQTTbrokerPort":1883,"MQTTUser":"","MQTTpasswd":"","MQTTinterval":2,"MQTTtopTopic":"P1-DONGLE/","LED":true,"ota":"http://ota.smart-stuff.nl/","enableHistory":true,"watermeter":false,"waterfactor":1,"HAdiscovery":true,"basic-auth":{"user":"","pass":""}}`

Om de authenticatie uit te zetten dient bij **user** de inhoud gewist ("") te worden.

#### Port-forwarding in uw router[](https://martijn-hendriks.gitbook.io/archive/geavanceerd/extern-toegang#port-forwarding-in-uw-router)

Hoe u dit dient in te stellen ia afhankelijk van de fabrikant van uw modem/router. Ingrediënten om dit in te stellen zijn:

*   ip-adres van de dongle = stel dat dit 192.168.2.3 is
    
*   poortnummer van de dongle = 80
    
*   ip v4 adres van uw thuisnetwerk. Te zien via bv : [https://www.whatismyip.com/](https://www.whatismyip.com/)
    
*   poortnummer om de dongle te bereiken. dit is een keuze bijvoorbeeld poort 8888
    

In uw router geeft u dan aan dat poort 80 van de dongle (192.168.2.3) gekoppeld dient te worden aan poort 8888 van uw thuisnetwerk.

Als u dan via uw browser op de smartphone (4G aan / Wifi uit) http//:<ip-thuis>:8888 intypt zou u na goede configuratie bij de dongle dienen uit te komen.

Wilt u de dongle zelf van nieuwe firmware voorzien dan is deze gemakkelijk te flashen via de micro usb poort.

Er zijn meerdere mogelijkheden, namelijk:

*   andere DSMR-API versie flashen. zie: [https://github.com/mhendriks/P1-Dongel-ESP32](https://github.com/mhendriks/P1-Dongel-ESP32)
    
*   ESPHome versie flashen. zie : [https://github.com/mhendriks/esphome-p1](https://github.com/mhendriks/esphome-p1)
    
*   Zelfgemaakte software flashen.

### JTAG[](https://martijn-hendriks.gitbook.io/archive/geavanceerd/flashen#jtag)

# Software update | Archive

3.  MQTT

Webinterface[](https://martijn-hendriks.gitbook.io/archive/geavanceerd/software-update#webinterface)

-----------------------------------------------------------------------------------------------------

Handmatig een update bestand (binary) uploaden kan via de webbrowser.

Via het settings menu, Reset en update, Firmware Update kunt u bij het update scherm komen. Zie hieronder.

Nog sneller kan het via deze url: [http://p1-dongle.local/update](http://p1-dongle.local/update)

Druk op Selecteer file en geef aan welke binary er geupload dient te worden. Druk daarna op UPDATE

URL[](https://martijn-hendriks.gitbook.io/archive/geavanceerd/software-update#url)

-----------------------------------------------------------------------------------

Er is ook een mogelijkheid om via de webbrowser zonder upload een update te doen. Dit kan door in de browser balk direct achter de hoofd URL `/remote-update?version=3.5.0` in te voeren.

Bijvoorbeeld: `http://p1-dongle.local/remote-update?version=3.5.0`

MQTT[](https://martijn-hendriks.gitbook.io/archive/geavanceerd/software-update#mqtt)

Als er een MQTT broker is geïnstalleerd kan de update ook gestart worden vanuit een andere MQTT client. Dit door in een MQTT client het volgende te posten:

Topic : /update -> in de standaard configuratie is dat: P1-DONGLE/update Payload: bijvoorbeeld : 3`.5.0`

Update locatie[](https://martijn-hendriks.gitbook.io/archive/geavanceerd/software-update#update-locatie)

---------------------------------------------------------------------------------------------------------

Indien je een eigen ota server hebt kan je de remote update url in de DSMRsettings.json aanpassen naar wens.

# Inleiding

Wifi adapter voor het makkelijk kunnen uitlezen van een slimme meter.

## Gedachte achter de dongles

Enkel jaren gelden gestart met het ontwerpen, fabriceren van de dongles. Belangrijkste reden was toen dat de commerciële oplossingen kostbaar zijn, vaak met abonnement en je data zonder dat je het weet op de servers van de leverancier zet.&#x20;

Het concept laat zich in enkele steekwoorden samenvatten:

\* Open source beschikbaar
\* Privacy: data blijft altijd van de gebruiker en wordt niet gedeeld
\* Veilig ontwerp
\* Geen abonnement
\* laagdrempelig: in kosten en gebruikerservaring

## Primaire functies

\* Uitlezen van de slimme meter (via de p1 aansluiting)
\* Wifi koppeling met uw netwerk
\* Inzien van de actuele gegevens (Elektra/Gas)
\* Inzien van de energie geschiedenis (tabel/grafisch)
\* Eigen web server (standalone) voor het kunnen inzien van alle gegevens en configureren
\* Lokaal opslaan van de gegevens met een bewaartermijn van maximaal 2 jaar
\* Delen van de gegevens met andere systemen

## Slimme meter versies

Er zijn diverse versies en merken slimme meters in omloop. Meest voorkomende zijn versies 2,3,4 en 5. De laatste jaren worden alleen versie 5 meters geïnstalleerd. De versie staat vaak ergens op de meter met de aanduiding DSMR of SMR er voor. Via het type nummer van de meter kan dit opgezocht worden op het internet.

Op versie 5 meters kan de dongle zo aangesloten worden zonder extra voeding. Voor de versie 2,3 en 4 meters dient een aparte usb adapter + kabel gebruikt te worden. Dit kan elke oude usb adapter zijn die u nog heeft liggen.

In België zijn het altijd versie 5 meters.

{% hint style="warning" %}
Soms is een usb adapter nodig om de dongle te voeden
{% endhint %}

{% hint style="info" %}
Enkele versie 5 meters zijn kritisch waardoor helaas een usb adapter aangesloten dient te worden op de dongle.

Het dashboard is een combinatie van actuele en historische gegevens van maximaal 3 dagen. Het aantal onderdelen is afhankelijk van uw situatie, heeft u bv. geen gasaansluiting dan zult u deze niet zien natuurlijk. Hieronder alle mogelijkheden op een rijtje.

\* Heeft u 1 fase systeem dan is maar een boog zichtbaar anders alle fases.&#x20;

## MQTT velden

Afhankelijk van uw voorzieningen worden de mqtt velden verzonden door de dongle. Heeft u bijvoorbeeld geen Gas dan zal dit niet verzonden worden. Etc.

Meest praktische is dan ook om na het instellen van de dongle een MQTT sniffer te gebruiken zoals MQTT Explorer (<http://mqtt-explorer.com/>). U ziet dan alle berichten langskomen. Dat is makkelijk met integratie.

{% hint style="info" %}

{% endhint %}

### Twee soorten data

Er zijn twee soorten data die verzonden worden, namelijk:

\* \*\*static data\*\*\\
  deze data krijgt de retained flag mee. Deze data wordt eens per 10 minuten verzonden. Bijvoorbeeld ID van de slimme meter, ip-adres dongle, versienummer etc. Het is onnodig om deze telkens op te sturen.&#x20;
\* \*\*actuele data\*\*\\
  deze data wordt telkens verzonden

# Blauwe LED

Wat is de betekenis van de LED

De  dongels zijn uitgerust met een blauwe LED. Deze heeft meerdere functies, namelijk:

\* na inpluggen zal de LED ±1 seconde oplichten. Is dit niet het geval dan is er een probleem met stroom of met de dongel
\* Zodra de dongel WiFi connectie heeft zal de LED blijven branden.
\* Tijdens het lezen van de slimme meter data zal de LED kortstondig uit of aan gaan. Indien er Wifi verbinding is gaat de LED kort uit. Indien er geen Wifi is zal de LED kort aan gaan.

# Problemen met Wifi koppeling

Er kunnen meerdere redenen zijn waarom het koppelen met het wifi-netwerk niet lukt hieronder een opsomming inclusief hoe te handelen

### Dongle hotspot blijft komen (blauwe led brand niet continu

Dit komt in veel gevallen doordat de stroomtoevoer van de dongle afgeknepen wordt door de slimme meter. Het opbouwen van een wifi signaal kost kortstondig heel veel energie. Advies is om een usb adapter aan te sluiten op de dongle.

### Hotspot is niet te zien

Controleer of na het opstarten van de dongle de blauwe led een keer aan gaat en daarna weer uit. Knippert deze langzaam dan herstart de dongle zichzelf. Meestal is er dan een usb adapter nodig.

### De dongle is maar kort verbonden met het netwerk

Kunnen meerdere oorzaken zijn, namelijk:

\* Heeft u een zogenaamd verborgen wifi netwerk?
\* Staat het netwerk op kanaal 13?
\* Geen 2.4GHz netwerk

De dongle heeft een 2.4GHz netwerk nodig die niet verborgen is en liefst niet op kanaal 13.

# Extern toegang

{% hint style="danger" %}
Met externe toegang kunt u vanaf buiten u netwerk naar de dongle. Juiste configuratie is essentieel zodat \*\*onbevoegde GEEN toegang\*\* kunnen krijgen tot dongle/data en eventueel uw netwerk.&#x20;

Als u niet weet wat u aan het doen bent is het verstandig om eerst in te lezen via het internet wat port forwaring betekent.
{% endhint %}

Zodra de dongle gekoppeld is aan uw Wifi-netwerk kunt u via uw Wifi-netwerk de dongle altijd bereiken. Mocht u het ook prettig vinden om buiten uw wifi-netwerk (onderweg, op werk) bij de dongle te kunnen dan is dat mogelijk. Hiervoor dient u uw router aan te passen zodat er vanaf buiten uw netwerk door de router naar de dongle gegaan kan worden. Dit doet u door port-forwarding te configureren in uw router.&#x20;

### Alleen toegang voor bevoegde

Om er voor te zorgen dan onbevoegden geen toegang kunnen krijgen tot uw netwerk dient de dongle te worden afgeschermd.

{% hint style="info" %}
Vanaf firmware versie 4.3.0 of 3.5.0 is gebruik te maken van deze functie i.v.m instellen van de autorisatie
{% endhint %}

Hieronder een klein stappenplannentje.

#### Instellen autorisatie&#x20;

Download het bestand DSMRsettings.json en pas onderstaande sectie aan door gebruikersnaam en wachtwoord toe te voegen.&#x20;

{% hint style="warning" %}
Let op! gebruik lange wachtwoorden! minimaal 8 karakters met enkele speciale tekens zoals # @ !.
{% endhint %}

\`\`\`
"basic-auth":{"user":"","pass":""
\`\`\`

Indien er geen sectie basic-auth aanwezig is dan staan hieronder alle settings en kunt u de sectie zelf toevoegen of onderstaande in zijn geheel kopiëren. Kopieert u onderstaande dan de overige settings weer even goed zetten.

\`\`\`
{"Hostname":"P1-DONGLE/","EnergyDeliveredT1":0.100000001,"EnergyDeliveredT2":0.200000003,"EnergyReturnedT1":0.300000012,"EnergyReturnedT2":0.400000006,"GASDeliveredT":0.5,"EnergyVasteKosten":15.14999962,"GasVasteKosten":11.10999966,"SmHasFaseInfo":1,"TelegramInterval":2,"IndexPage":"/DSMRindexEDGE.html","MQTTbroker":"","MQTTbrokerPort":1883,"MQTTUser":"","MQTTpasswd":"","MQTTinterval":2,"MQTTtopTopic":"P1-DONGLE/","LED":true,"ota":"http://ota.smart-stuff.nl/","enableHistory":true,"watermeter":false,"waterfactor":1,"HAdiscovery":true,"basic-auth":{"user":"","pass":""}}\`
\`\`\`

Om de authenticatie uit te zetten dient bij \*\*user\*\* de inhoud gewist ("") te worden.

#### Port-forwarding in uw router&#x20;

Hoe u dit dient in te stellen ia afhankelijk van de fabrikant van uw modem/router. Ingrediënten om dit in te stellen zijn:

\* ip-adres van de dongle = stel dat dit 192.168.2.3 is
\* poortnummer van de dongle = 80
\* ip v4 adres van uw thuisnetwerk. Te zien via bv : <https://www.whatismyip.com/>
\* poortnummer om de dongle te bereiken. dit is een keuze bijvoorbeeld poort 8888

In uw router geeft u dan aan dat poort 80 van de dongle (192.168.2.3) gekoppeld dient te worden aan poort 8888 van uw thuisnetwerk.&#x20;

Als u dan via uw browser op de smartphone (4G aan / Wifi uit) http//:\\<ip-thuis>:8888 intypt zou u na goede configuratie bij de dongle dienen uit te komen.

-- het IDX nummer in te vullen.

# Software update

Manieren om de software te vernieuwen

Er zijn verschillende manier om de software te vernieuwen, namelijk via:

1. Webinterface
2. Url
3. MQTT
4. Telnet, zie \[Telnet toegang\](/archive/geavanceerd/telnet-toegang.md)
5. Flashen, zie \[Flashen\](/archive/geavanceerd/flashen.md)

{% hint style="info" %}
De software release historie is te vinden op: <https://github.com/mhendriks/DSMR-API-V2/releases>
{% endhint %}

{% hint style="info" %}
De laatste binarie voor de dongle is te downloaden via: <http://ota.smart-stuff.nl/3-sketch-latest\_4Mb.bin>
{% endhint %}

## Webinterface

Handmatig een update bestand (binary) uploaden kan via de webbrowser.

Via het settings menu, Reset en update, Firmware Update kunt u bij het update scherm komen. Zie hieronder.&#x20;

Nog sneller kan het via deze url: <http://p1-dongle.local/update>

!\[\](https://942759145-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FJNPScwSpoihQIGBzQp0p%2Fuploads%2F5kwmoRmK8T9AVtCIpPGh%2FSchermafbeelding%202022-06-19%20om%2013.54.39.png?alt=media\\&token=99c60f89-b76d-477d-b849-0720520d6ba4)

Druk op Selecteer file en geef aan welke binary er geupload dient te worden. Druk daarna op UPDATE

## URL

Er is ook een mogelijkheid om via de webbrowser zonder upload een update te doen. Dit kan door in de browser balk direct achter de hoofd URL \`/remote-update?version=3.5.0\` in te voeren.&#x20;

Bijvoorbeeld: \`http://p1-dongle.local/remote-update?version=3.5.0\`

## MQTT

Als er een MQTT broker is geïnstalleerd kan de update ook gestart worden vanuit een andere MQTT client. Dit door in een MQTT client het volgende te posten:

Topic : /update -> in de standaard configuratie is dat: P1-DONGLE/update Payload: bijvoorbeeld : 3\`.5.0\`

## Update locatie

Indien je een eigen ota server hebt kan je de remote update url in de DSMRsettings.json aanpassen naar wens.

### Dongle hotspot blijft komen (blauwe led brand niet continu[](https://martijn-hendriks.gitbook.io/archive/faq#dongle-hotspot-blijft-komen-blauwe-led-brand-niet-continu)

Dit komt in veel gevallen doordat de stroomtoevoer van de dongle afgeknepen wordt door de slimme meter. Het opbouwen van een wifi signaal kost kortstondig heel veel energie. Advies is om een usb adapter aan te sluiten op de dongle.

### Hotspot is niet te zien[](https://martijn-hendriks.gitbook.io/archive/faq#hotspot-is-niet-te-zien)

Controleer of na het opstarten van de dongle de blauwe led een keer aan gaat en daarna weer uit. Knippert deze langzaam dan herstart de dongle zichzelf. Meestal is er dan een usb adapter nodig.

### De dongle is maar kort verbonden met het netwerk[](https://martijn-hendriks.gitbook.io/archive/faq#de-dongle-is-maar-kort-verbonden-met-het-netwerk)

Kunnen meerdere oorzaken zijn, namelijk:

*   Heeft u een zogenaamd verborgen wifi netwerk?
    
*   Staat het netwerk op kanaal 13?
    
*   Geen 2.4GHz netwerk
    

De dongle heeft een 2.4GHz netwerk nodig die niet verborgen is en liefst niet op kanaal 13.
