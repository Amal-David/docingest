# primordial lua api

 

[Skip to content](https://docs.primordial.dev/#location)

Getting Started
===============

Note

the api automatically includes the [bit](http://bitop.luajit.org/)
 and [ffi](https://luajit.org/ext_ffi.html)
 libraries

Location[#](https://docs.primordial.dev/#location "Copy Link")

---------------------------------------------------------------

*   scripts location: `{csgo folder}/primordial/scripts`
*   libraries location: `{csgo folder}/primordial/scripts/include`

note that you can only `require` luas from within the libraries location.
