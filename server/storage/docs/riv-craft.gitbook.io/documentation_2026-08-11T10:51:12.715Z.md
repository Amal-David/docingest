# Настройки графики | RIV CRAFT

For the complete documentation index, see [llms.txt](https://riv-craft.gitbook.io/rivcraft.ru/llms.txt)
. This page is also available as [Markdown](https://riv-craft.gitbook.io/rivcraft.ru/readme/graphics.md)
.

В официальной сборке RIV Craft подготовлены готовые профили графики. Они позволяют быстро настроить игру под возможности компьютера.

GitBook Assistant

Откройте меню:

GitBook Assistant

GitBook AssistantСпроситьКопировать

    Настройки → Profiles… / Профили…

![](https://riv-craft.gitbook.io/rivcraft.ru/~gitbook/image?url=https%3A%2F%2F2768925880-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252Ft1Bn9hHw6DdiSjZy6I8e%252Fuploads%252Fgit-blob-c699bf278691a21d7f8749625ec9f0abde51471a%252Fgraphics-profiles.png%3Falt%3Dmedia&width=768&dpr=3&quality=100&sign=5bdbb1ce&sv=2)

Выберите подходящий профиль графики: «Стандартные», «Высокие», «Низкие» или «Ультра низкие».

Доступные профили[](https://riv-craft.gitbook.io/rivcraft.ru/readme/graphics#dostupnye-profili)

------------------------------------------------------------------------------------------------

Профиль

Для кого

Что меняется

**Ультра низкие**

GitBook Assistant

Очень слабые ПК и ноутбуки

GitBook Assistant

Минимальная дальность, частицы, ресурспаки и визуальные эффекты. Максимум FPS.

GitBook Assistant

**Низкие**

GitBook Assistant

Слабые ПК

GitBook Assistant

Упрощённая графика без тяжёлых анимаций и ресурспаков.

GitBook Assistant

**Стандартные**

GitBook Assistant

Большинство ПК

GitBook Assistant

Основной рекомендуемый режим сборки.

GitBook Assistant

**Высокие**

GitBook Assistant

Мощные ПК

GitBook Assistant

Повышенная дальность, частицы, качество графики и визуальные эффекты.

GitBook Assistant

После смены профиля перезапускать игру не нужно.

GitBook Assistant

Если у вас слабый ПК[](https://riv-craft.gitbook.io/rivcraft.ru/readme/graphics#esli-u-vas-slabyi-pk)

------------------------------------------------------------------------------------------------------

1.  Выберите профиль **Ультра низкие**.
    
    GitBook Assistant
    
2.  Убедитесь, что шейдеры выключены.
    
    GitBook Assistant
    
3.  При необходимости вручную выключите:
    
    GitBook Assistant
    

GitBook AssistantСпроситьКопировать

    RyoamicLights
    Farsight
    Sound Physics Remastered

Шейдеры[](https://riv-craft.gitbook.io/rivcraft.ru/readme/graphics#sheidery)

-----------------------------------------------------------------------------

Шейдеры не входят в обязательные настройки. Они могут заметно снижать FPS.

GitBook Assistant

Если игра лагает:

GitBook Assistant

GitBook AssistantСпроситьКопировать

    Настройки видео → Шейдеры → Выкл.

Рекомендации[](https://riv-craft.gitbook.io/rivcraft.ru/readme/graphics#rekomendacii)

--------------------------------------------------------------------------------------

*   Не устанавливайте сторонние моды ради FPS без согласования с администрацией.
    
    GitBook Assistant
    
*   Не добавляйте OptiFine в готовую сборку: он может конфликтовать с Embeddium, Oculus и другими модами.
    
    GitBook Assistant
    
*   Если после изменения графики появились баги, загрузите профиль **Стандартные** или обратитесь в Discord.
    
    GitBook Assistant

    GitBook Assistant

    GitBook Assistant
    
5.  Дождитесь импорта.
    
    GitBook Assistant
    
6.  Запустите сборку.
    
    GitBook Assistant

5.2. Мирный и активный статус[](https://riv-craft.gitbook.io/rivcraft.ru/rules/pvp#id-5.2.-mirnyi-i-aktivnyi-status)

---------------------------------------------------------------------------------------------------------------------

*   PvP происходит только если **оба** игрока имеют активный PvP-статус.
    
    GitBook Assistant
    
*   Мирный игрок технически не может быть атакован активным игроком.
    
    GitBook Assistant
    
*   Попытки вынудить мирного игрока включить PvP считаются **подстрекательством к PvP**.
    
    GitBook Assistant
    
*   Если мирный игрок наносит урон другому игроку, он становится активным.
    
    GitBook Assistant
    
*   Отключение активного PvP не мгновенное: по стандартной конфигурации ожидание составляет **60 секунд**.
    
    GitBook Assistant
    
*   Если во время ожидания игрок наносит или получает урон от другого игрока, отмена PvP-статуса сбрасывается.
    
    GitBook Assistant

### После исключения[](https://riv-craft.gitbook.io/rivcraft.ru/rules/cities-and-territories#posle-isklyucheniya)

*   Если игрок физически не может зайти на сервер из-за болезни, поездки, поломки ПК или другой уважительной причины, срок вывоза приостанавливается или продлевается.
    
    GitBook Assistant
    
*   Если игрок не вывез личное имущество за 7 дней и не сообщил об уважительной причине, вещи, находящиеся в пределах городского привата, переходят городу.
    
    GitBook Assistant
    
*   Личное имущество до окончания срока остаётся собственностью игрока.
    
    GitBook Assistant
    
*   Городское имущество остаётся городу.
    
    GitBook Assistant

    GitBook Assistant

Город и его статус \* Город — это приват/команда, созданная через \*\*FTB Chunks\*\*. \* Название города должно совпадать с названием привата FTB Chunks. \* Город может иметь собственные правила, только если они: \* опубликованы; \* не противоречат правилам сервера; \* не являются дискриминационными; \* не используются для травли или обхода правил. {% hint style="info" icon="map" %} Зарегистрированные города публикуются в \[канале городов Discord\](https://discord.com/channels/1339961596499329024/1344369975758028800). {% endhint %} ## 6.2. Исключение из города Президент может исключить жителя только: \* за нарушение правил сервера; \* за нарушение опубликованных правил города. {% hint style="warning" icon="triangle-exclamation" %} Личная неприязнь сама по себе \*\*не является\*\* причиной для ограничения доступа в город или исключения жителя. {% endhint %} ### После исключения \* Игроку даётся \*\*7 календарных дней\*\* на вывоз личного имущества. \* Игрок может заходить в город в течение этих 7 дней, если не совершил серьёзного нарушения. \* Сообщение об исключении можно передать любым способом: Discord, личные сообщения, описание города, игровой чат или тикет. \* Если игрок физически не может зайти на сервер из-за болезни, поездки, поломки ПК или другой уважительной причины, срок вывоза приостанавливается или продлевается. \* Если игрок не вывез личное имущество за 7 дней и не сообщил об уважительной причине, вещи, находящиеся в пределах городского привата, переходят городу. \* Личное имущество до окончания срока остаётся собственностью игрока. \* Городское имущество остаётся городу. \* Спор о статусе имущества решают суд, президент и администрация. {% hint style="danger" icon="gavel" %} 🪓 \*\*Наказание за удержание или уничтожение вещей исключённого игрока до окончания срока:\*\* компенсация, восстановление.\\ 🕒 \*\*Срок:\*\* определяется в рамках политики наказаний. {% endhint %} ## 6.3. Ограничение входа в город Президент может запретить вход в город только игроку, который нарушил правила сервера или опубликованные правила города. Запрет входа: \* не может устанавливаться по личной неприязни; \* не даёт права удерживать игрока; \* не даёт права уничтожать его личные вещи; \* не отменяет право на вывоз вещей в течение 7 дней, если нарушение не было серьёзным. ## 6.4.
