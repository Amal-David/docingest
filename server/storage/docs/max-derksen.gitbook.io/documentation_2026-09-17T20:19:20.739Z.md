# Pivot Transform | Pivot Transform Documentation

For the complete documentation index, see [llms.txt](https://max-derksen.gitbook.io/pivot-transform/llms.txt)
. This page is also available as [Markdown](https://max-derksen.gitbook.io/pivot-transform/readme.md)
.

**Pivot Transform** edits the object origin (the pivot) and the 3D cursor — place them exactly on geometry, drop them to the bottom of a mesh, save them to a list and bring them back later.

Key features[](https://max-derksen.gitbook.io/pivot-transform#key-features)

----------------------------------------------------------------------------

*   Four active tools in the toolbar: [Pivot Flow](https://max-derksen.gitbook.io/pivot-transform/pivot-tools/pivot-flow)
     (snap the pivot to picked geometry), [Pivot BBox](https://max-derksen.gitbook.io/pivot-transform/pivot-tools/pivot-bbox)
     (bounding-box points), [Pivot Align](https://max-derksen.gitbook.io/pivot-transform/pivot-tools/pivot-align)
     (world axes / bottom), and the [3D Cursor tool](https://max-derksen.gitbook.io/pivot-transform/3d-cursor/cursor-tool)
    .
    
*   One toggle — **Pivot Transform** — turns Blender's move/rotate/scale into origin-only edits, and the tools flip it on for you → [Affect Only Origins](https://max-derksen.gitbook.io/pivot-transform/editing-the-pivot/affect-only-origins)
    .
    
*   Panel and pie-menu shortcuts: send the pivot [to the selection or to the bottom](https://max-derksen.gitbook.io/pivot-transform/editing-the-pivot/panel-actions)
    , reset it to a preset origin, or [apply transforms](https://max-derksen.gitbook.io/pivot-transform/editing-the-pivot/apply-transform)
    .
    
*   One system for every action: hold **Ctrl** to [move the 3D cursor instead of the pivot](https://max-derksen.gitbook.io/pivot-transform/editing-the-pivot/pivot-or-cursor)
    , and adjust any option — or switch pivot ↔ cursor — in the **F9** redo panel afterwards, in Object and Edit modes alike.
    
*   [Pivot Flow](https://max-derksen.gitbook.io/pivot-transform/pivot-tools/pivot-flow)
     mouse actions are yours to set: choose what **click**, **Shift + click** and **drag** each do — move the pivot, orient it, or aim its +X at anything you point to.
    
*   [Save pivots](https://max-derksen.gitbook.io/pivot-transform/editing-the-pivot/saved-pivots)
     and [cursor positions](https://max-derksen.gitbook.io/pivot-transform/3d-cursor/saved-cursors)
     to a list — per object or global.
    
*   Full [3D cursor workflow](https://max-derksen.gitbook.io/pivot-transform/3d-cursor/cursor-actions)
    : snap it to the selection, align it to the view, reset it, orient it to picked geometry.
    
*   Works in Object Mode and the Edit modes (Mesh, Curve, Surface, Armature, Lattice) plus Pose; the cursor tool runs in every mode.

# Installation | Pivot Transform Documentation

For the complete documentation index, see [llms.txt](https://max-derksen.gitbook.io/pivot-transform/llms.txt)
. This page is also available as [Markdown](https://max-derksen.gitbook.io/pivot-transform/getting-started/installation.md)
.

Pivot Transform ships as a Blender Extension — a single `.zip`. Don't unzip it. Requires **Blender 5.0+**.

Install[](https://max-derksen.gitbook.io/pivot-transform/getting-started/installation#install)

-----------------------------------------------------------------------------------------------

1.  Download `Pivot_Transform_*.zip` from your [Superhive](https://superhivemarket.com/products/pivot-transform)
     or [Gumroad](https://derksen.gumroad.com/)
     library.
    
2.  **Edit → Preferences → Get Extensions**.
    
3.  Open the dropdown in the top-right corner → **Install from Disk…**
    
4.  Pick the `.zip`.
    

The add-on installs and enables automatically. Or just **drag the** `**.zip**` **into the Blender window** — same result.

Enable / disable[](https://max-derksen.gitbook.io/pivot-transform/getting-started/installation#enable-disable)

---------------------------------------------------------------------------------------------------------------

**Edit → Preferences → Add-ons**, search for _Pivot Transform_, toggle the checkbox. No restart needed.

Update[](https://max-derksen.gitbook.io/pivot-transform/getting-started/installation#update)

---------------------------------------------------------------------------------------------

Install the new `.zip` over the old version, then restart Blender. Your keymaps and settings are kept.

Uninstall[](https://max-derksen.gitbook.io/pivot-transform/getting-started/installation#uninstall)

---------------------------------------------------------------------------------------------------

**Preferences → Add-ons** → expand _Pivot Transform_ → **Uninstall**.

If something goes wrong[](https://max-derksen.gitbook.io/pivot-transform/getting-started/installation#if-something-goes-wrong)

-------------------------------------------------------------------------------------------------------------------------------

*   **"Install from Disk" rejects the file** — the zip was re-packed (its folder structure changed) or it's built for a different Blender version.
    
*   **Add-on missing after install** — check the **Get Extensions** tab for errors and confirm Blender is 5.0+.
    
*   More: [FAQ & Troubleshooting](https://max-derksen.gitbook.io/pivot-transform/reference/faq)
    .

# Quick Start | Pivot Transform Documentation

For the complete documentation index, see [llms.txt](https://max-derksen.gitbook.io/pivot-transform/llms.txt)
. This page is also available as [Markdown](https://max-derksen.gitbook.io/pivot-transform/getting-started/quick-start.md)
.

1\. Pick a tool[](https://max-derksen.gitbook.io/pivot-transform/getting-started/quick-start#id-1.-pick-a-tool)

----------------------------------------------------------------------------------------------------------------

Pivot Transform adds a group of active tools to the viewport toolbar (**T**). Press **D** to activate the group and press it again to cycle through **Pivot Flow → Pivot BBox → Pivot Align**.

Select an object and the tool draws its snap points on it.

2\. Place the pivot[](https://max-derksen.gitbook.io/pivot-transform/getting-started/quick-start#id-2.-place-the-pivot)

------------------------------------------------------------------------------------------------------------------------

*   **Pivot Flow** — hover geometry and click: the origin jumps to that vertex, edge or face. **Shift + click** lines it up with the element instead of moving it, and **drag** aims its +X wherever you release. All three are configurable → [Pivot Flow](https://max-derksen.gitbook.io/pivot-transform/pivot-tools/pivot-flow)
    .
    
*   **Pivot BBox** — click a handle on the selection's bounding box (corner, edge, face or center) → [Pivot BBox](https://max-derksen.gitbook.io/pivot-transform/pivot-tools/pivot-bbox)
    .
    
*   **Pivot Align** — square up the pivot to the world axes or drop it to the lowest point → [Pivot Align](https://max-derksen.gitbook.io/pivot-transform/pivot-tools/pivot-align)
    .
    

By default the tool affects the **active** object only. Switch **Target** to **Selected** in the tool header to hit every selected object at once.

Two rules apply to _every_ pivot action in the add-on: hold **Ctrl** to move the **3D cursor** to the target instead of the pivot, and press **F9** afterwards to change any option — or switch pivot ↔ cursor — with the result recomputed from the original state → [Pivot or Cursor & the Redo Panel](https://max-derksen.gitbook.io/pivot-transform/editing-the-pivot/pivot-or-cursor)
.

3\. Move the pivot by hand[](https://max-derksen.gitbook.io/pivot-transform/getting-started/quick-start#id-3.-move-the-pivot-by-hand)

--------------------------------------------------------------------------------------------------------------------------------------

While a Pivot tool is active, the **Pivot Transform** toggle in the tool header is on — so plain **G / R / S** move, rotate and scale the **origin** instead of the geometry. Turn it off (or leave the tool) to go back to normal transforms → [Affect Only Origins](https://max-derksen.gitbook.io/pivot-transform/editing-the-pivot/affect-only-origins)
.

4\. Quick actions[](https://max-derksen.gitbook.io/pivot-transform/getting-started/quick-start#id-4.-quick-actions)

--------------------------------------------------------------------------------------------------------------------

Open the **Pivot Transform** tab in the sidebar (**N**), or the pie menu (**Shift + Alt + A**):

*   **To Active / To Select** — move the pivot onto the active object or the selected elements.
    
*   **To Bottom** — drop it to the lowest point of the mesh.
    
*   Origin presets — 3D cursor, center of mass, geometry.
    

See [Panel & Pie Actions](https://max-derksen.gitbook.io/pivot-transform/editing-the-pivot/panel-actions)
.

5\. Save it for later[](https://max-derksen.gitbook.io/pivot-transform/getting-started/quick-start#id-5.-save-it-for-later)

----------------------------------------------------------------------------------------------------------------------------

Store the current pivot to a list and restore it on any object → [Saved Pivots](https://max-derksen.gitbook.io/pivot-transform/editing-the-pivot/saved-pivots)
. The 3D cursor has [its own list](https://max-derksen.gitbook.io/pivot-transform/3d-cursor/saved-cursors)
.

     — where everything lives.

-------------------------------------------------------------------------------------------------------------------------------------------------------------------

*   3D cursor actions → [Cursor Actions](https://max-derksen.gitbook.io/pivot-transform/3d-cursor/cursor-actions)
    ;
    
*   the **Apply**, **Pivot Save** and **Cursor Save** sub-panels.

-----------------------------------------------------------------------------------------------------------------

**Shift + Alt + A** opens the pivot pie — the same quick actions as the panel, one keystroke away. The key is remappable in **Preferences → Add-ons → Pivot Transform → Keymaps**.

5\. Redo panel (F9)[](https://max-derksen.gitbook.io/pivot-transform/getting-started/interface-overview#id-5.-redo-panel-f9)

-----------------------------------------------------------------------------------------------------------------------------

After any pivot action, the **Adjust Last Operation** panel (bottom-left corner, or **F9**) shows the action's options plus the **Affect: Pivot / 3D Cursor** toggles. Changing anything re-runs the action from the state before it — works in Edit modes too → [Pivot or Cursor & the Redo Panel](https://max-derksen.gitbook.io/pivot-transform/editing-the-pivot/pivot-or-cursor)

# Pivot Flow | Pivot Transform Documentation

For the complete documentation index, see [llms.txt](https://max-derksen.gitbook.io/pivot-transform/llms.txt)
. This page is also available as [Markdown](https://max-derksen.gitbook.io/pivot-transform/pivot-tools/pivot-flow.md)
.

Snap the origin straight onto geometry. Hover a vertex, edge or face — Pivot Flow highlights it — and click to drop the pivot there. Hold **Shift** and the pivot stays put but **orients** to what you picked: aligned to the face normal, along the edge, or by the vertex normal. What click, Shift + click and drag each do is up to you.

**Where:** toolbar (**T**) → Pivot Flow. **D** activates it. Modes: Object, Edit Mesh / Curve / Surface / Armature.

Snap targets[](https://max-derksen.gitbook.io/pivot-transform/pivot-tools/pivot-flow#snap-targets)

---------------------------------------------------------------------------------------------------

The highlight follows the closest element under the cursor:

*   **Vertex** — the point, oriented by its normal.
    
*   **Edge** — the edge, with an option for its **midpoint**.
    
*   **Face** — the face, with an option for its **center**.
    

Snapping reads the evaluated mesh, so modifiers are taken into account.

Click modifiers[](https://max-derksen.gitbook.io/pivot-transform/pivot-tools/pivot-flow#click-modifiers)

---------------------------------------------------------------------------------------------------------

**Click** and **Shift + click** are configurable — open **Mouse Actions** in the tool header, or go to **Preferences → Add-ons → Pivot Transform → Pivot Flow**. Both places edit the same setting, and it sticks across files. Each can be:

Action

Result

**Position**

Move the pivot, keep its current orientation

**Orientation**

Orient the pivot to the element, keep it where it is

**Position & Orientation**

Both at once

Out of the box **Click** is _Position_ and **Shift + click** is _Orientation_ — two separate, single-purpose moves. Want the old one-click "both"? Set **Click** to _Position & Orientation_.

**Ctrl** is separate and is not configurable: it retargets whatever you just did onto the **3D cursor**. It combines with everything, so **Ctrl + Shift + click** is "the Shift action, applied to the cursor".

Input

Default action

**Click**

Pivot — position

**Shift + click**

Pivot — orientation

**Drag**

Pivot — aim its local **+X** at the release point

**Ctrl + click**

**3D cursor** — position

**Ctrl + Shift + click**

**3D cursor** — orientation

**Ctrl + drag**

**3D cursor** — aim its **+X**

After the click, the [redo panel](https://max-derksen.gitbook.io/pivot-transform/editing-the-pivot/pivot-or-cursor)
 (**F9**) lets you flip **Set Position / Set Rotation** or switch between pivot and cursor.

Up to 5.1.5 a plain click always did position **and** orientation, with **Shift** for position only. From 5.1.6 the two are separate actions and you choose what each one does. To get the old feel back, set **Click** to _Position & Orientation_ and **Shift Click** to _Position_.

Drag — Align X[](https://max-derksen.gitbook.io/pivot-transform/pivot-tools/pivot-flow#drag-align-x)

-----------------------------------------------------------------------------------------------------

Drag and the pivot swings to face what you point at: its local **+X** ends up aimed at the element you release on. The **Drag** slot picks one of two behaviours:

Action

Result

**Align X**

Only aim. The pivot doesn't move — start the drag anywhere, even off the mesh

**Position & Align X**

First move the pivot onto the element under the press, then aim it

While you drag, the viewport shows what you'll get — the element under the cursor highlights, a line runs from the pivot to it, and the pivot's **resulting X / Y / Z axes** are drawn in place. Release to commit exactly that. Release over empty space and nothing is aimed.

**Ctrl + drag** aims the 3D cursor instead. **Esc** or **right-click** mid-drag cancels, and **F9** afterwards exposes the **Aim Target** so you can nudge it.

**Position & Align X** is **two undo steps** on purpose: one **Ctrl + Z** removes just the aiming and leaves the pivot where it landed, a second reverts the placement too. **Align X** never places anything, so it's a single step.

The axes are a preview, not a live edit. Rotating a pivot counter-rotates the mesh data, so applying it on every mouse move would rewrite every vertex of the object per frame. The preview uses the same math the operator commits, so what you see is what you get.

Flow settings[](https://max-derksen.gitbook.io/pivot-transform/pivot-tools/pivot-flow#flow-settings)

-----------------------------------------------------------------------------------------------------

In the tool header (or the sidebar tab):

Setting

Does

**Edge Midpoint**

Also snap to the middle of edges

**Face Center**

Also snap to face centers

**Backface Culling**

Hide snap points on faces turned away from you, so you only catch what you can see

**Selected Only**

Pick only on **selected** objects — everything else is ignored. Off by default

**Selected Only** also lives in **Preferences → Add-ons → Pivot Transform → Pivot Flow**, and like the Mouse Actions it's global — it sticks across files. Handy in a crowded scene: select what you're working on and the highlight stops landing on background geometry. Objects you're editing (Edit or Pose mode) always stay pickable. Note that unselected objects don't occlude either — snap points behind them remain reachable.

Mouse Actions[](https://max-derksen.gitbook.io/pivot-transform/pivot-tools/pivot-flow#mouse-actions)

-----------------------------------------------------------------------------------------------------

The popover in the tool header — the same three settings live in **Preferences → Add-ons → Pivot Transform → Pivot Flow**. They're global: set them once and they follow you across files.

Setting

Does

**Click**

What a plain click does

**Shift Click**

What Shift + click does

**Drag**

What click-drag does

Target[](https://max-derksen.gitbook.io/pivot-transform/pivot-tools/pivot-flow#target)

---------------------------------------------------------------------------------------

**Active** moves only the active object's pivot. **Selected** moves the pivot of every selected object to the picked spot. Set it in the tool header.

Only origins move — the geometry stays put. This is the [Pivot Transform](https://max-derksen.gitbook.io/pivot-transform/editing-the-pivot/affect-only-origins)
 mode, which the tool turns on while it's active.

# Affect Only Origins | Pivot Transform Documentation

For the complete documentation index, see [llms.txt](https://max-derksen.gitbook.io/pivot-transform/llms.txt)
. This page is also available as [Markdown](https://max-derksen.gitbook.io/pivot-transform/editing-the-pivot/affect-only-origins.md)
.

The **Pivot Transform** toggle is the core of the add-on. When it's on, Blender's move / rotate / scale act on the **origin** only — the geometry doesn't follow. It's Blender's _Affect Only Origins_ option, surfaced where you actually need it.

You'll find the toggle in every Pivot tool header, in the sidebar tab header, and in the N-panel header.

The workflow[](https://max-derksen.gitbook.io/pivot-transform/editing-the-pivot/affect-only-origins#the-workflow)

------------------------------------------------------------------------------------------------------------------

1.  Turn on **Pivot Transform** (or just pick a Pivot tool — it flips the toggle on for you).
    
2.  Move the origin however you like:
    
    *   **G / R / S** — drag it by hand, with the usual axis locks and snapping.
        
    *   The [tools](https://max-derksen.gitbook.io/pivot-transform/pivot-tools/pivot-flow)
         — snap it to geometry, a bbox point, the bottom.
        
    *   The [panel actions](https://max-derksen.gitbook.io/pivot-transform/editing-the-pivot/panel-actions)
         — send it to the selection or a preset origin.
        
    
3.  Turn the toggle back off to return to normal transforms.
    

When you leave a Pivot tool but the toggle is still on, a **Apply Pivot Transform** button appears in the viewport's top menu bar as a reminder — click it to switch back.

Target: Active vs Selected[](https://max-derksen.gitbook.io/pivot-transform/editing-the-pivot/affect-only-origins#target-active-vs-selected)

---------------------------------------------------------------------------------------------------------------------------------------------

The **Target** dropdown (tool header) decides the reach of the tools:

*   **Active** — only the active object's origin moves.
    
*   **Selected** — the same edit is applied to every selected object's origin.
    

This only changes what geometry _stays behind_ while the origin moves. It doesn't touch the mesh data — undo puts everything back.

# Pivot BBox | Pivot Transform Documentation

For the complete documentation index, see [llms.txt](https://max-derksen.gitbook.io/pivot-transform/llms.txt)
. This page is also available as [Markdown](https://max-derksen.gitbook.io/pivot-transform/pivot-tools/pivot-bbox.md)
.

Put the pivot on the **bounding box** of the selection. The tool wraps a box around whatever is selected and gives you handles for every notable point:

*   **8 corners**
    
*   **12 edge midpoints**
    
*   **6 face centers**
    
*   **1 center**
    

Click a handle — the origin moves to that point. Good for centering a pivot, dropping it to a corner, or parking it on the middle of a side.

**Ctrl + click** a handle moves the **3D cursor** there instead of the pivot; after the click, the [redo panel](https://max-derksen.gitbook.io/pivot-transform/editing-the-pivot/pivot-or-cursor)
 (**F9**) lets you switch between pivot and cursor or tweak the position.

**Where:** toolbar (**T**) → Pivot BBox (**D** cycles to it). Modes: Object, Edit Mesh / Curve / Surface / Armature, Pose, Lattice.

What the box wraps[](https://max-derksen.gitbook.io/pivot-transform/pivot-tools/pivot-bbox#what-the-box-wraps)

---------------------------------------------------------------------------------------------------------------

*   **Object Mode** — the bounds of all selected objects.
    
*   **Edit modes** — the selected elements (verts, curve points, bones, lattice points).
    

The box follows the current transform orientation, so with a rotated object the handles sit on its own sides, not the world axes.

Target[](https://max-derksen.gitbook.io/pivot-transform/pivot-tools/pivot-bbox#target)

---------------------------------------------------------------------------------------

**Active / Selected** in the tool header decides whether the click moves one pivot or all selected pivots.

Nothing about the mesh changes — only the origin. See [Affect Only Origins](https://max-derksen.gitbook.io/pivot-transform/editing-the-pivot/affect-only-origins)
.

# Pivot or Cursor & the Redo Panel | Pivot Transform Documentation

For the complete documentation index, see [llms.txt](https://max-derksen.gitbook.io/pivot-transform/llms.txt)
. This page is also available as [Markdown](https://max-derksen.gitbook.io/pivot-transform/editing-the-pivot/pivot-or-cursor.md)
.

Every pivot action in the add-on — the tool clicks, the panel buttons, the pie entries, saved pivots — runs through one system. That buys you two things everywhere:

Ctrl = move the 3D cursor instead[](https://max-derksen.gitbook.io/pivot-transform/editing-the-pivot/pivot-or-cursor#ctrl-move-the-3d-cursor-instead)

------------------------------------------------------------------------------------------------------------------------------------------------------

Hold **Ctrl** while triggering _any_ pivot action and it moves the **3D cursor** to the target instead of the pivot:

*   **Ctrl + click** a [Flow](https://max-derksen.gitbook.io/pivot-transform/pivot-tools/pivot-flow)
     snap point — the cursor gets whatever the click action is set to, applied to it instead of the pivot. **Ctrl + Shift + click** does the same for the Shift action, and **Ctrl + drag** aims the cursor's +X.
    
*   **Ctrl + click** a [BBox](https://max-derksen.gitbook.io/pivot-transform/pivot-tools/pivot-bbox)
     corner / edge / face handle — the cursor goes to that bounding-box point.
    
*   **Ctrl + click** an [Align](https://max-derksen.gitbook.io/pivot-transform/pivot-tools/pivot-align)
     handle, **To Bottom**, **To Active / To Select**, an origin preset, a [saved pivot](https://max-derksen.gitbook.io/pivot-transform/editing-the-pivot/saved-pivots)
     — same rule.
    

The pivot stays where it was. One modifier, the same everywhere.

Affect: Pivot / 3D Cursor[](https://max-derksen.gitbook.io/pivot-transform/editing-the-pivot/pivot-or-cursor#affect-pivot-3d-cursor)

-------------------------------------------------------------------------------------------------------------------------------------

After any pivot action, the **Adjust Last Operation** panel (bottom-left corner, or **F9**) shows two toggles at the top:

Toggle

Does

**Pivot**

Apply the action to the object origin(s)

**3D Cursor**

Apply the action to the 3D cursor

They re-run the action from the state _before_ it — so unchecking **Pivot** after a "To Bottom" puts the pivot back where it was, and checking **3D Cursor** sends the cursor to the bottom point instead. Any combination works: both, either, or neither (full revert).

Change options after the fact[](https://max-derksen.gitbook.io/pivot-transform/editing-the-pivot/pivot-or-cursor#change-options-after-the-fact)

------------------------------------------------------------------------------------------------------------------------------------------------

The same panel exposes the action's options — **Mode**, **Drop To X/Y/Z**, **Axis**, **Align**, positions… Change anything and the result is recomputed from the original state, not stacked on top of the previous result. This works in Object Mode **and** in the Edit modes.

One **Ctrl + Z** undoes the whole action, including from Edit Mode. Undoing an Edit-Mode pivot action returns you to Object Mode — that's a Blender undo-stack limitation.

# Panel & Pie Actions | Pivot Transform Documentation

For the complete documentation index, see [llms.txt](https://max-derksen.gitbook.io/pivot-transform/llms.txt)
. This page is also available as [Markdown](https://max-derksen.gitbook.io/pivot-transform/editing-the-pivot/panel-actions.md)
.

One-click ways to move the pivot, without dragging anything. They live in the **Pivot Transform** sidebar tab (**N**) and in the pie menu (**Shift + Alt + A**) — same buttons in both.

Every button here follows the [shared rules](https://max-derksen.gitbook.io/pivot-transform/editing-the-pivot/pivot-or-cursor)
: **Ctrl + click** moves the **3D cursor** to the target instead of the pivot, and the **F9** redo panel lets you change any option (or switch pivot ↔ cursor) after the fact — the result is recomputed from the original state.

To Active / To Select[](https://max-derksen.gitbook.io/pivot-transform/editing-the-pivot/panel-actions#to-active-to-select)

----------------------------------------------------------------------------------------------------------------------------

Moves the pivot onto the current selection.

*   **Object Mode → To Active** — the selected objects' origins jump to the **active** object. The **▾** popover picks which coordinates to match — **X**, **Y**, **Z** or **All** — and whether to copy its orientation.
    
*   **Edit modes → To Select** — the origin goes to the selected vertices / points / bones. **Align To Normal** also turns the pivot to face the selection's normal.
    

To Bottom[](https://max-derksen.gitbook.io/pivot-transform/editing-the-pivot/panel-actions#to-bottom)

------------------------------------------------------------------------------------------------------

Drops the pivot to the lowest point of the mesh. The **▾** popover holds the options:

Option

Does

**Drop To X / Y / Z**

Which axes get dropped to the low point

**Mode**

How the low point is measured — **Lowest Median Center**, **Lowest Origin**, or **Lowest Vertex**

**Use Modifier**

Measure from the modified (evaluated) mesh

**Drop To Active**

Use the active object's floor level for all selected

Origin presets[](https://max-derksen.gitbook.io/pivot-transform/editing-the-pivot/panel-actions#origin-presets)

----------------------------------------------------------------------------------------------------------------

Quick buttons for the standard origin spots:

*   **To 3D Cursor** — origin to the cursor.
    
*   **Center of Mass** — the mesh's mass center.
    
*   **Geometry** — origin to the median of the geometry (and _Mesh To Pivot_, which moves the geometry to the origin instead).
    

In Object Mode the pie adds **Mass** and **Volume** centers too.

These act through [Affect Only Origins](https://max-derksen.gitbook.io/pivot-transform/editing-the-pivot/affect-only-origins)
, so the geometry stays where it is (except _Mesh To Pivot_, which is the deliberate opposite).

# Saved Pivots | Pivot Transform Documentation

For the complete documentation index, see [llms.txt](https://max-derksen.gitbook.io/pivot-transform/llms.txt)
. This page is also available as [Markdown](https://max-derksen.gitbook.io/pivot-transform/editing-the-pivot/saved-pivots.md)
.

Store a pivot's position and rotation to a list and bring it back whenever you need it — a reusable set of origins per object or for the whole file.

**Where:** the **Saved List** popover in the tool header, and the **Pivot Save** sub-panel in the sidebar tab.

Save and restore[](https://max-derksen.gitbook.io/pivot-transform/editing-the-pivot/saved-pivots#save-and-restore)

-------------------------------------------------------------------------------------------------------------------

*   **+** — save the current pivot to the list.
    
*   Click an entry — the origin moves to that saved transform. **Ctrl + click** moves the **3D cursor** there instead → [Pivot or Cursor](https://max-derksen.gitbook.io/pivot-transform/editing-the-pivot/pivot-or-cursor)
    .
    
*   **−** removes the selected entry; the up / down arrows reorder the list.
    
*   Each entry exposes its **position** and **rotation** fields, so you can nudge saved values by hand.
    

After applying an entry, the **F9** redo panel offers **Set Position / Rotation / Both** and a **Paste Transform** toggle — the latter moves the selected _objects_ to the saved transform instead of their pivots.

Global vs per-object[](https://max-derksen.gitbook.io/pivot-transform/editing-the-pivot/saved-pivots#global-vs-per-object)

---------------------------------------------------------------------------------------------------------------------------

The **globe** toggle switches where the list is stored:

*   **On (global)** — one shared list for the whole scene.
    
*   **Off** — the list belongs to the active object and travels with it.
    

Visibility[](https://max-derksen.gitbook.io/pivot-transform/editing-the-pivot/saved-pivots#visibility)

-------------------------------------------------------------------------------------------------------

The **keyframe** toggle shows or hides the saved points as markers in the viewport, so you can see your stored origins without opening the list.

Thanks to **TinkerBoi** for testing and helping build the saved-pivot list.

# Pivot Align | Pivot Transform Documentation

Straighten the pivot out. Pivot Align has two jobs, each toggled in the tool header:

*   **Axis Align** — square the pivot's rotation back to the world axes. Handles around the selection let you flatten the orientation onto X, Y or Z.
    
*   **Bottom** — drop the pivot to the lowest point of the mesh, so the object sits _on_ its origin (handy before placing it on the ground).
    

**Where:** toolbar (**T**) → Pivot Align (**D** cycles to it). Modes: Object, Edit Mesh / Curve / Surface / Armature.

Toggle

Does

**Axis Align**

Show the world-axis handles for re-orienting the pivot

**Bottom**

Show the handle that drops the pivot to the lowest point

Leave both on to have every handle available at once, or turn one off to keep the gizmo simple.

**Ctrl + click** any handle moves the **3D cursor** to that point instead of the pivot → [Pivot or Cursor](https://max-derksen.gitbook.io/pivot-transform/editing-the-pivot/pivot-or-cursor)
.

For a bottom drop with more control (which axis, how the low point is measured, offset), use **To Bottom** in the [panel or pie](https://max-derksen.gitbook.io/pivot-transform/editing-the-pivot/panel-actions#to-bottom)
.

As with the other tools, only the origin is affected → [Affect Only Origins](https://max-derksen.gitbook.io/pivot-transform/editing-the-pivot/affect-only-origins)

# FAQ & Troubleshooting | Pivot Transform Documentation

For the complete documentation index, see [llms.txt](https://max-derksen.gitbook.io/pivot-transform/llms.txt)
. This page is also available as [Markdown](https://max-derksen.gitbook.io/pivot-transform/reference/faq.md)
.

The tool doesn't move the pivot[](https://max-derksen.gitbook.io/pivot-transform/reference/faq#the-tool-doesnt-move-the-pivot)

-------------------------------------------------------------------------------------------------------------------------------

Check, in order:

1.  Something is selected — no selection, no pivot to move.
    
2.  **Pivot Transform** (Affect Only Origins) is on. A Pivot tool turns it on automatically; if you're using **G / R / S** without a tool, flip the toggle yourself.
    
3.  **Target** is what you expect — **Active** touches one object, **Selected** touches all of them.
    

My mesh moved instead of the origin[](https://max-derksen.gitbook.io/pivot-transform/reference/faq#my-mesh-moved-instead-of-the-origin)

----------------------------------------------------------------------------------------------------------------------------------------

The **Pivot Transform** toggle is off, so transforms hit the geometry as usual. Turn it on → [Affect Only Origins](https://max-derksen.gitbook.io/pivot-transform/editing-the-pivot/affect-only-origins)
. (The one button that _should_ move the mesh is **Mesh To Pivot**.)

G / R / S still move the object after I'm done[](https://max-derksen.gitbook.io/pivot-transform/reference/faq#g-r-s-still-move-the-object-after-im-done)

---------------------------------------------------------------------------------------------------------------------------------------------------------

The origin-only mode stays on until you turn it off. When you leave the Pivot tool with it still active, an **Apply Pivot Transform** button shows up in the viewport's top menu bar — click it to switch back.

A shortcut does nothing[](https://max-derksen.gitbook.io/pivot-transform/reference/faq#a-shortcut-does-nothing)

----------------------------------------------------------------------------------------------------------------

Another add-on is likely using the same key. Rebind Pivot Transform's keys in **Preferences → Add-ons → Pivot Transform → Keymaps**, or check Blender's main Keymap preferences to see what's winning.

The 3D Cursor tool has no shortcut[](https://max-derksen.gitbook.io/pivot-transform/reference/faq#the-3d-cursor-tool-has-no-shortcut)

--------------------------------------------------------------------------------------------------------------------------------------

By design — **Shift + Alt + D** ships disabled. Enable it in the add-on's **Keymaps**.

Can I change an action's options after clicking?[](https://max-derksen.gitbook.io/pivot-transform/reference/faq#can-i-change-an-actions-options-after-clicking)

Change the options, or use the **Affect: Pivot / 3D Cursor** toggles to redirect the action; the result is recomputed from the state before the click → [Pivot or Cursor & the Redo Panel](https://max-derksen.gitbook.io/pivot-transform/editing-the-pivot/pivot-or-cursor)
.

Undo from Edit Mode kicked me to Object Mode[](https://max-derksen.gitbook.io/pivot-transform/reference/faq#undo-from-edit-mode-kicked-me-to-object-mode)

----------------------------------------------------------------------------------------------------------------------------------------------------------

Expected. A pivot move changes object-level data that Blender's edit-mode undo can't store, so the add-on records the undo step in Object Mode — one **Ctrl + Z** cleanly reverts the whole action, but lands you in Object Mode.

-----------------------------------------------------------------------------------------------------------------------

Yes. Blender normally leaves the 3D cursor out of undo; cursor moves made through Pivot Transform are in the history.

No. Install the new `.zip` over the old one and restart — keymaps and settings are kept.

# Pivot Transform

\*\*Pivot Transform\*\* edits the object origin (the pivot) and the 3D cursor — place them exactly on geometry, drop them to the bottom of a mesh, save them to a list and bring them back later.

## Key features

\* Four active tools in the toolbar: \[Pivot Flow\](/pivot-transform/pivot-tools/pivot-flow.md) (snap the pivot to picked geometry), \[Pivot BBox\](/pivot-transform/pivot-tools/pivot-bbox.md) (bounding-box points), \[Pivot Align\](/pivot-transform/pivot-tools/pivot-align.md) (world axes / bottom), and the \[3D Cursor tool\](/pivot-transform/3d-cursor/cursor-tool.md).
\* One toggle — \*\*Pivot Transform\*\* — turns Blender's move/rotate/scale into origin-only edits, and the tools flip it on for you → \[Affect Only Origins\](/pivot-transform/editing-the-pivot/affect-only-origins.md).
\* Panel and pie-menu shortcuts: send the pivot \[to the selection or to the bottom\](/pivot-transform/editing-the-pivot/panel-actions.md), reset it to a preset origin, or \[apply transforms\](/pivot-transform/editing-the-pivot/apply-transform.md).
\* One system for every action: hold \*\*Ctrl\*\* to \[move the 3D cursor instead of the pivot\](/pivot-transform/editing-the-pivot/pivot-or-cursor.md), and adjust any option — or switch pivot ↔ cursor — in the \*\*F9\*\* redo panel afterwards, in Object and Edit modes alike.
\* \[Pivot Flow\](/pivot-transform/pivot-tools/pivot-flow.md) mouse actions are yours to set: choose what \*\*click\*\*, \*\*Shift + click\*\* and \*\*drag\*\* each do — move the pivot, orient it, or aim its +X at anything you point to.
\* \[Save pivots\](/pivot-transform/editing-the-pivot/saved-pivots.md) and \[cursor positions\](/pivot-transform/3d-cursor/saved-cursors.md) to a list — per object or global.
\* Full \[3D cursor workflow\](/pivot-transform/3d-cursor/cursor-actions.md): snap it to the selection, align it to the view, reset it, orient it to picked geometry.
\* Works in Object Mode and the Edit modes (Mesh, Curve, Surface, Armature, Lattice) plus Pose; the cursor tool runs in every mode.

# Affect Only Origins

The \*\*Pivot Transform\*\* toggle is the core of the add-on. When it's on, Blender's move / rotate / scale act on the \*\*origin\*\* only — the geometry doesn't follow. It's Blender's \*Affect Only Origins\* option, surfaced where you actually need it.

You'll find the toggle in every Pivot tool header, in the sidebar tab header, and in the N-panel header.

## The workflow

1. Turn on \*\*Pivot Transform\*\* (or just pick a Pivot tool — it flips the toggle on for you).
2. Move the origin however you like:
   \* \*\*G / R / S\*\* — drag it by hand, with the usual axis locks and snapping.
   \* The \[tools\](/pivot-transform/pivot-tools/pivot-flow.md) — snap it to geometry, a bbox point, the bottom.
   \* The \[panel actions\](/pivot-transform/editing-the-pivot/panel-actions.md) — send it to the selection or a preset origin.
3. Turn the toggle back off to return to normal transforms.

When you leave a Pivot tool but the toggle is still on, a \*\*Apply Pivot Transform\*\* button appears in the viewport's top menu bar as a reminder — click it to switch back.

## Target: Active vs Selected

The \*\*Target\*\* dropdown (tool header) decides the reach of the tools:

\* \*\*Active\*\* — only the active object's origin moves.
\* \*\*Selected\*\* — the same edit is applied to every selected object's origin.

{% hint style="info" %}
This only changes what geometry \*stays behind\* while the origin moves. It doesn't touch the mesh data — undo puts everything back.
{% endhint %}

# Pivot or Cursor & the Redo Panel

Every pivot action in the add-on — the tool clicks, the panel buttons, the pie entries, saved pivots — runs through one system. That buys you two things everywhere:

## Ctrl = move the 3D cursor instead

Hold \*\*Ctrl\*\* while triggering \*any\* pivot action and it moves the \*\*3D cursor\*\* to the target instead of the pivot:

\* \*\*Ctrl + click\*\* a \[Flow\](/pivot-transform/pivot-tools/pivot-flow.md) snap point — the cursor gets whatever the click action is set to, applied to it instead of the pivot. \*\*Ctrl + Shift + click\*\* does the same for the Shift action, and \*\*Ctrl + drag\*\* aims the cursor's +X.
\* \*\*Ctrl + click\*\* a \[BBox\](/pivot-transform/pivot-tools/pivot-bbox.md) corner / edge / face handle — the cursor goes to that bounding-box point.
\* \*\*Ctrl + click\*\* an \[Align\](/pivot-transform/pivot-tools/pivot-align.md) handle, \*\*To Bottom\*\*, \*\*To Active / To Select\*\*, an origin preset, a \[saved pivot\](/pivot-transform/editing-the-pivot/saved-pivots.md) — same rule.

The pivot stays where it was. One modifier, the same everywhere.

## Affect: Pivot / 3D Cursor

After any pivot action, the \*\*Adjust Last Operation\*\* panel (bottom-left corner, or \*\*F9\*\*) shows two toggles at the top:

| Toggle        | Does                                     |
| ------------- | ---------------------------------------- |
| \*\*Pivot\*\*     | Apply the action to the object origin(s) |
| \*\*3D Cursor\*\* | Apply the action to the 3D cursor        |

They re-run the action from the state \*before\* it — so unchecking \*\*Pivot\*\* after a "To Bottom" puts the pivot back where it was, and checking \*\*3D Cursor\*\* sends the cursor to the bottom point instead. Any combination works: both, either, or neither (full revert).

## Change options after the fact

The same panel exposes the action's options — \*\*Mode\*\*, \*\*Drop To X/Y/Z\*\*, \*\*Axis\*\*, \*\*Align\*\*, positions… Change anything and the result is recomputed from the original state, not stacked on top of the previous result. This works in Object Mode \*\*and\*\* in the Edit modes.

{% hint style="info" %}
One \*\*Ctrl + Z\*\* undoes the whole action, including from Edit Mode. Undoing an Edit-Mode pivot action returns you to Object Mode — that's a Blender undo-stack limitation.
{% endhint %}

# Pivot BBox

Put the pivot on the \*\*bounding box\*\* of the selection. The tool wraps a box around whatever is selected and gives you handles for every notable point:

\* \*\*8 corners\*\*
\* \*\*12 edge midpoints\*\*
\* \*\*6 face centers\*\*
\* \*\*1 center\*\*

Click a handle — the origin moves to that point. Good for centering a pivot, dropping it to a corner, or parking it on the middle of a side.

\*\*Ctrl + click\*\* a handle moves the \*\*3D cursor\*\* there instead of the pivot; after the click, the \[redo panel\](/pivot-transform/editing-the-pivot/pivot-or-cursor.md) (\*\*F9\*\*) lets you switch between pivot and cursor or tweak the position.

\*\*Where:\*\* toolbar (\*\*T\*\*) → Pivot BBox (\*\*D\*\* cycles to it). Modes: Object, Edit Mesh / Curve / Surface / Armature, Pose, Lattice.

## What the box wraps

\* \*\*Object Mode\*\* — the bounds of all selected objects.
\* \*\*Edit modes\*\* — the selected elements (verts, curve points, bones, lattice points).

The box follows the current transform orientation, so with a rotated object the handles sit on its own sides, not the world axes.

## Target

\*\*Active / Selected\*\* in the tool header decides whether the click moves one pivot or all selected pivots.

{% hint style="info" %}
Nothing about the mesh changes — only the origin. See \[Affect Only Origins\](/pivot-transform/editing-the-pivot/affect-only-origins.md).
{% endhint %}

| \*\*3D Cursor Transform\*\* | Every mode                                                    | \[3D Cursor Tool\](/pivot-transform/3d-cursor/cursor-tool.md) |

With a Pivot tool active, the header carries:

\* the \*\*Pivot Transform\*\* toggle (origin-only transforms) → \[Affect Only Origins\](/pivot-transform/editing-the-pivot/affect-only-origins.md);
\* \*\*Target\*\* — Active or Selected object(s);
\* the per-tool settings (Flow snapping, Align options, cursor orientation);
\* the \*\*Saved List\*\* popover and its \*\*+\*\* button → \[Saved Pivots\](/pivot-transform/editing-the-pivot/saved-pivots.md).

The same settings show up vertically in the sidebar's tool tab.

## 3. Sidebar panel (N → Pivot Transform)

A \*\*Pivot Transform\*\* tab in the viewport sidebar, available for mesh, curve, surface, metaball, armature, lattice, grease pencil and empty objects. It gathers the quick actions:

\* \*\*To Active / To Select\*\* and \*\*To Bottom\*\* → \[Panel & Pie Actions\](/pivot-transform/editing-the-pivot/panel-actions.md);
\* origin presets (3D cursor, center of mass, geometry);
\* 3D cursor actions → \[Cursor Actions\](/pivot-transform/3d-cursor/cursor-actions.md);
\* the \*\*Apply\*\*, \*\*Pivot Save\*\* and \*\*Cursor Save\*\* sub-panels.

The header of the panel has the \*\*Pivot Transform\*\* toggle, plus buttons for the add-on preferences (gear) and this documentation (\*\*?\*\*).

## 4. Pie menu

\*\*Shift + Alt + A\*\* opens the pivot pie — the same quick actions as the panel, one keystroke away. The key is remappable in \*\*Preferences → Add-ons → Pivot Transform → Keymaps\*\*.

## 5. Redo panel (F9)

After any pivot action, the \*\*Adjust Last Operation\*\* panel (bottom-left corner, or \*\*F9\*\*) shows the action's options plus the \*\*Affect: Pivot / 3D Cursor\*\* toggles. Changing anything re-runs the action from the state before it — works in Edit modes too → \[Pivot or Cursor & the Redo Panel\](/pivot-transform/editing-the-pivot/pivot-or-cursor.md).

# Quick Start

## 1. Pick a tool

Pivot Transform adds a group of active tools to the viewport toolbar (\*\*T\*\*). Press \*\*D\*\* to activate the group and press it again to cycle through \*\*Pivot Flow → Pivot BBox → Pivot Align\*\*.

Select an object and the tool draws its snap points on it.

## 2. Place the pivot

\* \*\*Pivot Flow\*\* — hover geometry and click: the origin jumps to that vertex, edge or face. \*\*Shift + click\*\* lines it up with the element instead of moving it, and \*\*drag\*\* aims its +X wherever you release. All three are configurable → \[Pivot Flow\](/pivot-transform/pivot-tools/pivot-flow.md).
\* \*\*Pivot BBox\*\* — click a handle on the selection's bounding box (corner, edge, face or center) → \[Pivot BBox\](/pivot-transform/pivot-tools/pivot-bbox.md).
\* \*\*Pivot Align\*\* — square up the pivot to the world axes or drop it to the lowest point → \[Pivot Align\](/pivot-transform/pivot-tools/pivot-align.md).

By default the tool affects the \*\*active\*\* object only. Switch \*\*Target\*\* to \*\*Selected\*\* in the tool header to hit every selected object at once.

Two rules apply to \*every\* pivot action in the add-on: hold \*\*Ctrl\*\* to move the \*\*3D cursor\*\* to the target instead of the pivot, and press \*\*F9\*\* afterwards to change any option — or switch pivot ↔ cursor — with the result recomputed from the original state → \[Pivot or Cursor & the Redo Panel\](/pivot-transform/editing-the-pivot/pivot-or-cursor.md).

## 3. Move the pivot by hand

While a Pivot tool is active, the \*\*Pivot Transform\*\* toggle in the tool header is on — so plain \*\*G / R / S\*\* move, rotate and scale the \*\*origin\*\* instead of the geometry. Turn it off (or leave the tool) to go back to normal transforms → \[Affect Only Origins\](/pivot-transform/editing-the-pivot/affect-only-origins.md).

## 4. Quick actions

Open the \*\*Pivot Transform\*\* tab in the sidebar (\*\*N\*\*), or the pie menu (\*\*Shift + Alt + A\*\*):

\* \*\*To Active / To Select\*\* — move the pivot onto the active object or the selected elements.
\* \*\*To Bottom\*\* — drop it to the lowest point of the mesh.
\* Origin presets — 3D cursor, center of mass, geometry.

See \[Panel & Pie Actions\](/pivot-transform/editing-the-pivot/panel-actions.md).

## 5. Save it for later

Store the current pivot to a list and restore it on any object → \[Saved Pivots\](/pivot-transform/editing-the-pivot/saved-pivots.md). The 3D cursor has \[its own list\](/pivot-transform/3d-cursor/saved-cursors.md).

# Saved Pivots

\*\*Where:\*\* the \*\*Saved List\*\* popover in the tool header, and the \*\*Pivot Save\*\* sub-panel in the sidebar tab.

\* \*\*+\*\* — save the current pivot to the list.
\* Click an entry — the origin moves to that saved transform. \*\*Ctrl + click\*\* moves the \*\*3D cursor\*\* there instead → \[Pivot or Cursor\](/pivot-transform/editing-the-pivot/pivot-or-cursor.md).

The \*\*globe\*\* toggle switches where the list is stored:

\* \*\*On (global)\*\* — one shared list for the whole scene.

The \*\*keyframe\*\* toggle shows or hides the saved points as markers in the viewport, so you can see your stored origins without opening the list.

# Pivot Flow

Snap the origin straight onto geometry. Hover a vertex, edge or face — Pivot Flow highlights it — and click to drop the pivot there. Hold \*\*Shift\*\* and the pivot stays put but \*\*orients\*\* to what you picked: aligned to the face normal, along the edge, or by the vertex normal. What click, Shift + click and drag each do is up to you.

\*\*Where:\*\* toolbar (\*\*T\*\*) → Pivot Flow. \*\*D\*\* activates it. Modes: Object, Edit Mesh / Curve / Surface / Armature.

## Snap targets

The highlight follows the closest element under the cursor:

\* \*\*Vertex\*\* — the point, oriented by its normal.
\* \*\*Edge\*\* — the edge, with an option for its \*\*midpoint\*\*.
\* \*\*Face\*\* — the face, with an option for its \*\*center\*\*.

Snapping reads the evaluated mesh, so modifiers are taken into account.

## Click modifiers

\*\*Click\*\* and \*\*Shift + click\*\* are configurable — open \*\*Mouse Actions\*\* in the tool header, or go to \*\*Preferences → Add-ons → Pivot Transform → Pivot Flow\*\*. Both places edit the same setting, and it sticks across files. Each can be:

| Action                     | Result                                               |
| -------------------------- | ---------------------------------------------------- |
| \*\*Position\*\*               | Move the pivot, keep its current orientation         |
| \*\*Orientation\*\*            | Orient the pivot to the element, keep it where it is |
| \*\*Position & Orientation\*\* | Both at once                                         |

Out of the box \*\*Click\*\* is \*Position\* and \*\*Shift + click\*\* is \*Orientation\* — two separate, single-purpose moves. Want the old one-click "both"? Set \*\*Click\*\* to \*Position & Orientation\*.

\*\*Ctrl\*\* is separate and is not configurable: it retargets whatever you just did onto the \*\*3D cursor\*\*. It combines with everything, so \*\*Ctrl + Shift + click\*\* is "the Shift action, applied to the cursor".

| Input                    | Default action                                    |
| ------------------------ | ------------------------------------------------- |
| \*\*Click\*\*                | Pivot — position                                  |
| \*\*Shift + click\*\*        | Pivot — orientation                               |
| \*\*Drag\*\*                 | Pivot — aim its local \*\*+X\*\* at the release point |
| \*\*Ctrl + click\*\*         | \*\*3D cursor\*\* — position                          |
| \*\*Ctrl + Shift + click\*\* | \*\*3D cursor\*\* — orientation                       |
| \*\*Ctrl + drag\*\*          | \*\*3D cursor\*\* — aim its \*\*+X\*\*                    |

After the click, the \[redo panel\](/pivot-transform/editing-the-pivot/pivot-or-cursor.md) (\*\*F9\*\*) lets you flip \*\*Set Position / Set Rotation\*\* or switch between pivot and cursor.

{% hint style="info" %}
Up to 5.1.5 a plain click always did position \*\*and\*\* orientation, with \*\*Shift\*\* for position only. From 5.1.6 the two are separate actions and you choose what each one does. To get the old feel back, set \*\*Click\*\* to \*Position & Orientation\* and \*\*Shift Click\*\* to \*Position\*.
{% endhint %}

## Drag — Align X

Drag and the pivot swings to face what you point at: its local \*\*+X\*\* ends up aimed at the element you release on. The \*\*Drag\*\* slot picks one of two behaviours:

| Action                 | Result                                                                        |
| ---------------------- | ----------------------------------------------------------------------------- |
| \*\*Align X\*\*            | Only aim. The pivot doesn't move — start the drag anywhere, even off the mesh |
| \*\*Position & Align X\*\* | First move the pivot onto the element under the press, then aim it            |

While you drag, the viewport shows what you'll get — the element under the cursor highlights, a line runs from the pivot to it, and the pivot's \*\*resulting X / Y / Z axes\*\* are drawn in place. Release to commit exactly that. Release over empty space and nothing is aimed.

\*\*Ctrl + drag\*\* aims the 3D cursor instead. \*\*Esc\*\* or \*\*right-click\*\* mid-drag cancels, and \*\*F9\*\* afterwards exposes the \*\*Aim Target\*\* so you can nudge it.

{% hint style="info" %}
\*\*Position & Align X\*\* is \*\*two undo steps\*\* on purpose: one \*\*Ctrl + Z\*\* removes just the aiming and leaves the pivot where it landed, a second reverts the placement too. \*\*Align X\*\* never places anything, so it's a single step.
{% endhint %}

{% hint style="info" %}
The axes are a preview, not a live edit. Rotating a pivot counter-rotates the mesh data, so applying it on every mouse move would rewrite every vertex of the object per frame. The preview uses the same math the operator commits, so what you see is what you get.
{% endhint %}

## Flow settings

In the tool header (or the sidebar tab):

| Setting              | Does                                                                               |
| -------------------- | ---------------------------------------------------------------------------------- |
| \*\*Edge Midpoint\*\*    | Also snap to the middle of edges                                                   |
| \*\*Face Center\*\*      | Also snap to face centers                                                          |
| \*\*Backface Culling\*\* | Hide snap points on faces turned away from you, so you only catch what you can see |
| \*\*Selected Only\*\*    | Pick only on \*\*selected\*\* objects — everything else is ignored. Off by default     |

\*\*Selected Only\*\* also lives in \*\*Preferences → Add-ons → Pivot Transform → Pivot Flow\*\*, and like the Mouse Actions it's global — it sticks across files. Handy in a crowded scene: select what you're working on and the highlight stops landing on background geometry. Objects you're editing (Edit or Pose mode) always stay pickable. Note that unselected objects don't occlude either — snap points behind them remain reachable.

## Mouse Actions

The popover in the tool header — the same three settings live in \*\*Preferences → Add-ons → Pivot Transform → Pivot Flow\*\*. They're global: set them once and they follow you across files.

| Setting         | Does                    |
| --------------- | ----------------------- |
| \*\*Click\*\*       | What a plain click does |
| \*\*Shift Click\*\* | What Shift + click does |
| \*\*Drag\*\*        | What click-drag does    |

## Target

\*\*Active\*\* moves only the active object's pivot. \*\*Selected\*\* moves the pivot of every selected object to the picked spot. Set it in the tool header.

{% hint style="info" %}
Only origins move — the geometry stays put. This is the \[Pivot Transform\](/pivot-transform/editing-the-pivot/affect-only-origins.md) mode, which the tool turns on while it's active.
{% endhint %}

Drops the pivot to the lowest point of the mesh. The \*\*▾\*\* popover holds the options:

| Option                | Does                                                                                              |
| --------------------- | ------------------------------------------------------------------------------------------------- |
| \*\*Drop To X / Y / Z\*\* | Which axes get dropped to the low point                                                           |
| \*\*Mode\*\*              | How the low point is measured — \*\*Lowest Median Center\*\*, \*\*Lowest Origin\*\*, or \*\*Lowest Vertex\*\* |
| \*\*Use Modifier\*\*      | Measure from the modified (evaluated) mesh                                                        |
| \*\*Drop To Active\*\*    | Use the active object's floor level for all selected                                              |

## Origin presets

Quick buttons for the standard origin spots:

\* \*\*To 3D Cursor\*\* — origin to the cursor.
\* \*\*Center of Mass\*\* — the mesh's mass center.
\* \*\*Geometry\*\* — origin to the median of the geometry (and \*Mesh To Pivot\*, which moves the geometry to the origin instead).

In Object Mode the pie adds \*\*Mass\*\* and \*\*Volume\*\* centers too.

{% hint style="info" %}
These act through \[Affect Only Origins\](/pivot-transform/editing-the-pivot/affect-only-origins.md), so the geometry stays where it is (except \*Mesh To Pivot\*, which is the deliberate opposite).
{% endhint %}

# Cursor Actions

One-click cursor moves. The same four buttons appear in the sidebar tab, the \[3D Cursor tool\](/pivot-transform/3d-cursor/cursor-tool.md) header, and the pie menu (\*\*Shift + Alt + A\*\*).

| Button                    | Does                                                     |
| ------------------------- | -------------------------------------------------------- |
| \*\*To Active / Selection\*\* | Move and orient the cursor to the selection              |
| \*\*Align From View\*\*       | Point the cursor's orientation to match the current view |
| \*\*Reset Location\*\*        | Send the cursor back to the world origin (position only) |
| \*\*Reset Rotation\*\*        | Clear the cursor's rotation (orientation only)           |

## Apply cursor to objects

\*\*Ctrl + click\*\* on a \*\*Reset\*\* button first applies the cursor's transform to the selected objects, then resets — a fast way to bake a cursor-based placement and clean up in one go.

{% hint style="info" %}
Every action here is undoable. To place the cursor \*on geometry\* by hand, use the \[3D Cursor tool\](/pivot-transform/3d-cursor/cursor-tool.md); to keep positions around, use \[Saved Cursors\](/pivot-transform/3d-cursor/saved-cursors.md).

The pivot actions can place the cursor too: hold \*\*Ctrl\*\* on any of them — a Flow snap point, a BBox corner, To Bottom… — and the \*\*cursor\*\* goes to the target instead of the pivot → \[Pivot or Cursor\](/pivot-transform/editing-the-pivot/pivot-or-cursor.md).
{% endhint %}

# FAQ & Troubleshooting

## The tool doesn't move the pivot

Check, in order:

1. Something is selected — no selection, no pivot to move.
2. \*\*Pivot Transform\*\* (Affect Only Origins) is on. A Pivot tool turns it on automatically; if you're using \*\*G / R / S\*\* without a tool, flip the toggle yourself.
3. \*\*Target\*\* is what you expect — \*\*Active\*\* touches one object, \*\*Selected\*\* touches all of them.

## My mesh moved instead of the origin

The \*\*Pivot Transform\*\* toggle is off, so transforms hit the geometry as usual. Turn it on → \[Affect Only Origins\](/pivot-transform/editing-the-pivot/affect-only-origins.md). (The one button that \*should\* move the mesh is \*\*Mesh To Pivot\*\*.)

## G / R / S still move the object after I'm done

The origin-only mode stays on until you turn it off. When you leave the Pivot tool with it still active, an \*\*Apply Pivot Transform\*\* button shows up in the viewport's top menu bar — click it to switch back.

## A shortcut does nothing

Another add-on is likely using the same key. Rebind Pivot Transform's keys in \*\*Preferences → Add-ons → Pivot Transform → Keymaps\*\*, or check Blender's main Keymap preferences to see what's winning.

## The 3D Cursor tool has no shortcut

By design — \*\*Shift + Alt + D\*\* ships disabled. Enable it in the add-on's \*\*Keymaps\*\*.

## Can I change an action's options after clicking?

Yes — every pivot action has a live \*\*Adjust Last Operation\*\* panel (\*\*F9\*\* / bottom-left corner), in Edit modes too. Change the options, or use the \*\*Affect: Pivot / 3D Cursor\*\* toggles to redirect the action; the result is recomputed from the state before the click → \[Pivot or Cursor & the Redo Panel\](/pivot-transform/editing-the-pivot/pivot-or-cursor.md).

## Undo from Edit Mode kicked me to Object Mode

Expected. A pivot move changes object-level data that Blender's edit-mode undo can't store, so the add-on records the undo step in Object Mode — one \*\*Ctrl + Z\*\* cleanly reverts the whole action, but lands you in Object Mode.

## The cursor is undoable now?

Yes. Blender normally leaves the 3D cursor out of undo; cursor moves made through Pivot Transform are in the history.

## Will updating lose my settings?

No. Install the new \`.zip\` over the old one and restart — keymaps and settings are kept.
