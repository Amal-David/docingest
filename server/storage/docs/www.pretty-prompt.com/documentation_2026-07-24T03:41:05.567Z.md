# Change your email address or password — Pretty Prompt Docs

Introducing: [Pretty Chat](https://www.pretty-prompt.com/pretty-chat)
 • Chat with any website without switching tabs. See how it works

You can change your email or password from the [Pretty Prompt web app](https://app.pretty-prompt.com/)
.

Change your password
--------------------

1.  Sign in at [app.pretty-prompt.com](https://app.pretty-prompt.com/)
    .
2.  Open **Settings → Account**.
3.  Click **Change password**, enter your current password, and set a new one.

If you signed up with Google, you won't have a password — sign in with **Continue with Google** instead.

Change your email
-----------------

Email changes require a quick verification step to make sure the new address belongs to you.

1.  Open **Settings → Account**.
2.  Click **Change email** and enter your new email.
3.  Check your inbox for a verification link. Click it to confirm.

Sign-in methods
---------------

Pretty Prompt supports two sign-in methods:

*   **Email + password** — classic login.
*   **Google OAuth** — one-click sign-in using your Google account.

You can use both on the same account. Signing in with one method links to the other as long as the email matches.

# Cancel your subscription — Pretty Prompt Docs

Introducing: [Pretty Chat](https://www.pretty-prompt.com/pretty-chat)
 • Chat with any website without switching tabs. See how it works

You can cancel your Pretty Prompt subscription anytime. No hard feelings, no hoops to jump through.

How to cancel
-------------

1.  Sign in at [app.pretty-prompt.com](https://app.pretty-prompt.com/)
    .
2.  Open **Settings → Billing**.
3.  Click **Cancel subscription** and confirm.

You'll keep full access until the end of your current billing period. After that, your account automatically drops to the free plan — your saved prompts stay put.

Refunds
-------

Subscriptions are billed in advance. If you cancel before the end of a billing period, you're not charged for the next one. For refunds on the current period, reach out within 14 days and we'll take a look.

Re-subscribe later
------------------

Your account, prompts, and history are preserved if you cancel. Re-subscribing is one click — nothing to migrate.

# What is Pretty Prompt? — Pretty Prompt Docs

Introducing: [Pretty Chat](https://www.pretty-prompt.com/pretty-chat)
 • Chat with any website without switching tabs. See how it works

Pretty Prompt helps you write better prompts, right where you already use AI. Think of it as **Grammarly for prompting**: a writing partner that makes every prompt clearer, sharper, and better at getting the results you want from AI tools like ChatGPT, Claude, Gemini, Perplexity, Lovable, and more.

How it works
------------

You write your idea the way you'd normally say it. Pretty Prompt improves it into a well-structured prompt that the AI can actually act on. No template hunting, no trial-and-error, no prompt engineering knowledge required.

Where you can use it
--------------------

*   **Browser extension** — works inside ChatGPT, Claude, Gemini, Perplexity, Lovable, v0, Bolt, Grok, and any other chat-based AI tool. Available for Chrome, Edge, Brave, Arc, Opera, Comet, and other Chromium-based browsers.

     — for improving prompts anywhere and managing your saved Prompt Library.
*   **Anywhere keyboard shortcut** — hit `Cmd+Shift+P` (or `Ctrl+Shift+P` on Windows) to open Pretty Prompt from any page.

Why people use it
-----------------

*   Turn rough ideas into clear prompts instantly
*   Get better AI responses faster
*   Save your favorite prompts in the Prompt Library and reuse them across devices

# Pretty Prompt MCP Server — Pretty Prompt Docs

Introducing: [Pretty Chat](https://www.pretty-prompt.com/pretty-chat)
 • Chat with any website without switching tabs. See how it works

Pretty Prompt provides an MCP server so MCP-aware clients like **Cursor** and **Claude** can connect to Pretty Prompt to browse and save prompts in your library.

Cursor setup
------------

Add this to your Cursor MCP config after generating a key. The same key works for Claude Desktop and other API-key MCP clients.

    {
      "mcpServers": {
        "pretty-prompt": {
          "command": "npx",
          "args": [\
            "-y",\
            "@pretty-prompt/mcp@latest"\
          ],
          "env": {
            "PRETTY_PROMPT_API_KEY": "pp_mcp_YOUR_KEY_HERE"
          }
        }
      }
    }
    

Generate a key on [app.pretty-prompt.com/settings/mcp](https://app.pretty-prompt.com/settings/mcp)
 and replace `pp_mcp_YOUR_KEY_HERE`.

Connect in Claude
-----------------

Use Pretty Prompt directly in claude.ai — no API key needed. You authorize access with your Pretty Prompt account.

1.  In Claude, open **Settings → Connectors**.
2.  Click **Add custom connector** and paste the URL below.
3.  Click **Connect** and approve access with your **Pretty Prompt** account.

`https://production.pretty-prompt.com/mcp`

Watch the setup walkthrough:

[https://youtu.be/hoWW3lAXQss](https://youtu.be/hoWW3lAXQss)

# Create a team and invite members — Pretty Prompt Docs

Introducing: [Pretty Chat](https://www.pretty-prompt.com/pretty-chat)
 • Chat with any website without switching tabs. See how it works

If you have a **team license**, you can create teams in Pretty Prompt and share prompts across your organization. Each team gets its own pool of prompt credits that members draw from.

Don't have a team plan yet? See [Team plans](https://www.pretty-prompt.com/#pricing)
 or get in touch about pricing.

Create a team
-------------

1.  Go to [**Teams**](https://app.pretty-prompt.com/teams)
     in the [web app](https://app.pretty-prompt.com/)
    .
2.  Select **Create Team**.
3.  Enter a **Team Name**.
4.  If your plan uses pooled credits, set how many **prompt credits** the team can use per cycle (refreshes to the full allocation automatically). Everyone on the team will draw from that shared pot.
5.  Click **Create** (or save) when you're done.

Edit a team
-----------

To change the team name or credit allocation, click the pencil icon next to the team. A modal opens where you can update the name and the number of prompt credits for the team. (Only Team Admins can do this.)

Invite team members
-------------------

1.  On the same [**Teams**](https://app.pretty-prompt.com/teams)
     page, open the team you want.
2.  Click **Invite Team Member**.
3.  Enter their email address and send the invite.

Done. Once they accept and the team is **Active**, they can:

*   Use prompt credits from the team's shared pool
*   Access **shared prompts** saved for that team

# Save prompts to your Prompt Library — Pretty Prompt Docs

Introducing: [Pretty Chat](https://www.pretty-prompt.com/pretty-chat)
 • Chat with any website without switching tabs. See how it works

The **Prompt Library** is your personal collection of prompts you want to reuse, like a prompt vault, accessible anywhere. It syncs across every device you're signed in to — extension, web app, and any browser.

If you find yourself asking an LLM the **same thing three or more times**, that's a good sign you should save the prompt and reuse it next time. That's where the Prompt Library saves you time.

[Watch the full library tutorial →](https://youtu.be/dxFMfvRFWFg)

Save a prompt
-------------

**After an improvement** — when Pretty Prompt improves a prompt, click the Save button next to the Apply button. Give it a short name so you can find it later in your Library.

**From scratch** — you can also save a prompt you wrote yourself, or paste one in from another platform (Notion, Google Docs, a previous chat, etc.) without running Improve first. Just open the Library, click **New Prompt**, and save it there.

Manage saves from the **extension** or the [web app](https://app.pretty-prompt.com/)
 — same library either way.

Reuse a prompt
--------------

Open the extension (or the web app) and pick the prompt from your library. One click inserts it into whatever tool you're currently using.

Organize and edit
-----------------

*   **Edit anytime** — open a saved prompt and update the text; your changes sync everywhere.
*   **Folders and tags** — sort prompts so weekly reports, code reviews, and client work stay easy to find.

Good candidates for your library
--------------------------------

*   Prompts you find yourself re-typing every week (weekly summaries, code review templates, writing style guides).
*   Long structured prompts with lots of context — so you only write them once.
*   Prompts you've iterated on and tuned until they consistently produce great output.

> "Works everywhere… doesn't depend which platform I use."

On a team plan? After you save a prompt, you can [share it with your team](https://www.pretty-prompt.com/docs/using-pretty-prompt/share-prompts-with-team)
.

# Install the Chrome extension — Pretty Prompt Docs

Introducing: [Pretty Chat](https://www.pretty-prompt.com/pretty-chat)
 • Chat with any website without switching tabs. See how it works

Pretty Prompt runs as a browser extension on any Chromium-based browser. That includes Chrome, Edge, Brave, Arc, Opera, and Comet.

Install in three steps
----------------------

1.  Open the [Pretty Prompt page on the Chrome Web Store](https://chromewebstore.google.com/detail/prettyprompt/opjebobgkipcdimgofkboimilnchghpd)
    .
2.  Click **Add to Chrome** (the same button adds it to Edge, Brave, Arc, etc.).
3.  Pin the extension to your toolbar so it's always one click away.

That's it. The next time you open ChatGPT, Claude, or Gemini, Pretty Prompt will be there — you'll see a small button next to the chat input. [See video example here](https://youtu.be/oHaScqw0fXI)
.

Keyboard shortcut
-----------------

On any page, press `Cmd+Shift+P` on macOS or `Ctrl+Shift+P` on Windows/Linux to open Pretty Prompt in a popup. You can type, paste, or edit anywhere — even outside of a supported AI tool.

Troubleshooting
---------------

If the button doesn't show up after installing:

*   Make sure the extension is pinned and enabled in `chrome://extensions`.
*   Refresh the AI tool tab once after installing.
*   If you're on an older version, see [Manually update the extension](https://www.pretty-prompt.com/docs/troubleshooting/manually-update-extension)
    .

# On which AI sites can I use Pretty Prompt? — Pretty Prompt Docs

Introducing: [Pretty Chat](https://www.pretty-prompt.com/pretty-chat)
 • Chat with any website without switching tabs. See how it works

Pretty Prompt works right inside the AI tools you already use **in your browser** (Chrome, Edge, Brave, and similar).

Once you've installed the extension, open ChatGPT, Claude, or Gemini **on the website** — for example [chatgpt.com](https://chatgpt.com/)
, claude.ai, or gemini.google.com. It does **not** work in the desktop apps you download to your Mac or PC. To use Pretty Prompt in the desktop, use the Desktop Version of Pretty Prompt (currently in beta).

Enabled by default
------------------

After you install the extension, Pretty Prompt appears in the chat input on these sites with no extra setup:

*   **ChatGPT**
*   **Claude**
*   **Gemini**

Open one of them in your browser, refresh the tab if you just installed, and you should see the Pretty Prompt button next to the message box.

Other sites (enable once in the web app)
----------------------------------------

Tools like **Perplexity**, **Lovable**, **v0**, **Bolt**, **Grok**, **Base44**, and others are supported too — you turn them on once under [**Sites**](https://app.pretty-prompt.com/sites)
 in the [Pretty Prompt web app](https://app.pretty-prompt.com/)
.

For the full list and step-by-step instructions, see [Use Pretty Prompt on Perplexity, Lovable, v0, and more](https://www.pretty-prompt.com/docs/using-pretty-prompt/use-on-other-sites)
.

# Manually update the Chrome extension — Pretty Prompt Docs

Introducing: [Pretty Chat](https://www.pretty-prompt.com/pretty-chat)
 • Chat with any website without switching tabs. See how it works

Chrome normally updates extensions in the background every few hours, but sometimes an update doesn't land immediately — especially if you haven't opened the extension popup in a while. Good news: you can force it in 10 seconds.

Force an update
---------------

1.  Open `chrome://extensions` in a new tab.
2.  Toggle **Developer mode** on in the top-right corner.
3.  Click the **Update** button that appears in the top-left.
4.  Chrome checks every extension for updates and pulls the latest Pretty Prompt.

Turn Developer mode back off when you're done (optional — it doesn't affect how Pretty Prompt works).

If the update doesn't appear
----------------------------

*   Close and reopen Chrome.
*   Remove and reinstall the extension from the [Chrome Web Store](https://chromewebstore.google.com/detail/prettyprompt/opjebobgkipcdimgofkboimilnchghpd)
    . Your account, saved prompts, and Pro status all sync back automatically after signing in.

Why this happens
----------------

Chrome checks for extension updates periodically, but:

*   Your laptop may have been offline when the check ran.
*   The extension popup hasn't been opened recently, so Chrome deprioritized it.
*   A recent release is still rolling out gradually across the Chrome Web Store.

The manual update above sidesteps all three.
