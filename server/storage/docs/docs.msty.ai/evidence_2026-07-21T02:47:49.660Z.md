# Model Matchmaker - Msty Studio Docs

Model Matchmaker
================

Find the best model for your task using ranked recommendations

Model Matchmaker helps you choose a starting model when you are not sure which one to use.

Set your priorities, review ranked suggestions, then test the top picks in real conversations.

![msty matchmaker](https://docs.msty.ai/studio/images/matchmaker.png)

[When to Use Matchmaker](https://docs.msty.ai/studio/managing-models/model-matchmaker#when-to-use-matchmaker)

--------------------------------------------------------------------------------------------------------------

Use Matchmaker when you:

*   Are adding a new provider and need a starting model
*   Need a fast recommendation instead of trial-and-error
*   Want to compare candidates before setting defaults

[How Matchmaker Works](https://docs.msty.ai/studio/managing-models/model-matchmaker#how-matchmaker-works)

----------------------------------------------------------------------------------------------------------

### [Open Matchmaker](https://docs.msty.ai/studio/managing-models/model-matchmaker#open-matchmaker)

Go to **Model Hub > Matchmaker**.

### [Set Priorities](https://docs.msty.ai/studio/managing-models/model-matchmaker#set-priorities)

Choose what matters most for your task.

### [Review Ranked Models](https://docs.msty.ai/studio/managing-models/model-matchmaker#review-ranked-models)

Matchmaker returns ordered suggestions based on your priorities.

### [Validate in Chat](https://docs.msty.ai/studio/managing-models/model-matchmaker#validate-in-chat)

Test top models with real prompts in [Conversations](https://docs.msty.ai/studio/conversations/main-chat)
, [Split Chat](https://docs.msty.ai/studio/conversations/split-chat)
, or [Turnstiles](https://docs.msty.ai/studio/add-ons/turnstiles)
.

![msty matchmaker ranked models](https://docs.msty.ai/studio/images/ranked-models.png)

[Recommended Follow-Up](https://docs.msty.ai/studio/managing-models/model-matchmaker#recommended-follow-up)

------------------------------------------------------------------------------------------------------------

After choosing a model, set it as default or tag its purpose from [Managing Models](https://docs.msty.ai/studio/managing-models)
.

# Command Palette - Msty Studio Docs

Command Palette
===============

Quickly run actions and navigate Msty Studio

Command Palette gives you one searchable command surface for navigation, creation, settings, and desktop actions.

Open it with **Cmd/Ctrl + K**.

[Available Across Msty Studio](https://docs.msty.ai/studio/settings/command-palette#available-across-msty-studio)

------------------------------------------------------------------------------------------------------------------

The Command Palette remains available while you are working in navigable hubs and dialogs, including:

*   Model Hub
*   Settings
*   Toolbox
*   Persona Studio
*   Prompt Studio
*   Turnstiles
*   Knowledge Stacks
*   Environments
*   Notifications, Insights, and the Log Viewer

Press **Cmd/Ctrl + K** without manually closing the current hub. When you run a navigation command, Msty closes the existing navigable surface and opens the selected destination.

The palette may remain unavailable while a blocking confirmation, editor drawer, license prompt, or other modal action requires your attention.

[Major Parts](https://docs.msty.ai/studio/settings/command-palette#major-parts)

--------------------------------------------------------------------------------

### [Create commands](https://docs.msty.ai/studio/settings/command-palette#create-commands)

Start new conversations, split chats, persona or crew chats, forge canvases, and workspaces.

### [Navigation commands](https://docs.msty.ai/studio/settings/command-palette#navigation-commands)

Jump directly between Model Hub, Toolbox, Persona Studio, Prompt Studio, Turnstiles, Knowledge Stacks, environments, notifications, and other major surfaces.

### [Settings and appearance commands](https://docs.msty.ai/studio/settings/command-palette#settings-and-appearance-commands)

Open settings sections, toggle mini map, and quickly switch theme, mode, split width, accent, or base color.

### [Desktop commands](https://docs.msty.ai/studio/settings/command-palette#desktop-commands)

On Desktop, run actions like checking for updates or opening the log viewer from the same interface.

[Using Command Palette](https://docs.msty.ai/studio/settings/command-palette#using-command-palette)

----------------------------------------------------------------------------------------------------

1.  Press **Cmd/Ctrl + K**.
2.  Type what you want to do, such as `new`, `persona`, or `settings`.
3.  Move through results with arrow keys or `Tab`.
4.  Press `Enter` to run the selected command.
5.  Press `Esc` to close.

Image placeholder: Command Palette with search input and grouped command results

[Tip](https://docs.msty.ai/studio/settings/command-palette#tip)

----------------------------------------------------------------

You can customize the Command Palette shortcut in **Settings > Keyboard Shortcuts**.

# Manage Teams - Msty Studio Docs

Manage Teams
============

Manage teams and what they can access in Msty Studio

Teams allow you to group users and assign access to features, platforms, models, and storage options.

[Add a New Team](https://docs.msty.ai/studio/enterprise/teams#add-a-new-team)

------------------------------------------------------------------------------

![add new team](https://docs.msty.ai/studio/images/enterprise/new-team-slideout.png)

From the **Teams** tab, select the **Create New Team** button to open the new team slide-out form.

#### [Configure the following options:](https://docs.msty.ai/studio/enterprise/teams#configure-the-following-options)

*   **Team Name**: the name of the team
*   **Platform Access**: select which platforms the team can access - Msty Studio Desktop, Msty Studio Web, or both ![user table](https://docs.msty.ai/studio/images/enterprise/platform-access.png)
*   **Users**: select which users belong to this team
*   **Features**: select which features the team members can access
    *   Insights
    *   Knowledge Stacks
    *   Toolbox
    *   Personas
    *   Prompts Library
    *   Real Time Data
    *   Attachments
    *   Forge Mode
    *   Remote Service
    *   Turnstile
*   **Model Hub**: select which online providers the team can access; they will need to provide their own API keys for these providers
*   **Model Providers**: select pre-configured provider models that the team can access - see the **Model Providers** section below for more details
*   **Storage**: select which S3 compatible storage provider to use for team sharing of Knowledge Stacks, Prompts, and Personas. You must have already configured a storage provider in **Storage** to select it here.

Once you have configured the team, select the **Create Team** button to create the team.

### [Model Providers](https://docs.msty.ai/studio/enterprise/teams#model-providers)

![user table](https://docs.msty.ai/studio/images/enterprise/share-model.png)

When adding a new online provider and model, you can select the cloud-sync option to share with team. You can also select the cloud icon from the Model Hub > Model Providers list as displayed in the image above.

This will add a copy of the provider and selected models and make this available to other Admins as well as the account Owner.

You may then enable this provider and models for specific teams when creating or editing a team.

Team members that have the **user** role can use the shared models; however, they can not edit the provider configurations nor manage the shared models.

[Manage User's Teams](https://docs.msty.ai/studio/enterprise/teams#manage-users-teams)

---------------------------------------------------------------------------------------

You can manage which teams a user belongs to either from the **Teams** tab or from the **Users** tab.

From the **Users** tab, select the ellipsis on the right side of a user and select **Manage Team** to open the manage teams modal.

![user table](https://docs.msty.ai/studio/images/enterprise/manage-users-team.png)

From this modal, you can select or deselect teams for the user. You may also assign the **Active Team** for the user, which can be used to set default entitlements for the user when they first sign in.
