# Adicionar Veiculos | Documentação FluxoShop

![Page cover](https://fluxoshop.gitbook.io/fluxoshop-docs/~gitbook/image?url=https%3A%2F%2F701688824-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252F3pecrT3XkqKbsgtvNlV0%252Fuploads%252FDrluoQlkvmYLevltr47h%252FLOGO%2520SITE%2520PDF.png%3Falt%3Dmedia%26token%3Db9e3b3e4-72fe-47e5-baf6-a4b92ef780ea&width=1248&dpr=3&quality=100&sign=7b7e0f07118fcd7efc0044887f17b144&sv=3)

For the complete documentation index, see [llms.txt](https://fluxoshop.gitbook.io/fluxoshop-docs/llms.txt)
. This page is also available as [Markdown](https://fluxoshop.gitbook.io/fluxoshop-docs/informacoes/addvehs.md)
.

Passos de como adicionar um novo veiculo em sua base, lembre-se você também pode assistir o video tutorial explicativo sobre os passos para adicionar um novo veiculo na sua base diretamente na aba de tutorial da BASE MATRIX.

LEIA ABAIXO COM ATENÇÃO![](https://fluxoshop.gitbook.io/fluxoshop-docs/informacoes/addvehs#leia-abaixo-com-atencao)

--------------------------------------------------------------------------------------------------------------------

1.  **PRÉ-REQUISITOS** **(VEJA COM ATENÇÃO)**
    

Antes de iniciar qualquer modificação, verifique cuidadosamente:

*   O resource do veículo deve estar corretamente instalado, contendo: • Pasta "stream" • Arquivo "fxmanifest.lua" • Demais arquivos necessários ao funcionamento do veículo
    
*   O servidor deve estar configurado para carregar o resource no arquivo server.cfg, utilizando o comando: ensure nome\_do\_resource
    
*   O nome de spawn do veículo deve ser identificado previamente e utilizado de forma idêntica em TODOS os arquivos configurados.
    

IMPORTANTE: A inconsistência no nome de spawn é uma das principais causas de erro na configuração.

* * *

1.  **CENÁRIO DE EXEMPLO**
    

Para fins de demonstração, considere o seguinte:

*   Nome de spawn: exemplocarro
    
*   Capacidade desejada do porta-malas: 350
    

Referência de valores comuns:

*   Veículos padrão (vanilla): ~120
    
*   Veículos add-on: ~350
    

* * *

1.  **PROCEDIMENTO DE CONFIGURAÇÃO**
    

3.1 ARQUIVO: vrp/client/basic\_garage.lua

AÇÃO: Adicionar o veículo na tabela vehList.

OBJETIVO: Permitir que o cliente reconheça corretamente o modelo do veículo e disponibilize suas informações para o framework e scripts.

CONFIGURAÇÃO (CONCEITUAL):

*   name = "exemplocarro"
    
*   hash = GetHashKey('exemplocarro')
    
*   banned = false (ou true, conforme regra do servidor)
    

* * *

3.2 ARQUIVO: vrp/cfg/inventory.lua

AÇÃO: Adicionar o veículo na tabela cfg.chestweight.

OBJETIVO: Definir o peso máximo do porta-malas (capacidade de armazenamento).

EXEMPLO: \["exemplocarro"\] = 350

* * *

3.3 ARQUIVO: \[FLUXO-NATIONS\]/fluxo\_garages/config.lua

AÇÃO: Cadastrar o veículo com os seguintes parâmetros:

*   hash
    
*   name
    
*   modelo
    
*   price
    
*   banido
    
*   tipo (carros ou motos)
    
*   capacidade
    

OBJETIVO: Definir regras da garagem, incluindo preço, categoria e comportamento do veículo.

IMPORTANTE: O valor de "capacidade" DEVE ser exatamente igual ao definido no inventory.lua.

**Exemplo: Se inventory.lua = 350 Então config.lua também deve ser = 350**

**OBSERVAÇÃO:** **O sistema de desmanche utiliza o preço definido na garagem. Caso o veículo não esteja cadastrado, o pagamento pode ser reduzido.**

* * *

3.4 ARQUIVO: \[FLUXO-EMPREGOS\]/fluxoEmpregos/ignore/fluxo\_desmanche/server/server.lua

AÇÃO: Adicionar o nome do veículo na lista CarrosDesmanches.

OBJETIVO: Permitir que o veículo seja utilizado no sistema de desmanche.

EXEMPLO: 'exemplocarro',

OBSERVAÇÃO: Se o veículo não estiver nessa lista, ele NÃO poderá ser desmanchado.

# Adicionar Veiculos

GUIA DE PERMISSÕES E COMANDOS DISPONIVEIS NA BASE.

Passos de como adicionar um novo veiculo em sua base, lembre-se você também pode assistir o video tutorial explicativo sobre os passos para adicionar um novo veiculo na sua base diretamente na aba de tutorial da BASE MATRIX.

## LEIA ABAIXO COM ATENÇÃO!

1. \*\*PRÉ-REQUISITOS&#x20;\*\*<mark style="color:$danger;">\*\*(VEJA COM ATENÇÃO)\*\*</mark>

Antes de iniciar qualquer modificação, verifique cuidadosamente:

\* O resource do veículo deve estar corretamente instalado, contendo: • Pasta "stream" • Arquivo "fxmanifest.lua" • Demais arquivos necessários ao funcionamento do veículo
\* O servidor deve estar configurado para carregar o resource no arquivo server.cfg, utilizando o comando: ensure nome\\\_do\\\_resource
\* O nome de spawn do veículo deve ser identificado previamente e utilizado de forma idêntica em TODOS os arquivos configurados.

IMPORTANTE: A inconsistência no nome de spawn é uma das principais causas de erro na configuração.

\*\*\*

2. \*\*CENÁRIO DE EXEMPLO\*\*

Para fins de demonstração, considere o seguinte:

\* Nome de spawn: exemplocarro
\* Capacidade desejada do porta-malas: 350

Referência de valores comuns:

\* Veículos padrão (vanilla): \\~120
\* Veículos add-on: \\~350

\*\*\*

3. \*\*PROCEDIMENTO DE CONFIGURAÇÃO\*\*

3.1 ARQUIVO: vrp/client/basic\\\_garage.lua

AÇÃO: Adicionar o veículo na tabela vehList.

OBJETIVO: Permitir que o cliente reconheça corretamente o modelo do veículo e disponibilize suas informações para o framework e scripts.

CONFIGURAÇÃO (CONCEITUAL):

\* name = "exemplocarro"
\* hash = GetHashKey('exemplocarro')
\* banned = false (ou true, conforme regra do servidor)

\*\*\*

3.2 ARQUIVO: vrp/cfg/inventory.lua

AÇÃO: Adicionar o veículo na tabela cfg.chestweight.

OBJETIVO: Definir o peso máximo do porta-malas (capacidade de armazenamento).

EXEMPLO: \\\["exemplocarro"\] = 350

\*\*\*

3.3 ARQUIVO: \\\[FLUXO-NATIONS\]/fluxo\\\_garages/config.lua

AÇÃO: Cadastrar o veículo com os seguintes parâmetros:

\* hash
\* name
\* modelo
\* price
\* banido
\* tipo (carros ou motos)
\* capacidade

OBJETIVO: Definir regras da garagem, incluindo preço, categoria e comportamento do veículo.

IMPORTANTE: O valor de "capacidade" DEVE ser exatamente igual ao definido no inventory.lua.

<mark style="color:$danger;">\*\*OBSERVAÇÃO:\*\*</mark>\*\*&#x20;O sistema de desmanche utiliza o preço definido na garagem. Caso o veículo não esteja cadastrado, o pagamento pode ser reduzido.\*\*

3.4 ARQUIVO: \\\[FLUXO-EMPREGOS\]/fluxoEmpregos/ignore/fluxo\\\_desmanche/server/server.lua

# Desmanche

Seja bem-vindo a aba de "DESMANCHE" do nosso GUIA DE USO da FluxoShop!

\*\*Aqui no desmanche não é necessário craftar itens para desmanchar, basta você realizar a rota para coletar item "chave" e apartir dai você já consegue desmanchar veiculos.\*\*\\
\\
\*\*- O valor pago por veiculos é 10% do valor configurado em fluxo\\\_garages/config\*\*\\
\*\*OBS: Siga exatamente como está descrito abaixo para que não tenha erros.\*\*\\
\\ <mark style="color:$danger;">\*\*Nesta aba contem farms de DESMANCHE\*\*</mark>

{% hint style="info" %}
\*\*Comando para testar os Farms:\*\*\\
/tpcds: Para se teletransportar para determinada coordenada.\\
/painel id ou /group id NomeDoGrupo: Para setar alguém.\\
/org: Para abrir o painel de gerenciamento dos membros e da fac.
{% endhint %}
